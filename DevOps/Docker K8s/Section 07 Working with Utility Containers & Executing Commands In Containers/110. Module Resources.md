## Các lệnh Docker quan trọng trong module

```bash
# Build image
docker build -t name:tag .

# Chạy utility container với bind mount
docker run -it -v $(pwd):/app name:tag command

# Chạy lệnh trong container đang chạy
docker exec -it container_name command

# Docker Compose — chạy utility container
docker compose run --rm service_name command

# Docker Compose — chạy utility container với user host
docker compose run --rm --user $(id -u):$(id -g) service_name command

# Dọn dẹp containers
docker container prune
docker container ls -a  # Liệt kê tất cả containers
```
