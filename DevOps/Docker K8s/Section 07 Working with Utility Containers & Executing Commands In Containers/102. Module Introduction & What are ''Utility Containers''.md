# Utility Containers là gì? Khái niệm cần nắm khi làm việc với Docker

## Giới thiệu

Trong các bài học trước, chúng ta đã tìm hiểu về Docker Compose và cách xây dựng các ứng dụng lớn hơn với nhiều container. Tuy nhiên, Docker không chỉ có thể chạy ứng dụng — nó còn có thể được sử dụng để thực thi các tác vụ cụ thể thông qua một khái niệm gọi là **Utility Containers**.

> **Lưu ý:** "Utility Containers" không phải là thuật ngữ chính thức của Docker. Đây là cách gọi mô tả một loại container đặc biệt mà trong bài viết này chúng ta sẽ khám phá tại sao nó lại hữu ích đến vậy.

## Containers chạy ứng dụng — Điểm xuất phát

Cho đến thời điểm này, tất cả các ví dụ trong khóa học đều tập trung vào **application containers** — những container chứa mã nguồn ứng dụng và môi trường cần thiết để chạy ứng dụng đó.

Ví dụ:
- Container Node.js chạy một API
- Container React chạy một SPA
- Container Database lưu trữ dữ liệu

Đây chính là **mục đích cốt lõi** của Docker. Khi bạn viết Dockerfile và chạy `docker run`, các lệnh trong Dockerfile được thực thi và ứng dụng của bạn khởi động.

```dockerfile
FROM node:14-alpine
WORKDIR /app
COPY . .
RUN npm install
CMD ["node", "server.js"]
```

Khi chạy lệnh này, server Node.js của bạn sẽ bắt đầu hoạt động — và đó là điều tuyệt vời nhất mà Docker mang lại.

## Vậy Utility Containers là gì?

**Utility Containers** là những container **chỉ chứa một môi trường cụ thể** (ví dụ: Node.js, PHP, Python...) nhưng **không khởi chạy ứng dụng** khi chạy lên. Thay vào đó, chúng được sử dụng kết hợp với một lệnh cụ thể mà bạn chỉ định để thực thi một tác vụ nhất định.

Nói cách khác:
- **Application Container:** Chạy và duy trì ứng dụng liên tục (web server, database...)
- **Utility Container:** Chạy một lệnh cụ thể, hoàn thành tác vụ, rồi dừng lại

```bash
# Ví dụ: sử dụng utility container để chạy npm init
docker run -it -v $(pwd):/app node:14-alpine init
```

Trong ví dụ trên, container Node.js không chạy server — nó chỉ thực thi `npm init` để tạo file `package.json` rồi thoát ra.

## Syntax mới — Chạy lệnh sau tên image

Để sử dụng Utility Containers, chúng ta cần một syntax mà trước đây chưa từng sử dụng:

```bash
docker run [OPTIONS] IMAGE [COMMAND]
```

Phần `[COMMAND]` ở đây là lệnh mà bạn muốn thực thi bên trong container, **thay thế** cho lệnh mặc định được định nghĩa trong Dockerfile (CMD).

Đây là chìa khóa để biến Docker từ một công cụ chỉ chạy ứng dụng thành một công cụ đa năng có thể thực thi bất kỳ tác vụ nào trong một môi trường được cách ly.

## Tóm tắt

- **Utility Containers** là container chứa môi trường nhưng không chạy ứng dụng
- Chúng được sử dụng để thực thi các lệnh cụ thể bằng cách truyền `[COMMAND]` sau tên image
- Concept này giúp bạn tận dụng Docker cho nhiều mục đích beyond running applications
- Thuật ngữ "Utility Container" không chính thức nhưng hữu ích để mô tả pattern này

Trong bài tiếp theo, chúng ta sẽ đi sâu vào **tại sao** Utility Containers lại hữu ích trong thực tế.
