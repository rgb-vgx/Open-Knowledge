# Scaling Trong Hành Động: Thay Đổi Số Lượng Pods

Traffic đến ứng dụng tăng đột biến? Bạn cần thêm Pods để xử lý? Kubernetes giúp bạn scale up/down chỉ với một lệnh đơn giản.

## Scale Up: Thêm Pods

```bash
kubectl scale deployment/first-app --replicas=3
```

Lệnh này nói với Kubernetes: "Tôi muốn 3 Pods đang chạy thay vì 1".

Kiểm tra:

```bash
kubectl get pods
```

```
NAME                        READY   STATUS    RESTARTS   AGE
first-app-6d4f5b8c9-abc12   1/1     Running   0          10m
first-app-6d4f5b8c9-def34   1/1     Running   0          30s
first-app-6d4f5b8c9-ghi56   1/1     Running   0          30s
```

Ba Pods đang chạy, tất cả đều chạy cùng container image.

## Load Balancing giữa Pods

Vì bạn đã tạo Service type LoadBalancer, traffic sẽ được phân phối đều:

1. Truy cập ứng dụng, note lại response
2. Truy cập `/error` trên một Pod — nó crash
3. Truy cập lại ứng dụng — vẫn hoạt động bình thường

Kubernetes đã redirect traffic sang Pod khác! Và Pod bị crash sẽ được restart tự động.

## Scale Down: Giảm Pods

```bash
kubectl scale deployment/first-app --replicas=1
```

```bash
kubectl get pods
```

```
NAME                        READY   STATUS        RESTARTS   AGE
first-app-6d4f5b8c9-abc12   1/1     Running       0          12m
first-app-6d4f5b8c9-def34   0/1     Terminating   0          2m
first-app-6d4f5b8c9-ghi56   0/1     Terminating   0          2m
```

Hai Pods đang trong quá trình terminate. Sau vài giây, chỉ còn 1 Pod.

## Kết luận

Scaling là một trong những tính năng mạnh mẽ nhất của Kubernetes. Với một lệnh đơn giản, bạn có thể thay đổi số lượng Pods để xử lý traffic mà không cần can thiệp vào code hay configuration phức tạp.

---

**Tóm tắt:** Scale up/down bằng `kubectl scale deployment/name --replicas=N`. Load Balancer phân phối traffic đều giữa Pods. Pods bị terminate sẽ được graceful shutdown.
