# Hướng Dẫn Cài Đặt Kubernetes Trên Windows

Bạn đang sử dụng Windows và muốn bắt đầu với Kubernetes? Bài viết này sẽ hướng dẫn bạn từng bước cài đặt kubectl và Minikube trên hệ điều hành Windows.

## Bước 1: Kiểm tra yêu cầu hệ thống

Trước tiên, kiểm tra xem máy bạn có hỗ trợ virtualization không. Mở Command Prompt và chạy:

```cmd
systeminfo | findstr /C:"Hyper-V"
```

Nếu thấy thông tin "A hypervisor has been detected", bạn đã sẵn sàng. Nếu看到 "Virtualization Enabled in Firmware" nhưng chưa có hypervisor, bạn cần cài đặt một hypervisor trước.

### Lựa chọn Hypervisor

Trên Windows, bạn có hai lựa chọn chính:

- **Hyper-V** — hypervisor built-in trên Windows 10 Pro/Enterprise/Education
- **VirtualBox** — miễn phí, hoạt động trên mọi phiên bản Windows包括 Windows 10 Home

> **Lưu ý:** Nếu bạn sử dụng Windows 10 Home, bạn bắt buộc phải dùng VirtualBox vì Hyper-V không khả dụng.

## Bước 2: Cài đặt kubectl

### Cách 1: Dùng Chocolatey (推荐)

Chocolatey là package manager cho Windows, giúp cài đặt phần mềm dễ dàng.

Cài đặt Chocolatey (chạy PowerShell với quyền Administrator):

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
```

Sau đó cài kubectl:

```cmd
choco install kubernetes-cli
```

### Cách 2: Tải trực tiếp

Tải binary từ trang chính thức: https://kubernetes.io/docs/tasks/tools/install-kubectl-windows/

### Xác nhận cài đặt

```cmd
kubectl version --client
```

### Thiết lập cấu hình

Tạo thư mục `.kube` trong thư mục user:

```cmd
cd %USERPROFILE%
mkdir .kube
```

Trong thư mục `.kube`, tạo file tên `config` (không có extension). Bạn có thể edit file này bằng bất kỳ text editor nào.

## Bước 3: Cài đặt Hypervisor

### VirtualBox

Tải VirtualBox tại: https://www.virtualbox.org/

Chọn **Windows hosts** để tải installer, sau đó làm theo hướng dẫn cài đặt. Bạn có thể giữ nguyên các default settings.

### Hyper-V

Nếu dùng Hyper-V (Windows 10 Pro/Enterprise), kích hoạt qua:

```powershell
Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V -All
```

Sau đó khởi động lại máy.

## Bước 4: Cài đặt Minikube

Với Chocolatey:

```cmd
choco install minikube
```

Sau khi cài xong, **đóng và mở lại Command Prompt** để reload PATH.

## Bước 5: Khởi động Cluster

```cmd
minikube start --driver=virtualbox
```

Hoặc nếu dùng Hyper-V:

```cmd
minikube start --driver=hyperv
```

> **Lưu ý:** Nếu dùng Hyper-V, bạn cần chạy Command Prompt với quyền Administrator.

Lệnh này sẽ tạo virtual machine và cài đặt Kubernetes cluster bên trong. Quá trình có thể mất vài phút.

### Xử lý lỗi phổ biến

Nếu gặp lỗi liên quan đến VirtualBox và Hyper-V conflict:
1. Hoặc tắt Hyper-V đi và dùng VirtualBox
2. Hoặc dùng `--driver=hyperv` thay vì VirtualBox

## Bước 6: Xác nhận hoạt động

```cmd
minikube status
```

Nếu thấy tất cả đều "Running", chúc mừng bạn đã cài đặt thành công!

Mở dashboard để xem trực quan:

```cmd
minikube dashboard
```

## Kết luận

Bạn đã thiết lập xong môi trường Kubernetes trên Windows! Giờ đây bạn có thể bắt đầu tạo Deployments và quản lý containers bằng Kubernetes. Tất cả cấu hình đều có thể migrate lên cloud cluster khi cần.

---

**Tóm tắt:** Cài đặt Kubernetes trên Windows gồm: cài Chocolatey → cài kubectl → cài VirtualBox/Hyper-V → cài Minikube → khởi động cluster bằng `minikube start --driver=...`. Luôn dùng `minikube status` để kiểm tra.
