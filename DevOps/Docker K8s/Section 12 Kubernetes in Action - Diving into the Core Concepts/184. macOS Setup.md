# Hướng Dẫn Cài Đặt Kubernetes Trên macOS

Hôm nay chúng ta sẽ thiết lập môi trường Kubernetes hoàn chỉnh trên macOS — bao gồm kubectl và Minikube với VirtualBox.

## Bước 1: Kiểm tra yêu cầu hệ thống

Đầu tiên, hãy chắc chắn máy của bạn hỗ trợ virtualization. Chạy lệnh sau trong Terminal:

```bash
sysctl -a | grep hypervisor
```

Nếu bạn thấy từ khóa **VMX** trong output, hệ thống của bạn đã sẵn sàng. Nếu không, có thể Docker cũng không hoạt động trên máy bạn — hãy kiểm tra lại.

## Bước 2: Cài đặt kubectl

kubectl là công cụ không thể thiếu — dù bạn dùng Minikube hay cloud cluster, bạn luôn cần nó.

### Cách 1: Dùng Homebrew (推荐)

Nếu chưa có Homebrew, cài đặt trước:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Sau đó cài kubectl:

```bash
brew install kubectl
```

### Cách 2: Dùng curl

```bash
curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/darwin/amd64/kubectl"
chmod +x kubectl
sudo mv kubectl /usr/local/bin/
```

### Xác nhận cài đặt

```bash
kubectl version --client
```

Nếu bạn thấy thông tin version, kubectl đã được cài thành công.

## Bước 3: Cài đặt Hypervisor

Minikube cần hypervisor để tạo virtual machine. Có ba lựa chọn phổ biến:

- VirtualBox (miễn phí, cross-platform)
- VMware Fusion (có phí, macOS-optimized)
- Hyper-V (Windows built-in, không khả dụng trên macOS)

Chúng ta sẽ dùng **VirtualBox** vì miễn phí và hoạt động tốt trên cả macOS lẫn Windows.

Tải VirtualBox tại trang chủ: https://www.virtualbox.org/

Chọn **OS X hosts** để tải installer, sau đó làm theo hướng dẫn cài đặt.

> **Lưu ý:** Nếu macOS hiển thị cảnh báo "System Extension Blocked", vào System Preferences > Security & Privacy và nhấn "Allow".

## Bước 4: Cài đặt Minikube

Với Homebrew đã có sẵn:

```bash
brew install minikube
```

## Bước 5: Khởi động Cluster

```bash
minikube start --driver=virtualbox
```

Lệnh này sẽ:
1. Tạo một virtual machine bằng VirtualBox
2. Cài đặt Kubernetes cluster bên trong VM
3. Setup master node và worker node (gộp lại thành single-node)
4. Cài đặt tất cả phần mềm cần thiết (API server, kubelet, etc.)

Quá trình này có thể mất vài phút.

## Bước 6: Xác nhận hoạt động

```bash
# Kiểm tra trạng thái cluster
minikube status

# Mở dashboard trực quan
minikube dashboard
```

Dashboard sẽ mở trong trình duyệt, cho phép bạn xem trực quan các Pods, Deployments, và resources khác trong cluster.

## Kết luận

Bạn đã có một Kubernetes cluster hoàn chỉnh trên macOS! Bây giờ bạn có thể bắt đầu tạo Deployments và triển khai ứng dụng đầu tiên. Cấu hình này hoàn toàn có thể迁移 lên cloud cluster sau này.

---

**Tóm tắt:** Cài đặt Kubernetes trên macOS gồm 3 bước chính: cài kubectl (qua Homebrew), cài VirtualBox (hypervisor), và cài Minikube để tạo cluster cục bộ. Kiểm tra bằng `minikube status` và `minikube dashboard`.
