# Yêu Cầu Cài Đặt Kubernetes: Những Gì Bạn Cần Chuẩn Bị

Trước khi bắt tay vào thực hành, chúng ta cần hiểu rõ những thành phần nào phải được cài đặt để Kubernetes hoạt động — dù là trên máy cục bộ hay trên cloud.

## Kiến trúc cần thiết

Bất kể bạn chạy Kubernetes ở đâu, bạn luôn cần hai thành phần chính:

### 1. Cluster (Nhóm máy)

Một Kubernetes cluster bao gồm:

- **Master Node (Control Plane)** — "bộ não" của cluster, chịu trách nhiệm đưa ra quyết định
- **Worker Node(s)** — nơi thực sự chạy containers

Trong production, master node thường được phân tán trên nhiều machines để đảm bảo high availability. Nhưng để development, một single-node cluster (master + worker gộp lại) là hoàn toàn đủ.

### 2. kubectl — Công cụ giao tiếp

**kubectl** (viết tắt của kube-control) là công cụ bạn cài đặt trên máy cục bộ để gửi lệnh đến cluster. Đây là "remote control" của bạn — mọi thao tác với Kubernetes đều thông qua kubectl.

> **Lưu ý quan trọng:** kubectl KHÔNG phải là API server hay master node. kubectl là công cụ gửi lệnh, master node là nơi thực thi lệnh. Tương tự: kubectl = Tổng thống đưa ra chỉ thị, master node = tướng lĩnh thực thi, worker nodes = lính thực hiện công việc.

### Chi tiết cần cài đặt

Trên **Master Node**:
- API Server
- Scheduler
- Controller Manager
- etcd (lưu trữ state của cluster)

Trên **Worker Node**:
- Docker (container runtime)
- kubelet (agent liên lạc với master)
- kube-proxy (quản lý networking)

## Cài đặt trên máy cục bộ với Minikube

Vì đây là môi trường development, chúng ta sẽ dùng **Minikube** — công cụ tạo cluster giả lập trong một virtual machine trên máy của bạn.

### Minikube hoạt động như thế nào?

Minikube tạo một **single-node cluster** trong VM:
- Master node và worker node gộp lại thành một
- Tất cả phần mềm Kubernetes được cài đặt tự động trong VM
- Phù hợp cho development và testing
- Không phù hợp cho production (vì lack of high availability)

### Yêu cầu hệ thống

- **Hypervisor** — phần mềm tạo virtual machine (VirtualBox, VMware Fusion, Hyper-V)
- **kubectl** — công cụ line command

### Hai bước cài đặt cơ bản

```bash
# Bước 1: Cài kubectl (công cụ giao tiếp)
# macOS
brew install kubectl

# Windows (dùng Chocolatey)
choco install kubernetes-cli

# Bước 2: Cài Minikube (tạo cluster cục bộ)
# macOS
brew install minikube

# Windows
choco install minikube
```

### Khởi động cluster

```bash
# Bắt đầu cluster với VirtualBox
minikube start --driver=virtualbox

# Hoặc với Docker
minikube start --driver=docker

# Kiểm tra trạng thái
minikube status

# Mở dashboard trực quan
minikube dashboard
```

## Kết luận

Kubernetes cần hai thành phần: **cluster** (nơi chạy containers) và **kubectl** (công cụ gửi lệnh). Với Minikube, bạn có thể tạo cluster cục bộ để phát triển mà không cần cloud provider. Cấu hình bạn tạo ra trên Minikube hoàn toàn có thể deploy lên production cluster sau này.

---

**Tóm tắt:** Kubernetes cần cluster (master + worker nodes) và kubectl để giao tiếp. Minikube giúp tạo cluster cục bộ trong VM cho development. Hai thành phần cần cài đặt: kubectl (giao tiếp) và Minikube (tạo cluster).
