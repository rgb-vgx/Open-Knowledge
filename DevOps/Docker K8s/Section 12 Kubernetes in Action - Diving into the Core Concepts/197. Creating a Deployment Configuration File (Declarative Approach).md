# Tạo Deployment Configuration File: Bắt Đầu Declarative Approach

Đã đến lúc chuyển sang cách tiếp cận declarative. Bạn sẽ học cách viết deployment.yaml file để Kubernetes quản lý ứng dụng của bạn.

## Cấu trúc cơ bản của Kubernetes YAML

Mọi Kubernetes configuration file đều có cấu trúc:

```yaml
apiVersion: <version>
kind: <resource-type>
metadata:
  name: <name>
spec:
  # cấu hình chi tiết
```

### Ba thành phần chính

1. **apiVersion** — phiên bản API của Kubernetes
2. **kind** — loại resource (Deployment, Service, Pod, etc.)
3. **metadata** — thông tin về resource (tên, labels, annotations)
4. **spec** — cấu hình chi tiết của resource

## Tạo deployment.yaml

Tạo file `deployment.yaml`:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: second-app-deployment
```

### Giải thích

- **apiVersion: apps/v1** — phiên bản API mới nhất cho Deployments. Kiểm tra tại: https://kubernetes.io/docs/reference/
- **kind: Deployment** — nói với Kubernetes rằng file này tạo một Deployment
- **metadata.name** — tên của Deployment (bạn tự đặt)

## Bước tiếp theo: Thêm spec

Spec là phần quan trọng nhất — nơi bạn định nghĩa cách Deployment hoạt động. Chúng ta sẽ tiếp tục trong bài tiếp theo.

## Kết luận

Kubernetes YAML file gồm apiVersion, kind, metadata, và spec. apiVersion và kind xác định loại resource, metadata chứa thông tin identification, spec chứa cấu hình chi tiết.

---

**Tóm tắt:** Kubernetes YAML gồm 4 phần: apiVersion, kind, metadata, spec. Kiểm tra apiVersion tại official docs. Kind xác định loại resource, metadata chứa tên và labels, spec chứa cấu hình chi tiết.
