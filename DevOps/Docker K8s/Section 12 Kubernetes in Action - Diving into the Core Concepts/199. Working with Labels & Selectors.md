# Labels & Selectors: Cách Kubernetes Tổ Chức Và Liên Kết Resources

Labels và Selectors là một trong những khái niệm quan trọng nhất trong Kubernetes. Chúng cho phép bạn tổ chức, tìm kiếm, và liên kết các resources với nhau.

## Labels là gì?

Labels là **key-value pairs** gắn metadata cho any Kubernetes resource:

```yaml
metadata:
  labels:
    app: my-app
    tier: backend
    environment: production
```

- **Key** (tùy bạn): `app`, `tier`, `environment`, etc.
- **Value** (tùy bạn): `my-app`, `backend`, `production`, etc.

Mỗi resource có thể có nhiều labels. Labels giúp bạn:
- Tổ chức resources theo nhóm
- Tìm kiếm và filter resources
- Liên kết resources với nhau qua selectors

## Selectors là gì?

Selectors là cách bạn **chọn** resources dựa trên labels. Có hai loại:

### 1. matchLabels (đơn giản)

```yaml
selector:
  matchLabels:
    app: my-app
```

Chọn tất cả resources có label `app=my-app`.

### 2. matchExpressions (mạnh mẽ hơn)

```yaml
selector:
  matchExpressions:
  - key: app
    operator: In
    values:
    - my-app
    - my-other-app
  - key: tier
    operator: NotIn
    values:
    - frontend
```

Các operators hỗ trợ: `In`, `NotIn`, `Exists`, `DoesNotExist`

## Ví dụ thực tế

### Deployment selector

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
spec:
  selector:
    matchLabels:
      app: my-app  # Pods phải có label này
  template:
    metadata:
      labels:
        app: my-app  # Label gắn cho Pod
    spec:
      containers:
      - name: nginx
        image: nginx
```

Deployment sẽ quản lý tất cả Pods có label `app: my-app`.

### Service selector

```yaml
apiVersion: v1
kind: Service
metadata:
  name: my-service
spec:
  selector:
    app: my-app  # Chọn Pods có label này
  ports:
  - port: 80
    targetPort: 8080
```

Service sẽ expose tất cả Pods có label `app: my-app`.

## Sử dụng selectors trong commands

### Xóa resources theo labels

```bash
kubectl delete deployments,services -l group=example
```

Xóa tất cả deployments và services có label `group=example`.

### Filter pods

```bash
kubectl get pods -l app=my-app
```

Chỉ hiện pods có label `app=my-app`.

## Kết luận

Labels là metadata key-value pairs gắn cho resources. Selectors chọn resources dựa trên labels. Deployment dùng selectors để quản lý Pods, Services dùng selectors để expose Pods. Đây là cách Kubernetes tổ chức và liên kết resources.

---

**Tóm tắt:** Labels là key-value pairs gắn metadata. Selectors chọn resources dựa trên labels. matchLabels đơn giản, matchExpressions mạnh mẽ hơn. Dùng `-l` flag để filter resources theo labels trong commands.
