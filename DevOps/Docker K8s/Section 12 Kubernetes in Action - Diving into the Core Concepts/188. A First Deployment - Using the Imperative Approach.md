# Deployment Đầu Tiên: Cách tiếp cận Imperative

Đã đến lúc bắt tay vào thực hành! Chúng ta sẽ tạo Deployment đầu tiên sử dụng **cách tiếp cận imperative** — chạy lệnh trực tiếp trên terminal.

## Chuẩn bị

Trước khi bắt đầu, hãy đảm bảo:

1. Minikube đang chạy: `minikube status`
2. Bạn đã có Docker image sẵn sàng (hoặc biết cách push image lên registry)

## Bước 1: Build Docker Image

Cho dù bạn dùng Kubernetes, bạn vẫn cần Docker để tạo image. Kubernetes chạy containers, và containers cần images.

```bash
# Build image từ Dockerfile
docker build -t kub-first-app .

# Hoặc nếu dùng Docker Hub repository
docker build -t your-dockerhub-username/kub-first-app .
```

## Bước 2: Push image lên Docker Hub

Kubernetes cluster (kể cả Minikube) sẽ pull image từ registry, không phải từ máy cục bộ của bạn. Vì vậy bạn cần push image lên một registry như Docker Hub.

```bash
# Đăng nhập Docker Hub
docker login

# Tag image
docker tag kub-first-app your-dockerhub-username/kub-first-app

# Push image
docker push your-dockerhub-username/kub-first-app
```

## Bước 3: Tạo Deployment

Bây giờ chúng ta sẽ tạo Deployment bằng kubectl:

```bash
kubectl create deployment first-app --image=your-dockerhub-username/kub-first-app
```

Lệnh này:
1. Tạo một Deployment object tên "first-app"
2. Sử dụng image "your-dockerhub-username/kub-first-app"
3. Tự động gửi object đến Kubernetes cluster

## Bước 4: Kiểm tra Deployment

```bash
# Xem danh sách deployments
kubectl get deployments

# Output:
# NAME        READY   UP-TO-DATE   AVAILABLE   AGE
# first-app   1/1     1            1           30s
```

```bash
# Xem pods được tạo bởi deployment
kubectl get pods

# Output:
# NAME                        READY   STATUS    RESTARTS   AGE
# first-app-6d4f5b8c9-abc12   1/1     Running   0          30s
```

## Bước 5: Troubleshooting

Nếu看到 `ImagePullError` hoặc `ErrImagePull`:

```bash
kubectl get pods
# NAME                        READY   STATUS             RESTARTS   AGE
# first-app-6d4f5b8c9-abc12   0/1     ImagePullBackOff   0          1m
```

**Nguyên nhân phổ biến:** Image không tồn tại trong registry mà cluster truy cập được. Đảm bảo:
1. Image đã được push lên Docker Hub
2. Tên image đúng (bao gồm username Docker Hub)
3. Docker Hub repository là public (hoặc bạn đã configure imagePullSecrets)

## Bước 6: Xem Dashboard

```bash
minikube dashboard
```

Trong dashboard, bạn sẽ thấy:
- Deployment "first-app" với 1 replica
- Pod đang chạy với label tương ứng
- Events log cho thấy các hoạt động gần đây

## Đằng sau hậu trường

Khi bạn chạy `kubectl create deployment`, điều gì xảy ra?

1. **kubectl** gửi Deployment object đến **API Server** trên master node
2. **API Server** lưu object vào **etcd** (kotlin store)
3. **Scheduler** phân Pods vào worker nodes dựa trên resources
4. **Kubelet** trên worker node nhận Pod và khởi động container

## Kết luận

Bạn đã tạo được Deployment đầu tiên! Đây là cách tiếp cận imperative — nhanh chóng và trực tiếp. Tuy nhiên, trong thực tế, bạn nên sử dụng **declarative approach** (YAML files) để dễ maintain hơn. Chúng ta sẽ học cách đó ở phần sau.

---

**Tóm tắt:** Tạo Deployment bằng `kubectl create deployment name --image=registry/image`. Đảm bảo image nằm trong registry mà cluster có thể truy cập. Kiểm tra bằng `kubectl get deployments` và `kubectl get pods`.
