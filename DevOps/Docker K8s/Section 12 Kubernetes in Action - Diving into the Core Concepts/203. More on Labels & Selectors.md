# Tìm Hiểu Sâu Hơn Về Labels & Selectors

Labels và Selectors không chỉ đơn giản là key-value pairs. Chúng là hệ thống tổ chức mạnh mẽ cho phép bạn linh hoạt quản lý resources.

## Match Expressions: Lựa Chọn Mạnh Mẽ Hơn

Ngoài `matchLabels`, bạn có thể dùng `matchExpressions` với các operators:

```yaml
selector:
  matchExpressions:
  - key: app
    operator: In
    values:
    - second-app
    - first-app
```

### Các Operators hỗ trợ

| Operator | Ý nghĩa |
|----------|---------|
| `In` | Label value nằm trong danh sách values |
| `NotIn` | Label value không nằm trong danh sách |
| `Exists` | Label key tồn tại |
| `DoesNotExist` | Label key không tồn tại |

### Ví dụ

```yaml
selector:
  matchExpressions:
  - key: app
    operator: In
    values:
    - second-app
  - key: tier
    operator: NotIn
    values:
    - frontend
```

Chọn Pods có `app=second-app` VÀ `tier` không phải `frontend`.

## Xóa Resources Theo Labels

Dùng `-l` flag để xóa resources theo labels:

```bash
kubectl delete deployments,services -l group=example
```

Xóa tất cả deployments và services có label `group=example`.

### Kết hợp nhiều labels

```bash
kubectl delete pods -l app=my-app,environment=production
```

Xóa pods có cả hai labels: `app=my-app` VÀ `environment=production`.

## Labels Trong Practice

### Tổ chức theo environment

```yaml
metadata:
  labels:
    environment: production
    team: backend
    project: my-app
```

### Tổ chức theo version

```yaml
metadata:
  labels:
    app: my-app
    version: v1.2.3
```

### Tổ chức theo tier

```yaml
metadata:
  labels:
    app: my-app
    tier: frontend
    component: api-gateway
```

## Kết luận

Labels và Selectors là hệ thống tổ chức mạnh mẽ trong Kubernetes. Match expressions cung cấp nhiều operators hơn match labels. Dùng `-l` flag để filter/delete resources theo labels.

---

**Tóm tắt:** Match expressions hỗ trợ In, NotIn, Exists, DoesNotExist operators. Dùng `-l` flag để filter/delete resources theo labels. Labels giúp tổ chức resources theo environment, version, team, etc.
