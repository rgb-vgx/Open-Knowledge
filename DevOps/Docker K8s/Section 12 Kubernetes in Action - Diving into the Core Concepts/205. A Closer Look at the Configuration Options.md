# Tổng Quan Các Tùy Chọn Configuration Trong Kubernetes

Kubernetes cung cấp vô số tùy chọn configuration. Hãy cùng điểm qua các tùy chọn quan trọng nhất mà bạn sẽ dùng thường xuyên.

## Image Pull Policy

Điều khiển khi nào Kubernetes pull image:

```yaml
containers:
- name: my-app
  image: my-app:latest
  imagePullPolicy: Always
```

| Value | Ý nghĩa |
|-------|---------|
| `Always` | Luôn pull image (mặc định nếu dùng tag `latest`) |
| `IfNotPresent` | Chỉ pull nếu chưa có (mặc định nếu dùng tag cụ thể) |
| `Never` | Không pull, chỉ dùng local image |

> **Lưu ý quan trọng:** Nếu dùng tag `latest` mà không set `imagePullPolicy: Always`, Kubernetes có thể không detect thay đổi image mới.

## Environment Variables

```yaml
containers:
- name: my-app
  image: my-app:latest
  env:
  - name: DATABASE_URL
    value: "mongodb://mongo:27017"
  - name: API_KEY
    valueFrom:
      secretKeyRef:
        name: my-secret
        key: api-key
```

Hoặc từ ConfigMaps:

```yaml
env:
- name: CONFIG_VALUE
  valueFrom:
    configMapKeyRef:
      name: my-config
      key: config-key
```

## Resource Requests & Limits

```yaml
containers:
- name: my-app
  image: my-app:latest
  resources:
    requests:
      memory: "64Mi"
      cpu: "250m"
    limits:
      memory: "128Mi"
      cpu: "500m"
```

- **requests**: Tài nguyên tối thiểu cần thiết
- **limits**: Tài nguyên tối đa được phép sử dụng

> CPU unit: `100m` = 0.1 CPU core. `1` = 1 full CPU core.

## Command & Arguments

```yaml
containers:
- name: my-app
  image: my-app:latest
  command: ["/bin/sh"]
  args: ["-c", "echo hello"]
```

Tương tự `ENTRYPOINT` và `CMD` trong Dockerfile.

## Ports

```yaml
containers:
- name: my-app
  image: my-app:latest
  ports:
  - containerPort: 8080
    name: http
    protocol: TCP
```

## Volume Mounts (Preview)

```yaml
containers:
- name: my-app
  image: my-app:latest
  volumeMounts:
  - name: config-volume
    mountPath: /etc/config
```

Sẽ cover chi tiết hơn trong phần Volumes.

## Kết luận

Kubernetes cung cấp nhiều tùy chọn configuration từ image pull policy, environment variables, resource limits, đến command overrides. Quản lý qua YAML files giúp dễ maintain và version control.

---

**Tóm tắt:** Các tùy chọn quan trọng: imagePullPolicy, env (từ secrets/configmaps), resources (requests/limits), command/args, ports. Quản lý qua YAML files để dễ maintain và version control.
