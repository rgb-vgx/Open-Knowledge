# Exposing Deployment Với Service: Cho Phép Thế Giới Bên Ngoài Truy Cập Ứng Dụng

Bạn đã có Deployment đang chạy containers. Nhưng làm thế nào để người dùng có thể truy cập ứng dụng của bạn? Câu trả lời là tạo một **Service**.

## Tạo Service bằng kubectl expose

Cách nhanh nhất để expose một Deployment:

```bash
kubectl expose deployment first-app --port=8080 --type=LoadBalancer
```

Giải thích từng tham số:

| Tham số | Ý nghĩa |
|---------|---------|
| `deployment/first-app` | Tên deployment cần expose |
| `--port=80` | Port mà Service lắng nghe (externally) |
| `--target-port=8080` | Port mà container đang chạy (internally) |
| `--type=LoadBalancer` | Loại Service (ClusterIP, NodePort, LoadBalancer) |

> **Lưu ý:** Nếu bạn không chỉ định `--target-port`, nó sẽ mặc định cùng giá trị với `--port`. Trong ví dụ trên, nếu bỏ `--target-port=8080`, Service sẽ forward traffic đến port 8080 (vì container của bạn lắng nghe ở đó).

## Kiểm tra Service

```bash
kubectl get services
```

Output:

```
NAME         TYPE           CLUSTER-IP      EXTERNAL-IP   PORT(S)          AGE
first-app    LoadBalancer   10.96.45.123    <pending>     8080:31234/TCP   30s
kubernetes   ClusterIP      10.96.0.1       <none>        443/TCP          5m
```

### Giải thích output

- **first-app**: Service bạn vừa tạo
  - Type: LoadBalancer
  - Cluster IP: 10.96.45.123 (internal IP, không dùng được từ bên ngoài)
  - Port: 8080 (port externally) → 31234 (port trên node)
  - External IP: pending (vì Minikube không có real load balancer)

- **kubernetes**: Service mặc định của Kubernetes (tự động tạo)

## Truy cập ứng dụng với Minikube

Vì Minikube không có real load balancer, EXTERNAL-IP luôn ở trạng thái pending. Để truy cập:

```bash
minikube service first-app
```

Lệnh này sẽ:
1. Tạo tunnel từ máy cục bộ đến Service trong cluster
2. Hiển thị URL để bạn truy cập
3. Tự mở trình duyệt (nếu có thể)

Output:

```
|-----------|------------|-------------|---------------------------|
| NAMESPACE  | NAME       | TARGET PORT | URL                       |
|-----------|------------|-------------|---------------------------|
| default   | first-app  |        8080 | http://192.168.49.2:31234 |
|-----------|------------|-------------|---------------------------|
Opening http://192.168.49.2:31234 in your default browser...
```

Bây giờ bạn có thể truy cập ứng dụng Node.js của mình qua URL này.

## Kiểm tra chi tiết Service

```bash
kubectl describe service first-app
```

Output sẽ cho bạn thông tin chi tiết về endpoints, ports, và selectors.

## Kết luận

Bằng cách tạo Service, bạn đã đưa ứng dụng từ "chỉ chạy trong cluster" thành "có thể truy cập từ thế giới bên ngoài". Đây là bước quan trọng để đưa ứng dụng đến người dùng thực.

---

**Tóm tắt:** Dùng `kubectl expose deployment` để tạo Service cho Deployment. Với Minikube, dùng `minikube service <name>` để truy cập vì Minikube không có real load balancer. Service type LoadBalancer là lựa chọn phổ biến cho production.
