# Thêm Pod & Container Specs: Định Nghĩa Cách Containers Chạy

Bạn đã có skeleton của deployment.yaml. Bây giờ chúng ta sẽ thêm **spec** — phần quan trọng nhất định nghĩa cách containers chạy.

## Deployment Spec cơ bản

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: second-app-deployment
spec:
  replicas: 1
  selector:
    matchLabels:
      app: second-app
  template:
    metadata:
      labels:
        app: second-app
    spec:
      containers:
      - name: second-node
        image: your-dockerhub-username/kub-first-app
```

### Giải thích từng phần

#### replicas

```yaml
spec:
  replicas: 1
```

Số lượng Pods mặc định. Có thể thay đổi sau bằng `kubectl scale`.

#### selector

```yaml
spec:
  selector:
    matchLabels:
      app: second-app
```

**Selector** xác định哪些 Pods thuộc về Deployment này. Deployment sẽ quản lý tất cả Pods có label `app: second-app`.

> **Quan trọng:** Selector là bắt buộc. Nếu thiếu, Kubernetes sẽ báo lỗi khi apply.

#### template

```yaml
spec:
  template:
    metadata:
      labels:
        app: second-app
    spec:
      containers:
      - name: second-node
        image: your-dockerhub-username/kub-first-app
```

Template định nghĩa Pod sẽ được tạo bởi Deployment:
- **metadata.labels** — labels gắn cho Pod (phải match với selector)
- **spec.containers** — danh sách containers trong Pod

#### Container definition

```yaml
containers:
- name: second-node
  image: your-dockerhub-username/kub-first-app
```

Mỗi container cần:
- **name** — tên container (tùy bạn)
- **image** — Docker image cần chạy

## Áp dụng Deployment

```bash
kubectl apply -f deployment.yaml
```

Nếu thiếu selector, bạn sẽ thấy lỗi:

```
Error from server: error when creating "deployment.yaml": 
Deployment.apps "second-app-deployment" is invalid: 
spec.selector: Invalid value: ...
```

## Kết luận

Deployment spec gồm replicas, selector (bắt buộc), và template. Template định nghĩa Pod với containers. Selector xác định Pods thuộc về Deployment này.

---

**Tóm tắt:** Deployment spec gồm replicas (số Pods), selector (bắt buộc, xác định Pods thuộc về deployment), và template (định nghĩa Pod containers). Selector phải match labels trong template.
