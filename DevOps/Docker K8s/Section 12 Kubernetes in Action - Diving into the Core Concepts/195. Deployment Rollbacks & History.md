# Rollbacks & History: Quay Lại Phiên Bản Trước Đó

Update có vấn đề? Đừng lo — Kubernetes ghi lại lịch sử các phiên bản Deployment và cho phép bạn quay lại bất kỳ lúc nào.

## Xem lịch sử Deployments

```bash
kubectl rollout history deployment/first-app
```

```
REVISION  CHANGE-CAUSE
1         <none>
2         <none>
3         <none>
```

Mỗi revision là một phiên bản Deployment khác nhau.

## Chi tiết từng revision

```bash
kubectl rollout history deployment/first-app --revision=3
```

```
deployment.apps/first-app rolled out
# 输出 chi tiết về image, labels, annotations của revision đó
```

## Rollback về phiên bản trước

```bash
kubectl rollout undo deployment/first-app
```

Lệnh này quay lại revision trước đó (revision 2 nếu đang ở revision 3).

## Rollback về revision cụ thể

```bash
kubectl rollout undo deployment/first-app --to-revision=1
```

Quay về revision 1 — phiên bản đầu tiên.

## Ví dụ thực tế

Giả sử bạn update nhưng image tag bị sai:

```bash
kubectl set image deployment/first-app kub-first-app=wrong-tag:latest
```

Pod mới không thể start vì image không tồn tại:

```bash
kubectl get pods
# Pod ở trạng thái ImagePullBackOff hoặc ErrImagePull
```

Kiểm tra rollout status:

```bash
kubectl rollout status deployment/first-app
# Waiting for rollout to finish...
```

Hủy update ngay lập tức:

```bash
kubectl rollout undo deployment/first-app
```

Kiểm tra lại — Pods quay về phiên bản cũ hoạt động bình thường.

## Thêm "change-cause" annotations

Để lịch sử có ý nghĩa hơn, thêm annotations khi tạo deployment:

```bash
kubectl annotate deployment/first-app kubernetes.io/change-cause="Initial deployment"
```

Hoặc trong declarative YAML:

```yaml
metadata:
  annotations:
    kubernetes.io/change-cause: "Initial deployment"
```

## Xóa lịch sử revisions

```bash
kubectl rollout history deployment/first-app
kubectl rollout undo deployment/first-app --to-revision=1
```

> **Lưu ý:** Kubernetes giữ lại history revisions theo config `revisionHistoryLimit` (mặc định là 10).

## Kết luận

Rollback là tính năng救命 cho production. Khi update có vấn đề, bạn có thể quay lại phiên bản hoạt động chỉ trong vài giây. Luôn xem lịch sử trước khi rollback để chọn đúng phiên bản.

---

**Tóm tắt:** Xem lịch sử bằng `kubectl rollout history`, quay lại bằng `kubectl rollout undo`. Có thể quay về revision cụ thể bằng `--to-revision=N`. Luôn thêm change-ause annotations để dễ quản lý.
