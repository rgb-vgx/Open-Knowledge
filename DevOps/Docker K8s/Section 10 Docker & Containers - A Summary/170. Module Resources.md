## Tài Liệu Tham Khảo Nhanh

### 11. Docker Cheat Sheet

```bash
# Các lệnh Docker quan trọng nhất

# Images
docker build -t name:tag .
docker images
docker rmi image_id

# Containers
docker run -d --name name image
docker ps
docker stop container
docker rm container

# Networks
docker network create name
docker network ls

# Volumes
docker volume create name
docker volume ls

# Compose
docker compose up -d
docker compose down
docker compose ps
docker compose logs
```
