# Docker Commands Cốt Lõi: Những Lệnh Bạn Cần Ghi Nhớ

Để làm việc hiệu quả với Docker, bạn cần nắm vững một số lệnh quan trọng. Bài viết này sẽ tổng hợp các lệnh cơ bản nhất giúp bạn xây dựng, chạy và quản lý containers một cách tự tin.

## Lệnh Build Image

`docker build` là lệnh dùng để xây dựng image từ Dockerfile. Bạn cần chỉ định:

```bash
docker build -t myapp:1.0 .
```

Trong đó:
- `-t myapp:1.0`: Đặt tên và tag cho image. Tag giúp version hóa image, ví dụ `node:14`, `node:16`
- `.`: Build context - đường dẫn đến thư mục chứa Dockerfile

Hệ thống tag giúp bạn dễ dàng quản lý nhiều phiên bản của cùng một image. Ví dụ, image chính thức của Node.js có các tag `12`, `14`, `16` để đại diện cho các phiên bản khác nhau.

## Lệnh Run Container

`docker run` là lệnh quan trọng nhất để khởi chạy container từ image:

```bash
docker run --name my-container --rm -d -p 8080:80 myapp:1.0
```

**Các tùy chọn quan trọng:**
- `--name`: Đặt tên cho container
- `--rm`: Tự động xóa container khi dừng
- `-d`: Chạy ở chế độ detached (chạy nền)
- `-p`: Map port giữa host và container

Container luôn cần được tạo từ một image cụ thể, vì vậy bạn phải chỉ định tên và tag của image khi chạy.

## Lệnh Push và Pull Image

Để chia sẻ image với người khác hoặc môi trường production:

```bash
# Pull image từ Docker Hub
docker pull myapp:1.0

# Push image lên Docker Hub
docker push myusername/myapp:1.0
```

**Lưu ý quan trọng:** Tên image phải trùng với tên repository trên Docker Hub. Định dạng là `username/repository:tag`. Nếu sử dụng registry khác, bạn cần cung cấp URL đầy đủ.

## Lệnh Quản Lý Container

```bash
# Liệt kê các container đang chạy
docker ps

# Liệt kê tất cả container (bao gồm đã dừng)
docker ps -a

# Dừng container
docker stop my-container

# Xóa container
docker rm my-container

# Xem log của container
docker logs my-container

# Thực thi lệnh trong container đang chạy
docker exec -it my-container /bin/bash
```

## Lệnh Quản Lý Image

```bash
# Liệt kê các image trên máy
docker images

# Xóa image
docker rmi myapp:1.0

# Xóa tất cả image không sử dụng
docker image prune
```

## Lệnh Docker System

```bash
# Xem thông tin hệ thống Docker
docker system df

# Xóa tất cả resource không sử dụng
docker system prune
```

## Best Practices Khi Sử Dụng Lệnh

1. **Luôn sử dụng tag cụ thể** thay vì `latest` để đảm bảo tính reproducible
2. **Sử dụng `--rm`** khi chạy container tạm thời để tránh tích tụ container thừa
3. **Sử dụng `-d`** cho các container chạy dài hạn
4. **Luôn check `docker ps`** trước khi chạy để tránh conflict tên

## Tóm Tắt

Các lệnh Docker cơ bản được chia thành:
- **Build**: `docker build` để tạo image
- **Run**: `docker run` để khởi chạy container
- **Share**: `docker push` và `docker pull` để chia sẻ image
- **Manage**: `docker ps`, `docker stop`, `docker rm` để quản lý container

Nắm vững các lệnh này, bạn sẽ có nền tảng vững chắc để làm việc với Docker trong mọi tình huống.
