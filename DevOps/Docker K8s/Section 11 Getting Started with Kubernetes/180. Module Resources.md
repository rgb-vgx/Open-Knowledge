## Công Cụ Thực Hành

### Minikube — Cluster Local
```bash
# Cài đặt Minikube
minikube start

# Kiểm tra cluster
kubectl get nodes
```

Minikube tạo cluster Kubernetes trên máy cá nhân, lý tưởng cho việc học và test.

### kubectl — Công Cú CLI
kubectl là công cụ chính để tương tác với Kubernetes:
```bash
# Xem pods
kubectl get pods

# Triển khai deployment
kubectl apply -f deployment.yaml

# Xem logs
kubectl logs <pod-name>
```

### Docker Desktop
Docker Desktop tích hợp Kubernetes, giúp bạn chạy cluster local mà không cần cài đặt thêm.
