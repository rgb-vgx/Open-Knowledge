# Triển khai Frontend lên Kubernetes

Chuyển Frontend từ Docker local lên Kubernetes cluster.

## Kiến trúc hoàn chỉnh

```
┌────────────────────────────────────────────────────────────┐
│                    Internet / Users                         │
└─────────────────────────────┬──────────────────────────────┘
                              │
                              ▼
┌────────────────────────────────────────────────────────────┐
│                   Kubernetes Cluster                        │
│                                                             │
│  ┌─────────────────┐                                       │
│  │ Frontend Service│  (LoadBalancer - port 80)             │
│  │   ┌──────────┐  │                                       │
│  │   │ Frontend │  │◀──── Users truy cập                   │
│  │   │  (Nginx) │  │                                       │
│  │   └──────────┘  │                                       │
│  └─────────────────┘                                       │
│          │                                                  │
│          │  → API calls                                    │
│          ▼                                                  │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐                 │
│  │ Tasks    │  │ Users    │  │ Auth     │                 │
│  │ Service  │  │ Service  │  │ Service  │                 │
│  └──────────┘  └──────────┘  └──────────┘                 │
└────────────────────────────────────────────────────────────┘
```

## Bước 1: Tạo Frontend Deployment

Tạo file `kubernetes/frontend-deployment.yaml`:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: frontend-deployment
spec:
  replicas: 1
  selector:
    matchLabels:
      app: frontend
  template:
    metadata:
      labels:
        app: frontend
    spec:
      containers:
        - name: frontend
          image: your-dockerhub/kub-demo-frontend:latest
```

## Bước 2: Tạo Frontend Service

Tạo file `kubernetes/frontend-service.yaml`:

```yaml
apiVersion: v1
kind: Service
metadata:
  name: frontend-service
spec:
  type: LoadBalancer
  selector:
    app: frontend
  ports:
    - port: 80
      targetPort: 80
      protocol: TCP
```

## Bước 3: Push Image

```bash
# Đảm bảo repository tồn tại trên Docker Hub
# Tên: kub-demo-frontend

docker push your-dockerhub/kub-demo-frontend
```

## Bước 4: Apply

```bash
cd kubernetes

kubectl apply -f frontend-deployment.yaml
kubectl apply -f frontend-service.yaml
```

## Bước 5: Verify và truy cập

```bash
# Kiểm tra pods
kubectl get pods
# NAME                            READY   STATUS    RESTARTS   AGE
# frontend-deployment-xxx-yyy     1/1     Running   0          30s

# Lấy URL
minikube service frontend-service
```

Truy cập URL trong browser — Frontend React sẽ load!

## Kiểm tra hoạt động

```
1. Mở browser → Frontend load thành công
2. Click "Fetch Tasks" → Không có task nào (mới redeploy)
3. Click "Add Task" → Thêm task mới
4. Click "Fetch Tasks" → Hiển thị task vừa thêm
```

**Tuy nhiên** vẫn có vấn đề: URL backend bị hardcode trong Frontend code. Giải pháp ở bài tiếp theo!
