# Giao tiếp nội bộ Pod: Sử dụng localhost

Đây là networking concept quan trọng nhất trong Kubernetes: Container trong cùng Pod giao tiếp qua `localhost`.

## Cơ chế hoạt động

```
┌──────────────────────────────────┐
│              Pod                 │
│  ┌──────────┐    ┌──────────┐   │
│  │ Users API│───▶│ Auth API │   │
│  │ (8080)   │    │  (80)    │   │
│  └──────────┘    └──────────┘   │
│         │              │        │
│         └──── localhost ────────┘
└──────────────────────────────────┘
```

Container trong cùng Pod:
- **Chia sẻ Network Namespace** — Cùng localhost
- **Giao tiếp trực tiếp** qua port của Container kia
- **Không cần Service** — Đơn giản và nhanh

## Cấu hình Kubernetes

Trong `users-deployment.yaml`, thêm Environment Variable:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: users-deployment
spec:
  replicas: 1
  selector:
    matchLabels:
      app: users
  template:
    metadata:
      labels:
        app: users
    spec:
      containers:
        - name: users
          image: your-dockerhub/kub-demo-users:latest
          env:
            - name: AUTH_ADDRESS
              value: "localhost"  #的关键!
        - name: auth
          image: your-dockerhub/kub-demo-auth:latest
```

## Code sử dụng

```javascript
// users-app.js
const AUTH_ADDRESS = process.env.AUTH_ADDRESS || 'auth';

// Signup
app.post('/signup', async (req, res) => {
  const response = await axios.post(`http://${AUTH_ADDRESS}/signup`, {
    password: hashedPassword
  });
});

// Login
app.post('/login', async (req, res) => {
  const response = await axios.post(`http://${AUTH_ADDRESS}/login`, {
    password: hashedPassword
  });
});
```

## Apply và Test

```bash
# Apply deployment
kubectl apply -f users-deployment.yaml

# Kiểm tra pods
kubectl get pods
# NAME                          READY   STATUS    RESTARTS   AGE
# users-deployment-xxx-yyy      2/2     Running   0          10s

# Test với Minikube
minikube service users-service
```

## Verify hoạt động

```bash
# POST request đến /signup
curl -X POST <minikube-url>/signup \
  -H "Content-Type: application/json" \
  -d '{"email":"test@test.com","password":"123"}'

# Response: User created (chứng tỏ auth service hoạt động)
```

Token `'abc'` trong response đến từ Auth API — proof rằng localhost communication hoạt động!

## Lưu ý quan trọng

- **Chỉ dùng được khi Container cùng Pod** — Không hoạt động giữa các Pod
- **Đơn giản nhất** — Không cần DNS, không cần IP lookup
- **Phù hợp khi**: Container tightly coupled, gần nhau
