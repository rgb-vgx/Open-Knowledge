# Reverse Proxy cho Frontend: Mẫu Nginx trong Kubernetes

Hardcode URL backend trong Frontend code không lý tưởng. Reverse Proxy giải quyết vấn đề này.

## Reverse Proxy là gì?

Reverse proxy **chuyển tiếp request** từ client đến backend server:

```
Browser → Frontend Server (Nginx) → Backend Service
         /api/tasks                  tasks-service:8000
```

## Cấu hình Nginx

Sửa file `nginx.conf` trong thư mục frontend:

```nginx
server {
    listen 80;
    
    # Serve Frontend React app
    location / {
        root /usr/share/nginx/html;
        index index.html;
        try_files $uri $uri/ /index.html;
    }
    
    # Reverse proxy đến Tasks Service
    location /api/ {
        proxy_pass http://tasks-service.default:8000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### Giải thích

- `location /` — Phục vụ Frontend React app
- `location /api/` — Chuyển tiếp request đến Tasks Service
- `proxy_pass http://tasks-service.default:8000/` — Backend address
- DNS name `tasks-service.default` — CoreDNS tự động resolve

## Cập nhật Frontend Code

```javascript
// src/App.js
// Thay thế hardcode URL
const API_BASE = '/api';

// Fetch tasks
const fetchTasks = async () => {
  const response = await fetch(`${API_BASE}/tasks`, {
    headers: { 'Authorization': 'Bearer abc' }
  });
};

// Add task
const addTask = async (task) => {
  const response = await fetch(`${API_BASE}/tasks`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': 'Bearer abc'
    },
    body: JSON.stringify(task)
  });
};
```

## Lợi ích của Reverse Proxy

| Tính năng | Mô tả |
|-----------|-------|
| **Không hardcode** | Frontend không cần biết URL backend |
| **DNS resolution** | CoreDNS tự động resolve tên service |
| **Bảo mật** | Backend không expose trực tiếp |
| **Linh hoạt** | Dễ thay đổi backend |
| **Production-ready** | Pattern phổ biến trong industry |

## Lưu ý quan trọng

```nginx
# Cần trailing slash sau /api/
location /api/ {
    proxy_pass http://tasks-service.default:8000/;
}

# KHÔNG được
location /api {
    proxy_pass http://tasks-service.default:8000;
}
```

Trailing slash đảm bảo path được forward đúng!
