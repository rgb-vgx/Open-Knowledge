# Tạo nhiều Deployment: Quản lý Pod riêng biệt

Sau khi hoàn thành Pod-internal communication, bây giờ chúng ta sẽ tách Auth API ra Pod riêng và triển khai Tasks API.

## Kiến trúc mới

```
┌──────────────────┐    ┌──────────────────┐    ┌──────────────────┐
│     Pod 1        │    │     Pod 2        │    │     Pod 3        │
│  ┌──────────┐    │    │  ┌──────────┐    │    │  ┌──────────┐    │
│  │ Users API│    │    │  │ Auth API │    │    │  │ Tasks API│    │
│  │  (8080)  │    │    │  │   (80)   │    │    │  │  (8000)  │    │
│  └──────────┘    │    │  └──────────┘    │    │  └──────────┘    │
└──────────────────┘    └──────────────────┘    └──────────────────┘
         │                      │                      │
         └──────────────────────┴──────────────────────┘
                          Kubernetes Network
```

## Tạo Auth Deployment

Tạo file `kubernetes/auth-deployment.yaml`:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: auth-deployment
spec:
  replicas: 1
  selector:
    matchLabels:
      app: auth
  template:
    metadata:
      labels:
        app: auth
    spec:
      containers:
        - name: auth
          image: your-dockerhub/kub-demo-auth:latest
```

## Tạo Auth Service (ClusterIP)

Vì Auth API **không nên truy cập từ bên ngoài**, sử dụng ClusterIP:

```yaml
apiVersion: v1
kind: Service
metadata:
  name: auth-service
spec:
  type: ClusterIP  # Chỉ nội bộ cluster
  selector:
    app: auth
  ports:
    - port: 80
      targetPort: 80
```

## Cập nhật Users Deployment

Xóa container auth khỏi Users deployment:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: users-deployment
spec:
  replicas: 1
  selector:
    matchLabels:
      app: users
  template:
    metadata:
      labels:
        app: users
    spec:
      containers:
        - name: users
          image: your-dockerhub/kub-demo-users:latest
          env:
            - name: AUTH_ADDRESS
              value: "auth-service.default"  # DNS name!
```

## Áp dụng tất cả

```bash
# Apply Auth deployment
kubectl apply -f auth-deployment.yaml
kubectl apply -f auth-service.yaml

# Apply Users deployment (updated)
kubectl apply -f users-deployment.yaml

# Kiểm tra
kubectl get pods
kubectl get services
```
