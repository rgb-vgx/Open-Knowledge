# Pod-to-Pod Communication: IP Address và Environment Variables

Khi Pod ở xa nhau, làm thế nào để chúng giao tiếp? Có 3 cách — và đây là 2 cách đầu tiên.

## Cách 1: Sử dụng IP Address của Service

Mỗi Service có một IP ổn định duy nhất trong cluster.

### Tìm IP của Auth Service

```bash
kubectl get services
# NAME           TYPE        CLUSTER-IP      EXTERNAL-IP   PORT(S)   AGE
# auth-service   ClusterIP   10.96.100.200   <none>        80/TCP    5m
```

IP `10.96.100.200` là IP ổn định — không thay đổi dù Pod có restart.

### Sử dụng trong Code

```javascript
// Thay thế localhost bằng IP thực
const AUTH_ADDRESS = '10.96.100.200';
const response = await axios.post(`http://${AUTH_ADDRESS}/login`, { ... });
```

### Ưu/Nhược điểm

| Ưu điểm | Nhược điểm |
|----------|------------|
| Ổn định | Phải lookup thủ công |
| Đơn giản | Khó maintain khi scale |
| Hoạt động mọi ngôn ngữ | Hardcode trong code |

## Cách 2: Environment Variables tự động

Kubernetes **tự động tạo** env variables cho mỗi Service:

```bash
# Xem env variables trong Pod
kubectl exec <pod-name> -- printenv | grep SERVICE
```

### Mẫu env variable

```
<TEN-TEN>_<SERVICE-NAME>_SERVICE_HOST=<IP>
<TEN-TEN>_<SERVICE-NAME>_SERVICE_PORT=<PORT>
```

Ví dụ:
```
AUTH_SERVICE_HOST=10.96.100.200
AUTH_SERVICE_PORT=80
USERS_SERVICE_HOST=10.96.100.201
USERS_SERVICE_PORT=8080
```

### Sử dụng trong Node.js

```javascript
// Users API - Login route
app.post('/login', async (req, res) => {
  // Sử dụng env variable tự động của Kubernetes
  const authHost = process.env.AUTH_SERVICE_HOST;
  const authPort = process.env.AUTH_SERVICE_PORT;
  
  const response = await axios.post(
    `http://${authHost}:${authPort}/login`,
    { password: hashedPassword }
  );
});
```

### Ưu/Nhược điểm

| Ưu điểm | Nhược điểm |
|----------|------------|
| Tự động | Đặt tên phức tạp |
| Không hardcode IP | Tên service phải match |
| Hoạt động mọi ngôn ngữ | Order dependency |

## Áp dụng

```bash
# Cập nhật code users-app.js
# Rebuild image
docker build -t your-dockerhub/kub-demo-users .
docker push your-dockerhub/kub-demo-users

# Delete và recreate deployment
kubectl delete -f users-deployment.yaml
kubectl apply -f users-deployment.yaml
```
