# Sử dụng DNS (CoreDNS) cho Pod-to-Pod Communication

Cách tốt nhất để Pods giao tiếp với nhau: **Sử dụng DNS name tự động**.

## CoreDNS trong Kubernetes

Kubernetes đi kèm **CoreDNS** — DNS server nội bộ cluster. CoreDNS:

- **Tự động tạo domain name** cho mỗi Service
- **Quản lý bởi Kubernetes** — Không cần cấu hình thủ công
- **Resolution nhanh** — Pods truy cập Services qua tên DNS

## Mẫu DNS name

```
<service-name>.<namespace>.svc.cluster.local
```

Hoặc ngắn hơn (cùng namespace):
```
<service-name>
```

Ví dụ:
```
# Full name
auth-service.default.svc.cluster.local

# Short name (cùng namespace)
auth-service
```

## Sử dụng trong Code

```javascript
// users-app.js - Signup route
app.post('/signup', async (req, res) => {
  const response = await axios.post(
    `http://auth-service/signup`,  // DNS name!
    { password: hashedPassword }
  );
});

// Login route
app.post('/login', async (req, res) => {
  const response = await axios.post(
    `http://auth-service/login`,  // DNS name!
    { password: hashedPassword }
  );
});
```

## Namespace là gì?

Namespace cho phép nhóm các Resources:

```bash
# Xem namespaces
kubectl get namespaces
# NAME              STATUS   AGE
# default           Active   1h
# kube-system       Active   1h
```

Services và Deployments mặc định thuộc namespace `default`.

## Ưu điểm của DNS

| Tính năng | Mô tả |
|-----------|-------|
| **Dễ nhớ** | Tên rõ nghĩa, không phải số |
| **Ổn định** | Tên không thay đổi |
| **Tự động** | Kubernetes quản lý |
| **Linh hoạt** | Hoạt động mọi ngôn ngữ |
| **Cross-namespace** | Có thể truy cập service khác namespace |

## Áp dụng

```bash
# Cập nhật code
# Rebuild và push
docker build -t your-dockerhub/kub-demo-users .
docker push your-dockerhub/kub-demo-users

# Apply
kubectl apply -f users-deployment.yaml

# Test
minikube service users-service
```

## So sánh 3 cách

| Cách | Ưu điểm | Nhược điểm |
|------|----------|------------|
| **IP Address** | Đơn giản | Hardcode, khó maintain |
| **Env Variables** | Tự động | Tên phức tạp |
| **DNS Name** ✅ | Dễ nhớ, ổn định | Cần CoreDNS hoạt động |

**Khuyến nghị**: Sử dụng DNS name là cách phổ biến và tốt nhất!
