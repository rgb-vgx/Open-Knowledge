# Giải pháp: Triển khai Tasks API trên Kubernetes

Giải pháp chi tiết cho thử thách triển khai Tasks API.

## Bước 1: Cập nhật Tasks API Code

Thay thế hardcode auth address bằng environment variable:

```javascript
// tasks-app.js
const AUTH_ADDRESS = process.env.AUTH_ADDRESS || 'auth';

app.post('/tasks', async (req, res) => {
  const token = req.headers.authorization?.split(' ')[1];
  
  // Gọi auth service qua DNS
  const response = await axios.post(
    `http://${AUTH_ADDRESS}/token/verify`,
    { token }
  );
  // ...
});
```

## Bước 2: Tạo Deployment YAML

Tạo file `kubernetes/tasks-deployment.yaml`:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: tasks-deployment
spec:
  replicas: 1
  selector:
    matchLabels:
      app: tasks
  template:
    metadata:
      labels:
        app: tasks
    spec:
      containers:
        - name: tasks
          image: your-dockerhub/kub-demo-tasks:latest
          env:
            - name: AUTH_ADDRESS
              value: "auth-service"  # DNS name
            - name: TASKS_FOLDER
              value: "/tasks"
```

## Bước 3: Tạo Service YAML

Tạo file `kubernetes/tasks-service.yaml`:

```yaml
apiVersion: v1
kind: Service
metadata:
  name: tasks-service
spec:
  type: LoadBalancer
  selector:
    app: tasks
  ports:
    - port: 8000
      targetPort: 8000
      protocol: TCP
```

## Bước 4: Build và Push Image

```bash
cd tasks-api

# Tạo repository trên Docker Hub: kub-demo-tasks

# Build image
docker build -t your-dockerhub/kub-demo-tasks .

# Push image
docker push your-dockerhub/kub-demo-tasks
```

## Bước 5: Apply lên Kubernetes

```bash
cd kubernetes

# Apply tasks deployment
kubectl apply -f tasks-deployment.yaml

# Apply tasks service
kubectl apply -f tasks-service.yaml
```

## Bước 6: Verify

## Bước 7: Test

```bash
# Lấy URL của Tasks Service
minikube service tasks-service

# POST tạo task mới
curl -X POST <tasks-url>/tasks \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer abc" \
  -d '{"title":"Task 1","text":"Mô tả task"}'

# GET lấy danh sách tasks
curl -X GET <tasks-url>/tasks \
  -H "Authorization: Bearer abc"
```
