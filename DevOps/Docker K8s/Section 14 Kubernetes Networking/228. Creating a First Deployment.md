# Tạo Deployment Đầu tiên trên Kubernetes: Hướng dẫn từng bước

Bắt đầu hành trình Networking với Deployment đầu tiên cho Users API.

## Chuẩn bị

```bash
# Kiểm tra Minikube
minikube status

# Đảm bảo không có Deployment nào đang chạy
kubectl get deployments

# Kiểm tra Services
kubectl get services
```

## Bước 1: Chỉnh sửa Code

Trước khi deploy,我们需要 tạm thời vô hiệu hóa kết nối đến Auth API trong `users-app.js`:

```javascript
// Signup route - Thay thế axios request bằng dummy data
app.post('/signup', (req, res) => {
  const { email, password } = req.body;
  // Dummy response thay vì gọi auth service
  const hashedPassword = 'dummy-hashed-password';
  res.status(201).json({ message: 'User created', userId: '1' });
});

// Login route - Thay thế bằng dummy response
app.post('/login', (req, res) => {
  const response = {
    status: { code: 200 },
    data: { token: 'dummy-token' }
  };
  res.json(response);
});
```

## Bước 2: Build và Push Image

```bash
# Tạo repository trên Docker Hub
# Tên: kub-demo-users

# Build image
docker build -t your-dockerhub/kub-demo-users .

# Push lên Docker Hub
docker push your-dockerhub/kub-demo-users
```

## Bước 3: Tạo Deployment YAML

Tạo file `kubernetes/users-deployment.yaml`:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: users-deployment
spec:
  replicas: 1
  selector:
    matchLabels:
      app: users
  template:
    metadata:
      labels:
        app: users
    spec:
      containers:
        - name: users
          image: your-dockerhub/kub-demo-users:latest
```

## Bước 4: Apply Deployment

```bash
cd kubernetes
kubectl apply -f users-deployment.yaml
```

## Verification

```bash
kubectl get deployments
kubectl get pods
```

Bạn sẽ thấy một Pod đang chạy với container `users`. Deployment đã sẵn sàng — tiếp theo là Service!
