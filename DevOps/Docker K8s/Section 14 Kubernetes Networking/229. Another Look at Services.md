# Kubernetes Service: ClusterIP, NodePort và LoadBalancer

Services là đối tượng cốt lõi trong mạng Kubernetes. Hãy cùng tìm hiểu cách sử dụng chúng.

## Tại sao cần Service?

Pod có IP address, nhưng IP này **thay đổi** khi Pod bị xóa hoặc di chuyển. Service giải quyết vấn đề này bằng cách:

1. **Cung cấp IP ổn định** — Không thay đổi dù Pod có restart
2. **Cho phép truy cập từ bên ngoài** — Configure loại Service phù hợp
3. **Load balancing** — Tự động phân phối request đến các Pod

## Các loại Service chính

### 1. ClusterIP (Mặc định)

```yaml
apiVersion: v1
kind: Service
metadata:
  name: auth-service
spec:
  type: ClusterIP  # Mặc định, có thể bỏ qua
  selector:
    app: auth
  ports:
    - port: 80
      targetPort: 80
```

- **Chỉ truy cập được từ trong cluster**
- Phù hợp cho services nội bộ (Auth API, Database)
- Kubernetes tự động load balance

### 2. NodePort

```yaml
apiVersion: v1
kind: Service
metadata:
  name: users-service
spec:
  type: NodePort
  selector:
    app: users
  ports:
    - port: 8080
      targetPort: 8080
      nodePort: 30080  # Port trên mỗi Node (30000-32767)
```

- **Truy cập qua IP của Node** trên port cụ thể
- Hạn chế: Port range giới hạn (30000-32767)
- Phù hợp cho development/testing

### 3. LoadBalancer

```yaml
apiVersion: v1
kind: Service
metadata:
  name: users-service
spec:
  type: LoadBalancer
  selector:
    app: users
  ports:
    - port: 8080
      targetPort: 8080
```

- **Tạo IP bên ngoài ổn định** (Cloud provider hoặc MetalLB)
- Load balance trên toàn cluster
- Phù hợp cho production

## So sánh các loại Service

| Tính năng | ClusterIP | NodePort | LoadBalancer |
|-----------|-----------|----------|--------------|
| Truy cập bên ngoài | ❌ | ✅ | ✅ |
| IP ổn định | ✅ | ❌ | ✅ |
| Port range | Bất kỳ | 30000-32767 | Bất kỳ |
| Chi phí | Miễn phí | Miễn phí | Cloud LB |
| Use case | Internal | Dev/Test | Production |

## Ví dụ thực tế: Users Service

```yaml
apiVersion: v1
kind: Service
metadata:
  name: users-service
spec:
  type: LoadBalancer
  selector:
    app: users
  ports:
    - port: 8080
      targetPort: 8080
      protocol: TCP
```

Apply và test:

```bash
kubectl apply -f users-service.yaml

# Trên Minikube - lấy URL
minikube service users-service

# Test với Postman
POST <minikube-url>/login
```

## Kết luận

- **ClusterIP**: Internal services (Auth API, Database)
- **LoadBalancer**: External services (Users API, Tasks API, Frontend)
- **NodePort**: Development/testing nhanh

Tiếp theo, chúng ta sẽ探讨 cách Container giao tiếp nội bộ Pod!
