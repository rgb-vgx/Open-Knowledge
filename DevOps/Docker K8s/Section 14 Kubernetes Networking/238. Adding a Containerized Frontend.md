# Thêm Frontend React: Kết nối với Backend trên Kubernetes

Đến đây, Backend đã sẵn sàng. Giờ là lúc thêm Frontend — giao diện người dùng cho ứng dụng.

## Tổng quan Frontend

Frontend là một **React application** chạy trong browser.牠:

- Gửi request đến Backend API
- Hiển thị dữ liệu cho người dùng
- Chạy hoàn toàn trong browser (không phải trong container)

## CORS Issue

Khi chạy Frontend trên `localhost:80` và gọi API trên Minikube IP, browser chặn request do **CORS (Cross-Origin Resource Sharing)**.

### Giải pháp: Thêm CORS headers vào Backend

```javascript
// tasks-app.js
app.use((req, res, next) => {
  res.setHeader('Access-Control-Allow-Origin', '*');
  res.setHeader('Access-Control-Allow-Methods', 'GET,POST,PUT,DELETE,PATCH');
  res.setHeader('Access-Control-Allow-Headers', 'Content-Type,Authorization');
  next();
});
```

## Code Frontend

```javascript
// src/App.js
const TASKS_URL = 'http://<minikube-ip>:8000';

// Fetch tasks
const fetchTasks = async () => {
  const response = await fetch(`${TASKS_URL}/tasks`, {
    headers: {
      'Authorization': 'Bearer abc'
    }
  });
  const data = await response.json();
  setTasks(data.tasks);
};

// Add task
const addTask = async (task) => {
  const response = await fetch(`${TASKS_URL}/tasks`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': 'Bearer abc'
    },
    body: JSON.stringify(task)
  });
};
```

## Build Docker Image

Frontend sử dụng **multi-stage build** với Nginx:

```dockerfile
# Frontend Dockerfile
FROM node:alpine AS build
WORKDIR /app
COPY package*.json .
RUN npm install
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=build /app/build /usr/share/nginx/html
COPY nginx.conf /etc/nginx/nginx.conf
EXPOSE 80
```

## Chạy thử

```bash
cd frontend

# Build image
docker build -t your-dockerhub/kub-demo-frontend .

# Chạy container locally
docker run -p 80:80 --rm -d your-dockerhub/kub-demo-frontend
```

Truy cập `http://localhost` trong browser — Frontend sẽ load!
