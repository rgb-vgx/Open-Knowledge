# Nhiều Container trong một Pod: Nhóm Container liên quan

Khi nào nên đặt nhiều Container trong cùng một Pod? Và làm thế nào để chúng giao tiếp?

## Nguyên tắc Pod-Internal Container

Hai Container trong cùng một Pod:
- **Chia sẻ Network namespace** — Cùng IP, cùng ports
- **Có thể giao tiếp qua localhost**
- **Chia sẻ Storage Volumes** (nếu cần)

## Khi nào sử dụng Multi-Container Pod?

Chỉ sử dụng khi Container **tightly coupled**:

```
✅ Nên: Sidecar pattern (logging, monitoring)
✅ Nên: Ambassador pattern (proxy)
❌ Không nên: Container độc lập, riêng biệt
```

## Cấu trúc Pod với Users API + Auth API

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: users-deployment
spec:
  replicas: 1
  selector:
    matchLabels:
      app: users
  template:
    metadata:
      labels:
        app: users
    spec:
      containers:
        - name: users
          image: your-dockerhub/kub-demo-users:latest
        - name: auth
          image: your-dockerhub/kub-demo-auth:latest
```

## Bước thực hiện

### 1. Build Auth API Image

```bash
cd auth-api
docker build -t your-dockerhub/kub-demo-auth .
docker push your-dockerhub/kub-demo-auth
```

### 2. Cập nhật Users API Code

Thay thế dummy data bằng axios request thực:

```javascript
// Signup - Gọi auth service thật
const response = await axios.post(`http://auth/signup`, {
  password: hashedPassword
});

// Login - Gọi auth service thật
const response = await axios.post(`http://auth/login`, {
  password: hashedPassword
});
```

### 3. Sử dụng Environment Variable

Thay vì hardcode `http://auth`, sử dụng env variable:

```javascript
const AUTH_ADDRESS = process.env.AUTH_ADDRESS || 'auth';
```

### 4. Cập nhật Docker Compose (cho development)

```yaml
services:
  users-service:
    environment:
      - AUTH_ADDRESS=auth
```

### 5. Apply lên Kubernetes

```bash
# Rebuild users image
docker build -t your-dockerhub/kub-demo-users .
docker push your-dockerhub/kub-demo-users

# Apply deployment
kubectl apply -f users-deployment.yaml
```

## Kiểm tra

```bash
kubectl get pods
# NAME                          READY   STATUS    RESTARTS   AGE
# users-deployment-xxx-yyy      2/2     Running   0          30s
```

`2/2` nghĩa là cả 2 Container đều đang chạy. Tiếp theo là cách giao tiếp qua localhost!
