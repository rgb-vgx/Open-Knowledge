# Dự án Demo: Xây dựng 3 Microservices API trên Kubernetes

Trước khi bắt đầu với Networking, hãy cùng tìm hiểu dự án demo mà chúng ta sẽ xây dựng trong Module này.

## Kiến trúc ứng dụng

Ứng dụng demo gồm **3 Backend API** được viết bằng Node.js:

| API | Chức năng | Port |
|-----|-----------|------|
| **Auth API** | Xác thực Token, tạo Token cho user | 80 |
| **Users API** | Đăng ký, đăng nhập user | 8080 |
| **Tasks API** | Quản lý danh sách công việc | 8000 |

### Luồng hoạt động

```
Client → Users API → Auth API (tạo Token)
Client → Tasks API → Auth API (xác thực Token)
```

## Cấu trúc Pod ban đầu

```
┌─────────────────────────┐    ┌──────────────────┐
│       Pod 1             │    │      Pod 2       │
│  ┌──────────┐           │    │                  │
│  │ Users API│           │    │    Tasks API     │
│  └──────────┘           │    │                  │
│  ┌──────────┐           │    └──────────────────┘
│  │ Auth API │           │
│  └──────────┘           │
└─────────────────────────┘
```

- **Pod 1**: Chứa Users API + Auth API (giao tiếp nội bộ Pod)
- **Pod 2**: Chứa Tasks API (giao tiếp với Auth API qua Network)

## Chạy thử với Docker Compose

```bash
docker-compose up -d --build
```

Sử dụng Postman để test:
- `POST localhost:8080/login` — Đăng nhập
- `POST localhost:8080/signup` — Đăng ký
- `GET localhost:8002/tasks` — Lấy danh sách tasks

> **Lưu ý**: Khi chạy `docker-compose down`, toàn bộ dữ liệu sẽ mất vì chúng ta không sử dụng Volume. Đây là ứng dụng demo, không tập trung vào lưu trữ dữ liệu.

## Mục tiêu cuối cùng

Sau khi hoàn thành Module này, bạn sẽ có:

- 3 Deployment riêng biệt trên Kubernetes
