# hostPath Volume trong Kubernetes: Chia sẻ dữ liệu giữa các Pods

## Vấn đề với emptyDir khi có nhiều Replicas

Khi bạn scale replicas lên nhiều (ví dụ 2 pods), mỗi pod sẽ có **volume riêng biệt** với `emptyDir`. Nếu request gửi đến pod A nhưng dữ liệu ghi ở pod B, bạn sẽ không đọc được.

Giải pháp? Dùng `hostPath` — cho phép nhiều pods chia sẻ cùng một thư mục trên host machine.

## hostPath hoạt động thế nào?

`hostPath` mount một thư mục cụ thể trên **worker node** (host machine) vào container. Nhiều pods chạy trên cùng node có thể truy cập cùng một đường dẫn này.

```yaml
volumes:
  - name: story-volume
    hostPath:
      path: /data/story
      type: DirectoryOrCreate
```

**Giải thích:**
- `path` — đường dẫn trên host machine (không phải trong container)
- `type: DirectoryOrCreate` — tự tạo thư mục nếu chưa tồn tại

## So sánh emptyDir vs hostPath

| emptyDir | hostPath |
|---|---|
| Mỗi pod có thư mục riêng | Nhiều pods chia sẻ cùng thư mục trên node |
| Luôn tạo mới thư mục trống | Có thể dùng thư mục đã có sẵn dữ liệu |
| Dữ liệu mất khi pod xóa | Dữ liệu tồn tại trên host, không mất khi pod xóa |
| Đơn giản, không cần cấu hình | Cần chỉ rõ path trên host |

## Cấu hình đầy đủ

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: story-deployment
spec:
  replicas: 2
  selector:
    matchLabels:
      app: story
  template:
    metadata:
      labels:
        app: story
    spec:
      containers:
        - name: story
          image: your-dockerhub/kub-data-demo:1
          volumeMounts:
            - name: story-volume
              mountPath: /app/story
      volumes:
        - name: story-volume
          hostPath:
            path: /data/story
            type: DirectoryOrCreate
```

## Hạn chế của hostPath

hostPath **vẫn có vấn đề lớn:** nó chỉ hoạt động trên **một node duy nhất**. Nếu cluster có nhiều worker nodes, pods chạy trên node khác nhau sẽ không thể chia sẻ dữ liệu. Trong Minikube (1 node) thì hoạt động tốt, nhưng trên production cluster thực sự thì không đủ.

Đó là lý do chúng ta cần **Persistent Volumes** — giải pháp thực sự cho bài toán lưu trữ dữ liệu trong distributed cluster.

> **Tóm tắt:** `hostPath` cải thiện hơn `emptyDir` khi nhiều pods cần chia sẻ dữ liệu trên cùng node. Nhưng nó vẫn phụ thuộc vào node cụ thể — không phù hợp cho multi-node cluster production.
