# Định nghĩa Persistent Volume trong Kubernetes

## Cấu trúc YAML của Persistent Volume

Tạo file `host-pv.yaml` để định nghĩa Persistent Volume sử dụng `hostPath` (dành cho Minikube 1-node):

```yaml
apiVersion: v1
kind: PersistentVolume
metadata:
  name: host-pv
spec:
  capacity:
    storage: 1Gi
  volumeMode: Filesystem
  accessModes:
    - ReadWriteOnce
  hostPath:
    path: /data/story
    type: DirectoryOrCreate
  storageClassName: standard
```

## Giải thích từng phần

### 1. apiVersion & kind

```yaml
apiVersion: v1
kind: PersistentVolume
```

`PersistentVolume` là một cluster-level resource, không thuộc namespace nào.

### 2. capacity — Dung lượng tối đa

```yaml
capacity:
  storage: 1Gi
```

Định nghĩa dung lượng tối đa mà PV có thể cung cấp. Các đơn vị hỗ trợ: `Ki`, `Mi`, `Gi`, `Ti`, `Pi`, `Ei` (binary) hoặc `K`, `M`, `G` (decimal).

### 3. volumeMode — Chế độ lưu trữ

```yaml
volumeMode: Filesystem
```

Hai chế độ:
- **`Filesystem`** — Mount như thư mục (phổ biến nhất)
- **`Block`** — Mount như thiết bị block (cho database...)

### 4. accessModes — Quyền truy cập

```yaml
accessModes:
  - ReadWriteOnce
```

Ba chế độ khả dụng:
- **`ReadWriteOnce` (RWO)** — Đọc/ghi, chỉ trên một node
- **`ReadOnlyMany` (ROX)** — Chỉ đọc, nhiều nodes
- **`ReadWriteMany` (RWX)** — Đọc/ghi, nhiều nodes

Lưu ý: `hostPath` chỉ hỗ trợ `ReadWriteOnce` vì bản chất chỉ hoạt động trên một node.

### 5. hostPath — Nơi lưu trữ

```yaml
hostPath:
  path: /data/story
  type: DirectoryOrCreate
```

Vì đang dùng Minikube, `hostPath` là lựa chọn thực tế. Trên production, bạn sẽ dùng cloud storage hoặc CSI driver.

### 6. storageClassName

```yaml
storageClassName: standard
```

**Bắt buộc phải có.** Kiểm tra storage class hiện có:

```bash
kubectl get sc
```

Minikube mặc định có storage class tên `standard`.

## Apply và Kiểm tra

```bash
# Tạo Persistent Volume
kubectl apply -f host-pv.yaml

# Kiểm tra
kubectl get pv
```

Kết quả sẽ hiển thị PV với status `Available` — chờ được claim bởi một PVC.

> **Tóm tắt:** Persistent Volume định nghĩa storage resource trong cluster với capacity, access mode, và storage type. Nó tồn tại độc lập và chờ pods claim qua Persistent Volume Claims.
