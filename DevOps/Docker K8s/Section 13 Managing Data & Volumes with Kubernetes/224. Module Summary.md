# Tóm tắt Module: Quản lý Dữ liệu & Volumes trong Kubernetes

## Tổng kết những gì đã học

Section này đã trang bị cho bạn kiến thức nền tảng để quản lý dữ liệu trong Kubernetes cluster. Dưới đây là tóm tắt các concept quan trọng.

## 1. Kubernetes Volumes

Volumes gắn liền với pod, giúp dữ liệu tồn tại qua các lần container restart.

**Các loại volume phổ biến:**
- `emptyDir` — Thư mục trống, đơn giản, phù hợp development
- `hostPath` — Thư mục trên host node, chia sẻ giữa pods trên cùng node
- `CSI` — Giao diện linh hoạt cho mọi loại storage bên thứ ba

**Cách sử dụng:**

```yaml
# Định nghĩa volume trong pod spec
volumes:
  - name: data
    emptyDir: {}

# Mount vào container
containers:
  - name: app
    volumeMounts:
      - name: data
        mountPath: /app/data
```

## 2. Persistent Volumes & Claims

Giải pháp storage **độc lập với pod và node** — dữ liệu không bị mất khi pod bị xóa.

**Quy trình:**

```
Admin tạo PV → Pod tạo PVC → PVC claim PV → Container mount volume
```

```yaml
# Persistent Volume
apiVersion: v1
kind: PersistentVolume
spec:
  capacity:
    storage: 1Gi
  hostPath:
    path: /data
  storageClassName: standard

# Persistent Volume Claim
apiVersion: v1
kind: PersistentVolumeClaim
spec:
  volumeName: my-pv
  resources:
    requests:
      storage: 1Gi
  storageClassName: standard

# Pod sử dụng PVC
volumes:
  - name: data
    persistentVolumeClaim:
      claimName: my-pvc
```

## 3. Environment Variables & ConfigMaps

Quản lý cấu hình ứng dụng linh hoạt:

```yaml
# Env trực tiếp
env:
  - name: KEY
    value: "value"

# Từ ConfigMap
env:
  - name: KEY
    valueFrom:
      configMapKeyRef:
        name: my-config
        key: my-key
```

## Quy tắc khi làm việc với Data trong Kubernetes

1. **Dữ liệu tạm thời** → `emptyDir` hoặc regular volumes
2. **Dữ liệu quan trọng** → Persistent Volumes
3. **Cấu hình ứng dụng** → Environment variables + ConfigMaps
4. **Sensitive data** → Secrets (không phải ConfigMaps)
5. **Production** → Cloud storage types hoặc CSI drivers

## Tiếp theo

Bạn đã có đủ kiến thức nền tảng để quản lý dữ liệu trong Kubernetes. Trong các section tiếp theo, chúng ta sẽ深入 hơn vào các chủ đề nâng cao như Secrets, StatefulSets, và Dynamic Volume Provisioning.

> **Lưu ý:** Dù Kubernetes có nhiều cách quản lý dữ liệu, nguyên tắc cốt lõi vẫn luôn là: **dữ liệu quan trọng không được phép bị mất chỉ vì container restart hay pod replacement.**
