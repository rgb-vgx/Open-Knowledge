# Tạo Deployment & Service cho ứng dụng Demo trên Kubernetes

## Bước 1: Kiểm tra trạng thái cluster

Trước khi bắt đầu, hãy đảm bảo rằng bạn không có deployment nào đang chạy:

```bash
kubectl get deployments
```

Và Minikube đang hoạt động:

```bash
minikube status
```

Nếu chưa có, khởi động lại:

```bash
minikube start
```

## Bước 2: Tạo Deployment YAML

Tạo file `deployment.yaml`:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: story-deployment
spec:
  replicas: 1
  selector:
    matchLabels:
      app: story
  template:
    metadata:
      labels:
        app: story
    spec:
      containers:
        - name: story
          image: your-dockerhub/kub-data-demo:1
```

**Giải thích:**
- `apiVersion: apps/v1` — version API cho Deployments
- `kind: Deployment` — loại resource我们要 tạo
- `selector.matchLabels` — chọn pods có label `app: story`
- `template.spec.containers` — container/image sẽ chạy trong pod

## Bước 3: Tạo Service YAML

Tạo file `service.yaml`:

```yaml
apiVersion: v1
kind: Service
metadata:
  name: story-service
spec:
  type: LoadBalancer
  selector:
    app: story
  ports:
    - protocol: TCP
      port: 80
      targetPort: 3000
```

**Lưu ý quan trọng:** Bạn **phải** thêm `type: LoadBalancer`, nếu không service chỉ được expose nội bộ trong cluster và không thể truy cập từ bên ngoài.

## Bước 4: Build, Push Image và Apply

```bash
# Build image
docker build -t your-dockerhub/kub-data-demo:1 .

# Push lên Docker Hub
docker push your-dockerhub/kub-data-demo:1

# Apply cả hai file
kubectl apply -f service.yaml
kubectl apply -f deployment.yaml

# Kiểm tra
kubectl get deployments
kubectl get pods
```

## Bước 5: Truy cập ứng dụng

```bash
minikube service story-service
```

Lệnh này sẽ trả về một URL mà bạn có thể dùng để truy cập ứng dụng. Dùng Postman hoặc curl để test GET/POST requests tới `/story`.

> **Tóm tắt:** Deployment quản lý pods và replicas. Service expose pods ra bên ngoài. Bạn cần image đã push lên Docker Hub để Kubernetes có thể pull và chạy.
