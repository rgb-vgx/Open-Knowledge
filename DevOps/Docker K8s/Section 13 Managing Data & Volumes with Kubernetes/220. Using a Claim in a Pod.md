# Sử dụng Persistent Volume Claim trong Pod

## Trước khi Apply: StorageClass

Kubernetes sử dụng concept **StorageClass** để quản lý cách storage được provisioning. Trên Minikube, đã có một StorageClass mặc định tên `standard`:

```bash
kubectl get sc
```

**Quan trọng:** Bạn phải thêm `storageClassName: standard` vào cả PV và PVC để đảm bảo chúng được liên kết đúng.

## Áp dụng toàn bộ

```bash
# Bước 1: Tạo Persistent Volume
kubectl apply -f host-pv.yaml

# Bước 2: Tạo Persistent Volume Claim
kubectl apply -f host-pvc.yaml

# Bước 3: Áp dụng Deployment (sử dụng PVC)
kubectl apply -f deployment.yaml
```

## Kiểm tra

```bash
# Kiểm tra PV - status phải là "Bound"
kubectl get pv

# Kiểm tra PVC - status cũng là "Bound"
kubectl get pvc

# Kiểm tra pods đang chạy
kubectl get pods
kubectl get deployments
```

## Truy cập ứng dụng

```bash
minikube service story-service
```

Giờ đây ứng dụng hoạt động với Persistent Volume. Dữ liệu được lưu trên host path `/data/story` thông qua PV — hoàn toàn độc lập với pod và container.

## Sự khác biệt so với hostPath trực tiếp

Trước đây, khi dùng `hostPath` trực tiếp trong pod spec:

```yaml
volumes:
  - name: story-volume
    hostPath:
      path: /data/story
```

Bây giờ, qua PVC:

```yaml
volumes:
  - name: story-volume
  persistentVolumeClaim:
    claimName: host-pvc
```

**Kết quả behave giống nhau** vì cùng dùng hostPath. Nhưng ưu điểm mới:

1. **Quản lý tập trung** — PV định nghĩa ở cấp cluster, không lặp lại trong mỗi pod spec
2. **Phân quyền rõ ràng** — Admin quản lý PV, Developer chỉ cần biết tên PVC
3. **Độc lập hơn** — Trên production với cloud storage, PV thực sự tách khỏi node

## Kiểm tra dữ liệu tồn tại

```bash
# Gửi POST request lưu dữ liệu
curl -X POST $(minikube service story-service --url)/story \
  -H "Content-Type: application/json" \
  -d '{"text": "Dữ liệu từ Persistent Volume!"}'

# Đọc dữ liệu
curl $(minikube service story-service --url)/story
```

Dữ liệu sẽ tồn tại qua các lần restart container và cả khi pod bị thay thế — đó là sức mạnh của Persistent Volumes.

> **Tóm tắt:** PV và PVC đã hoạt động. Ứng dụng giờ có dữ liệu độc lập với pod lifecycle. Trong production, bạn sẽ dùng cloud storage type thay vì hostPath để đạt node independence thực sự.
