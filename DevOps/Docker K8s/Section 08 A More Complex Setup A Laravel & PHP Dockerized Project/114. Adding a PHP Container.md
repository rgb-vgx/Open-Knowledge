# Thêm Container PHP: PHP Interpreter Cho Laravel

## Tại Sao Cần Custom Dockerfile?

Image PHP chính thức trên Docker Hub (`php:7.4-fpm-alpine`) chỉ chứa PHP cơ bản. Laravel yêu cầu thêm một số extension PHP mà image mặc định không có. Vì vậy, chúng ta cần tạo một **custom Dockerfile** để cài đặt thêm các extension cần thiết.

## Tạo PHP Dockerfile

Tạo thư mục `dockerfiles/` và file `dockerfiles/php.dockerfile`:

```dockerfile
FROM php:7.4-fpm-alpine

WORKDIR /var/www/html

RUN docker-php-ext-install pdo pdo_mysql
```

### Giải thích từng dòng

- **`FROM php:7.4-fpm-alpine`** — Image cơ sở là PHP 7.4 với FPM (FastCGI Process Manager) trên Linux Alpine. FPM là phiên bản PHP được tối ưu cho việc chạy như service backend.
- **`WORKDIR /var/www/html`** — Đặt thư mục làm việc. Đây là đường dẫn chuẩn trên web server để chứa source code.
- **`RUN docker-php-ext-install pdo pdo_mysql`** — Cài đặt extension PDO và PDO MySQL — cần thiết để PHP kết nối với MySQL database.

### Tại Sao Không Có CMD hay ENTRYPOINT?

Image PHP cơ sở đã có sẵn default command để khởi động PHP FPM interpreter. Nếu bạn không ghi đè, lệnh mặc định sẽ được sử dụng — và đó chính là điều chúng ta muốn.

## Cấu Hình Docker Compose

Thêm service PHP vào `docker-compose.yaml`:

```yaml
services:
  php:
    build:
      context: ./dockerfiles
      dockerfile: php.dockerfile
    volumes:
      - ./src:/var/www/html:delegated
```

### Giải thích

- **`build`** — Chỉ định Dockerfile để build image. `context` là thư mục chứa Dockerfile, `dockerfile` là tên file.
- **`volumes: ./src:/var/www/html:delegated`** — Bind mount thư mục `src/` trên host vào `/var/www/html` trong container. Tùy chọn `delegated` cải thiện hiệu suất bằng cách không đồng bộ ngay lập tức mỗi thay đổi.

## Thư Mục Cấu Trúc

```
project/
├── docker-compose.yaml
├── dockerfiles/
│   └── php.dockerfile
├── nginx/
│   └── nginx.conf
└── src/          ← Source code Laravel sẽ nằm ở đây
```

## Kết nối Nginx và PHP

Trong file `nginx.conf`, chúng ta đã cấu hình:

```nginx
fastcgi_pass php:9000;
```

Điều này có nghĩa Nginx sẽ gửi request PHP đến container tên `php` trên port 9000 — chính là port mà PHP-FPM mặc định lắng nghe. Vì cả hai container nằm trong cùng mạng Docker Compose, chúng có thể giao tiếp trực tiếp với nhau bằng tên service.

## Kết Luận

Container PHP đóng vai trò thực thi code Laravel. Nginx chỉ xử lý request HTTP, còn việc chạy code PHP hoàn toàn do container này đảm nhận. Sự tách biệt này giúp dễ dàng mở rộng — bạn có thể chạy nhiều instances PHP container phía sau một Nginx load balancer.
