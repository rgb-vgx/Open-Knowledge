# Thêm Container Artisan & NPM: Utility Containers Cuối Cùng

## Container Artisan

Artisan là CLI tool của Laravel, dùng để chạy migrations, seed data, tạo boilerplate code, và nhiều tác vụ khác. Vì Artisan là file PHP, chúng ta cần PHP interpreter để chạy nó.

### Cấu Hình Docker Compose

```yaml
services:
  artisan:
    build:
      context: ./dockerfiles
      dockerfile: php.dockerfile
    volumes:
      - ./src:/var/www/html:delegated
    entrypoint: ['php', '/var/www/html/artisan']
```

### Giải thích

- **Sử dụng `php.dockerfile`** — Artisan cần PHP để chạy, nên dùng chung Dockerfile với PHP container
- **`entrypoint`** — Ghi đè entrypoint để chạy lệnh `php artisan` thay vì PHP-FPM server
- **Bind mount `./src`** — Truy cập source code Laravel

## Container NPM

NPM xử lý front-end assets (JavaScript, CSS) trong Laravel. Sử dụng image Node.js:

```yaml
services:
  npm:
    image: 'node:14'
    working_dir: /var/www/html
    entrypoint: ['npm']
    volumes:
      - ./src:/var/www/html:delegated
```

### Giải thích

- **`image: 'node:14'`** — Image Node.js chính thức
- **`working_dir`** — Đặt thư mục làm việc trực tiếp trong Docker Compose (không cần Dockerfile riêng)
- **`entrypoint: ['npm']`** — Mỗi lệnh sẽ bắt đầu bằng `npm`

> **Mẹo:** Bạn có thể cấu hình `working_dir` và `entrypoint` trực tiếp trong Docker Compose mà không cần tạo Dockerfile riêng. Điều này phù hợp cho các image đơn giản.

## Sử Dụng Utility Containers

### Chạy Artisan Migration

```bash
docker compose run --rm artisan migrate
```

Lệnh này sẽ:
1. Tạo temporary container từ image PHP
2. Chạy `php artisan migrate`
3. Tự động xóa container sau khi hoàn thành

### Chạy NPM Install

```bash
docker compose run --rm npm install
```

### Chạy NPM Dev

```bash
docker compose run --rm npm run dev
```

## Tổng Hợp Docker Compose

```yaml
version: '3.8'

services:
  server:
    image: 'nginx:stable-alpine'
    ports:
      - '8000:80'
    volumes:
      - ./nginx/nginx.conf:/etc/nginx/conf.d/default.conf:ro
      - ./src:/var/www/html:delegated
    depends_on:
      - php
      - mysql

  php:
    build:
      context: ./dockerfiles
      dockerfile: php.dockerfile
    volumes:
      - ./src:/var/www/html:delegated

  mysql:
    image: 'mysql:5.7'
    env_file:
      - ./env/mysql.env

  composer:
    build:
      context: ./dockerfiles
      dockerfile: composer.dockerfile
    volumes:
      - ./src:/var/www/html:delegated

  artisan:
    build:
      context: ./dockerfiles
      dockerfile: php.dockerfile
    volumes:
      - ./src:/var/www/html:delegated
    entrypoint: ['php', '/var/www/html/artisan']

  npm:
    image: 'node:14'
    working_dir: /var/www/html
    entrypoint: ['npm']
    volumes:
      - ./src:/var/www/html:delegated
```

## Kết Luận

Với 6 container hoàn chỉnh, chúng ta đã có một môi trường phát triển Laravel chuyên nghiệp. Mỗi container đảm nhiệm một trách nhiệm riêng biệt, dễ bảo trì và mở rộng. Utility containers (Composer, Artisan, NPM) chỉ chạy khi cần, giữ cho hệ thống luôn gọn nhẹ.
