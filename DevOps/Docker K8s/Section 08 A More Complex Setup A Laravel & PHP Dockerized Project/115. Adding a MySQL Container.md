# Thêm Container MySQL: Cơ Sở Dữ Liệu Cho Laravel

## Sử Dụng Image MySQL Chính Thức

Tương tự như Nginx và PHP, Docker Hub có sẵn image MySQL chính thức. Thêm service MySQL vào `docker-compose.yaml`:

```yaml
services:
  mysql:
    image: 'mysql:5.7'
    env_file:
      - ./env/mysql.env
```

## Tại Sao Dùng File `.env`?

Thay vì hardcode thông tin đăng nhập trực tiếp trong `docker-compose.yaml`, chúng ta sử dụng file `.env` để quản lý environment variables. Đây là best practice vì:

- **Bảo mật** — Không để lộ thông tin đăng nhập trong code
- **Dễ thay đổi** — Chỉ cần sửa file `.env` khi cần thay đổi cấu hình
- **Flexible** — Mỗi môi trường (dev, staging, production) có thể có file `.env` riêng

## Tạo File Environment

Tạo thư mục `env/` và file `env/mysql.env`:

```
MYSQL_DATABASE=homestead
MYSQL_USER=homestead
MYSQL_PASSWORD=secret
MYSQL_ROOT_PASSWORD=secret
```

### Giải thích các biến môi trường

- **`MYSQL_DATABASE`** — Tên database mặc định sẽ được tạo khi container khởi động lần đầu
- **`MYSQL_USER`** — Tên người dùng database
- **`MYSQL_PASSWORD`** — Mật khẩu người dùng
- **`MYSQL_ROOT_PASSWORD`** — Mật khẩu root user của MySQL

> **Lưu ý:** Giá trị `homestead` và `secret` là values mặc định của Laravel Homestead environment. Bạn có thể thay đổi chúng tùy ý.

## Cập Nhật Docker Compose

```yaml
services:
  mysql:
    image: 'mysql:5.7'
    env_file:
      - ./env/mysql.env
```

## Kết nối Laravel Với MySQL

Sau khi tạo Laravel project (sẽ thực hiện ở phần sau), bạn cần cập nhật file `.env` của Laravel để kết nối đúng database:

```
DB_CONNECTION=mysql
DB_HOST=mysql
DB_PORT=3306
DB_DATABASE=homestead
DB_USERNAME=homestead
DB_PASSWORD=secret
```

**Điểm quan trọng:** `DB_HOST=mysql` — Đây là tên service trong Docker Compose, không phải localhost. Vì Laravel chạy trong container, nó sẽ tìm MySQL thông qua tên service trên mạng Docker.

## Thư Mục Cấu Trúc

```
project/
├── docker-compose.yaml
├── dockerfiles/
│   └── php.dockerfile
├── nginx/
│   └── nginx.conf
├── env/
│   └── mysql.env
└── src/
```

## Kết Luận

Container MySQL đảm nhận vai trò lưu trữ dữ liệu. Laravel sẽ giao tiếp với MySQL qua PDO extension (đã cài đặt ở container PHP). Tất cả data sẽ được lưu trong named volume của Docker, đảm bảo dữ liệu không bị mất khi container restart.
