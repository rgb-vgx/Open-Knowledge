## Lệnh Docker Compose Thường Dùng

```bash
# Khởi động tất cả services
docker compose up -d

# Khởi động cụ thể một số services
docker compose up -d --build server php mysql

# Chạy utility container
docker compose run --rm composer create-project laravel/laravel .
docker compose run --rm artisan migrate
docker compose run --rm npm install

# Kiểm tra trạng thái
docker compose ps

# Dừng tất cả
docker compose down
```

## Mẹo Hữu Ích

1. **Luôn dùng `--rm`** khi chạy utility containers để tránh dead containers
2. **Thêm `--build`** khi thay đổi Dockerfile để rebuild image
3. **Sử dụng `.env` file** thay vì hardcode thông tin đăng nhập
4. **`DB_HOST`** phải là tên service (ví dụ: `mysql`), không phải `localhost`
5. **Bind mount** cho development, **COPY** cho production
