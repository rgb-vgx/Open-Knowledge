# Docker Compose: Khi Nào Dùng Dockerfile, Khi Nào Không?

## Hai Cách Cấu Hình Container

Docker Compose cho phép bạn định nghĩa container theo hai cách:

### Cách 1: Chỉ Sử Dụng Image

```yaml
services:
  npm:
    image: 'node:14'
    working_dir: /var/www/html
    entrypoint: ['npm']
    volumes:
      - ./src:/var/www/html:delegated
```

**Ưu điểm:** Đơn giản, không cần file thêm, dễ đọc
**Nhược điểm:** Chỉ áp dụng được cho các cấu hình cơ bản

### Cách 2: Sử Dụng Dockerfile

```yaml
services:
  php:
    build:
      context: ./dockerfiles
      dockerfile: php.dockerfile
    volumes:
      - ./src:/var/www/html:delegated
```

**Ưu điểm:** linh hoạt hơn, có thể chạy `RUN`, `COPY`, `WORKDIR`
**Nhược điểm:** Nhiều file hơn, cần quản lý thêm

## Khi Nào Cần Dockerfile?

Bạn **bắt buộc** cần Dockerfile khi:

- Cần chạy lệnh `RUN` (cài đặt package, extension)
- Cần copy file từ host vào image (`COPY`)
- Cần cấu hình phức tạp hơn entrypoint và working_dir

Ví dụ: PHP container cần cài thêm extension `pdo_mysql` — điều này không thể làm trực tiếp trong Docker Compose.

## Khi Nào Không Cần Dockerfile?

Bạn có thể bỏ qua Dockerfile khi chỉ cần:

- Đặt `working_dir`
- Đặt `entrypoint`
- Sử dụng image có sẵn

Ví dụ: NPM container chỉ cần image Node.js với entrypoint là `npm`.

## Bind Mounts Cho Development

Trong môi trường development, bind mount là lựa chọn lý tưởng:

```yaml
volumes:
  - ./src:/var/www/html:delegated
```

**Ưu điểm:**
- Thay đổi code trên host → thấy ngay trong container
- Không cần rebuild image mỗi lần sửa code
- Phát triển nhanh chóng

**Nhược điểm:**
- Không phù hợp cho production — bind mount chỉ tồn tại trên máy cục bộ
- Container deployment sẽ không có source code

## Chuẩn Bị Cho Production

Trong production, source code cần được **COPY trực tiếp vào image** (không dùng bind mount). Điều này đảm bảo container tự chứa đầy đủ mọi thứ cần thiết.

## Kết Luận

Lựa chọn giữa Dockerfile và Docker Compose trực tiếp phụ thuộc vào độ phức tạp của container. Cho development, bind mount giúp bạn code nhanh hơn. Cho production, COPY vào image đảm bảo container self-contained.
