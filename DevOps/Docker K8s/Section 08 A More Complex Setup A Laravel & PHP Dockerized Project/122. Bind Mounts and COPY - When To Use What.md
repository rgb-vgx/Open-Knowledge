# Bind Mounts vs COPY: Khi Nào Dùng Cái Nào?

## Bind Mounts Cho Development

Trong môi trường development, bind mount giúp bạn thấy thay đổi code ngay lập tức:

```yaml
volumes:
  - ./src:/var/www/html:delegated
```

Khi bạn sửa file `welcome.blade.php` trên host, trang web sẽ cập nhật ngay — không cần rebuild image.

## COPY Cho Production

Trong Dockerfile, `COPY` embedding source code trực tiếp vào image:

```dockerfile
FROM nginx:stable-alpine

WORKDIR /etc/nginx/conf.d

COPY nginx/nginx.conf .

RUN mv nginx.conf default.conf

WORKDIR /var/www/html

COPY src .
```

**Ưu điểm:**
- Container tự chứa mọi thứ — không phụ thuộc host
- Deploy được lên bất kỳ server nào
- ẤN định phiên bản code (snapshot tại thời điểm build)

## Vấn Đề COPY: Build Context

Khi COPY file từ host vào image, Docker cần biết **build context** — thư mục mà Docker có quyền truy cập.

Nếu Dockerfile nằm trong `dockerfiles/`, nhưng cần COPY từ thư mục gốc:

```yaml
services:
  server:
    build:
      context: .              # ← Thư mục gốc project
      dockerfile: dockerfiles/nginx.dockerfile
```

**Lỗi thường gặp:** Nếu `context` là `./dockerfiles`, Docker sẽ không thể truy cập `src/` hay `nginx/` nằm ngoài thư mục đó.

## Dockerfile Cho Nginx Production

```dockerfile
FROM nginx:stable-alpine

WORKDIR /etc/nginx/conf.d

COPY nginx/nginx.conf .

RUN mv nginx.conf default.conf

WORKDIR /var/www/html

COPY src .
```

### Giải thích

- **COPY nginx/nginx.conf .** — Copy file cấu hình vào working directory
- **RUN mv nginx.conf default.conf** — Rename thành `default.conf` (Nginx yêu cầu tên này)
- **COPY src .** — Copy toàn bộ source code Laravel vào image

## Cập Nhật Docker Compose

```yaml
services:
  server:
    build:
      context: .
      dockerfile: dockerfiles/nginx.dockerfile
    # volumes: ← Comment bind mount khi test production mode
```

## Xử Lý Lỗi Permission

Khi COPY source code vào image, container có thể gặp lỗi permission. Giải pháp:

```dockerfile
FROM php:8.2-fpm-alpine

WORKDIR /var/www/html

COPY src .

RUN docker-php-ext-install pdo pdo_mysql

RUN chown -R www-data:www-data /var/www/html
```

Hoặc tạo user riêng (best practice hơn):

```dockerfile
RUN addgroup -g 1000 laravel && adduser -G laravel -g laravel -s /bin/sh -D laravel

USER laravel
```

## Kết Hợp Cả Hai

Trong thực tế, bạn có thể sử dụng kết hợp:

1. **COPY** trong Dockerfile — Snapshot code khi build image
2. **Bind mount** trong Docker Compose — Override code trong development

Khi deploy, chỉ dùng image (đã COPY), bỏ bind mount. Khi develop, thêm bind mount để thấy thay đổi real-time.

## Kết Luận

- **Development:** Dùng bind mount — code thay đổi ngay lập tức
- **Production:** Dùng COPY — container tự chứa code, deploy được mọi nơi
- **Kết hợp cả hai:** Cách tiếp cận linh hoạt nhất cho cả development lẫn production
