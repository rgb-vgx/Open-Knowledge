# Tạo Laravel Project Với Container Composer

## Bước 1: Lấy Lệnh Từ Tài Liệu Laravel

Truy cập tài liệu chính thức của Laravel tại `laravel.com/docs/installing` để lấy lệnh cài đặt. Lệnh cơ bản là:

```bash
composer create-project laravel/laravel example-app
```

Tuy nhiên, vì Composer đã được cấu hình sẵn trong container, chúng ta sẽ điều chỉnh lệnh này cho phù hợp.

## Bước 2: Chạy Container Composer

Mở terminal và thực thi lệnh sau:

```bash
docker compose run --rm composer create-project laravel/laravel .
```

### Giải thích lệnh

- **`docker compose run`** — Chạy một service cụ thể trong docker-compose
- **`--rm`** — Tự động xóa container sau khi hoàn thành
- **`composer`** — Tên service cần chạy
- **`create-project laravel/laravel .`** — Lệnh Composer tạo Laravel project mới trong thư mục hiện tại (`.`)

> **Lưu ý:** Vì entrypoint trong `composer.dockerfile` đã là `composer`, chúng ta không cần viết `composer` twice. Lệnh sẽ tự động thêm `--ignore-platform-reqs`.

## Bước 3: Đợi Quá Trình Hoàn Thành

Quá trình này có thể mất vài phút vì Composer cần tải và cài đặt tất cả dependencies của Laravel. Docker sẽ tự động build image lần đầu (nếu chưa có).

Khi hoàn thành, kiểm tra thư mục `src/` trên host machine — bạn sẽ thấy toàn bộ cấu trúc Laravel đã được tạo:

```
src/
├── app/
├── bootstrap/
├── config/
├── database/
├── public/
├── resources/
├── routes/
├── storage/
├── vendor/
├── .env
├── artisan
├── composer.json
├── composer.lock
└── ...
```

## Bước 4: Kiểm Tra Kết Quả

Khởi động lại các container application (Nginx, PHP, MySQL):

```bash
docker compose up -d --build server php mysql
```

Truy cập `http://localhost:8000` — bạn sẽ thấy trang welcome mặc định của Laravel!

## Thư Mục Cấu Trúc

```
project/
├── docker-compose.yaml
├── dockerfiles/
│   ├── php.dockerfile
│   └── composer.dockerfile
├── nginx/
│   └── nginx.conf
├── env/
│   └── mysql.env
└── src/          ← Laravel project nằm ở đây
```

## Kết Luận

Chỉ với một lệnh duy nhất, chúng ta đã tạo được Laravel project hoàn chỉnh — không cần cài Composer hay PHP trên máy cục bộ. Toàn bộ quá trình diễn ra bên trong container, và kết quả được reflect ngay lập tức vào thư mục `src/` nhờ bind mount.
