# Chạy Một Số Container Cụ Thể Với Docker Compose

## Cấu Hình Laravel Kết Nối Database

Trước khi chạy ứng dụng, cập nhật file `.env` trong thư mục `src/` (file cấu hình Laravel):

```
DB_CONNECTION=mysql
DB_HOST=mysql
DB_PORT=3306
DB_DATABASE=homestead
DB_USERNAME=homestead
DB_PASSWORD=secret
```

**Điểm quan trọng:** `DB_HOST=mysql` phải là tên service trong Docker Compose, không phải `localhost`. Vì Laravel chạy trong container, nó cần tìm MySQL qua tên service trên mạng Docker.

## Thêm Bind Mount Cho Nginx

Nginx container chưa có quyền truy cập source code. Cần thêm bind mount:

```yaml
services:
  server:
    image: 'nginx:stable-alpine'
    ports:
      - '8000:80'
    volumes:
      - ./nginx/nginx.conf:/etc/nginx/conf.d/default.conf:ro
      - ./src:/var/www/html:delegated
```

> **Lưu ý:** Path mount phải là `/var/www/html` — khớp với root trong nginx.conf.

## Chỉ Khởi Động Một Số Service

Mặc định, `docker compose up` sẽ khởi động tất cả services. Để chạy cụ thể:

```bash
docker compose up -d --build server php mysql
```

Hoặc đơn giản hơn với `depends_on`:

```yaml
services:
  server:
    image: 'nginx:stable-alpine'
    ports:
      - '8000:80'
    volumes:
      - ./nginx/nginx.conf:/etc/nginx/conf.d/default.conf:ro
      - ./src:/var/www/html:delegated
    depends_on:
      - php
      - mysql
```

Với `depends_on`, khi chạy `docker compose up server`, Docker sẽ tự động khởi động cả `php` và `mysql`.

## Sửa Lỗi Nginx Config Path

Một lỗi phổ biến: bind mount nginx.conf vào sai path. Thay vì mount vào `/etc/nginx/nginx.conf`, hãy mount vào:

```
/etc/nginx/conf.d/default.conf
```

Đây là file cấu hình site mặc định của Nginx, được include bởi `nginx.conf` chính.

## Sử Dụng `--build`

Thêm flag `--build` khi chạy `docker compose up`:

```bash
docker compose up -d --build server php mysql
```

Flag này buộc Docker Compose rebuild image từ Dockerfile, đảm bảo mọi thay đổi trong Dockerfile đều được áp dụng. Nếu không có thay đổi, Docker sẽ sử dụng cache layer.

## Kiểm Tra

1. Chạy `docker compose ps` — kiểm tra các container đang chạy
2. Truy cập `http://localhost:8000` — xem trang welcome Laravel
3. Chỉnh sửa file `src/resources/views/welcome.blade.php` — thêm `<h1>Hello</h1>`
4. Reload trình duyệt — thấy thay đổi ngay lập tức

## Kết Luận

Docker Compose cho phép bạn linh hoạt khởi động các service cần thiết. Kết hợp `depends_on` với việc chạy cụ thể service giúp tiết kiệm tài nguyên và tăng tốc quá trình development.
