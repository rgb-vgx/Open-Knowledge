# Thêm Container Nginx: Web Server Cho Laravel Application

## Bắt Đầu Với Docker Compose

Tạo một file `docker-compose.yaml` trong thư mục dự án. Đây là nơi định nghĩa tất cả containers mà chúng ta cần:

```yaml
version: '3.8'

services:
  server:
    image: 'nginx:stable-alpine'
    ports:
      - '8000:80'
    volumes:
      - ./nginx/nginx.conf:/etc/nginx/conf.d/default.conf:ro
```

### Giải thích từng phần

- **`image: 'nginx:stable-alpine'`** — Sử dụng image Nginx chính thức từ Docker Hub. Phiên bản `stable-alpine` dựa trên Linux Alpine — rất nhẹ và ổn định.
- **`ports: '8000:80'`** — Map port 8000 trên host machine sang port 80 bên trong container (Nginx mặc định lắng nghe port 80).
- **`volumes`** — Bind mount file cấu hình Nginx từ host vào container.

## Tại Sao Cần File Cấu hình Nginx Riêng?

Image Nginx mặc định chỉ hiển thị trang "Welcome to nginx". Để Laravel hoạt động đúng, chúng ta cần cấu hình Nginx để:

1. **Lắng nghe request** trên port 80
2. **Chuyển tiếp request PHP** đến container PHP Interpreter
3. **Phục vụ file tĩnh** từ thư mục `public/` của Laravel

Tạo thư mục `nginx/` và file `nginx/nginx.conf`:

```nginx
server {
    listen 80;
    server_name localhost;
    root /var/www/html/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass php:9000;
        fastcgi_index index.php;
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }
}
```

### Các Điểm Quan Trọng

- **`fastcgi_pass php:9000`** — Chuyển tiếp request PHP đến container tên `php` trên port 9000. Docker Compose tự động phân giải tên service thành IP address.
- **`root /var/www/html/public`** — Thư mục gốc của Laravel (thư mục `public`).
- **`try_files`** — Tất cả request đều được chuyển đến `index.php` nếu không tìm thấy file static tương ứng.

## Thư Mục Cấu trúc

```
project/
├── docker-compose.yaml
└── nginx/
    └── nginx.conf
```

## Kiểm Tra

Sau khi cấu hình, chạy lệnh sau để khởi động container:

```bash
docker compose up -d
```

Truy cập `http://localhost:8000` — bạn sẽ thấy trang "Welcome to nginx" (chưa phải Laravel vì chúng ta chưa có source code).

## Kết Luận

Container Nginx đóng vai trò là "cổng vào" cho toàn bộ ứng dụng. Mọi request từ bên ngoài đều đi qua Nginx trước, sau đó được chuyển tiếp đến các container phù hợp. Đây là mô hình proxy reverse proxy phổ biến trong kiến trúc microservices.
