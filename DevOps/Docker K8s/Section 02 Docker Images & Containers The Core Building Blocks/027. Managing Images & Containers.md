# Quản Lý Images & Containers: Những Lệnh Cơ Bản Nhưng Thiết Yếu

Ở các bài trước, chúng ta đã học cách build image và chạy container. Nhưng Docker còn cung cấp rất nhiều lệnh quản trị khác giúp bạn kiểm soát vòng đời của images và containers. Hôm nay, chúng ta sẽ cùng khám phá những lệnh thiết yếu nhất.

---

## 1. Mẹo Hữu Ích: `--help`

Trước khi đi vào chi tiết, có một mẹo cực kỳ quan trọng mà bạn nên nhớ: **với bất kỳ lệnh Docker nào, thêm `--help` ở cuối để xem tất cả các tùy chọn có sẵn.**

```bash
docker --help
docker run --help
docker ps --help
```

Sẽ có rất nhiều tùy chọn mà bạn hiếm khi cần đến, nhưng việc biết cách tra cứu sẽ giúp bạn tự tin hơn khi làm việc với Docker.

---

## 2. Quản Lý Containers

### Liệt kê Containers

```bash
# Xem các containers ĐANG CHẠY
docker ps

# Xem TẤT CẢ containers (kể cả đã stop)
docker ps -a
```

Lệnh `docker ps` mặc định chỉ hiển thị các containers đang hoạt động. Thêm `-a` để thấy toàn bộ lịch sử, bao gồm cả những containers đã bị dừng.

### Dừng và Khởi Động Lại Container

```bash
# Dừng một container đang chạy
docker stop <container_id_or_name>

# Khởi động lại container đã dừng
docker start <container_id_or_name>
```

**Lưu ý quan trọng:** Bạn không luôn cần phải tạo container mới bằng `docker run`. Nếu nothing thay đổi trong code và image, bạn hoàn toàn có thể **khởi động lại container cũ** bằng `docker start`. Đây là thao tác nhanh hơn và tiết kiệm tài nguyên hơn.

### Xem Logs

```bash
# Xem logs của container
docker logs <container_id_or_name>

# Theo dõi logs real-time
docker logs -f <container_id_or_name>
```

---

## 3. Quản Lý Images

### Liệt kê Images

```bash
docker images
# Hoặc
docker image ls
```

Bạn sẽ thấy danh sách tất cả images trên máy, bao gồm tên, tag, ID và kích thước.

### Xóa Images

```bash
# Xóa một image
docker rmi <image_id>

# Xóa nhiều images cùng lúc
docker rmi <id1> <id2> <id3>

# Xóa tất cả images chưa được dùng bởi container nào
docker image prune
```

**Quy tắc quan trọng:** Bạn **không thể xóa image** nếu có container nào đó (kể cả container đã stop) đang sử dụng image đó. Bạn phải **xóa container trước**, sau đó mới xóa được image.

---

## 4. Tổng Kết

| Thao tác | Lệnh |
|----------|------|
| Xem containers đang chạy | `docker ps` |
| Xem tất cả containers | `docker ps -a` |
| Dừng container | `docker stop <id/name>` |
| Khởi động lại container | `docker start <id/name>` |
| Xóa container | `docker rm <id/name>` |
| Xem images | `docker images` |
| Xóa image | `docker rmi <image_id>` |
| Dọn dẹp images thừa | `docker image prune` |

Với những lệnh này, bạn đã có trong tay bộ công cụ cơ bản nhất để quản trị Docker trên môi trường development. Ở các bài tiếp theo, chúng ta sẽ đi sâu hơn vào từng thao tác cụ thể.
