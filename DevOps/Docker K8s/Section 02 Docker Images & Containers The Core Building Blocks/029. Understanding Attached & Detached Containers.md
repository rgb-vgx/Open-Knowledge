# Attached & Detached Containers: Hai Chế Độ Chạy Cơ Bản Của Docker

Trong quá trình làm việc với Docker, bạn sẽ thường xuyên gặp hai chế độ chạy: **Attached** và **Detached**. Hiểu rõ sự khác biệt giữa chúng sẽ giúp bạn kiểm soát tốt hơn vòng đời container, đặc biệt khi debug và theo dõi log.

---

## 1. Attached Mode — Chế Độ Mặc Định Của `docker run`

Khi bạn chạy `docker run` mà không thêm cờ `-d`, container sẽ chạy ở chế độ **attached** — nghĩa là terminal của bạn **bị chặn** bởi tiến trình container. Mọi output (log, thông báo) từ container sẽ hiển thị trực tiếp trên terminal.

```bash
docker run --name my-app -p 3000:80 my-image:v1
# Terminal bị chặn — không thể nhập lệnh khác
```

**Ưu điểm:** Bạn thấy output real-time ngay trên terminal.
**Nhược điểm:** Terminal bị chiếm dụng, không thể làm gì khác.

---

## 2. Detached Mode — Chạy Ngầm Với Cờ `-d`

Khi thêm cờ `-d`, container chạy ở chế độ **detached** — tức là chạy nền (background). Terminal không bị chặn và bạn có thể tiếp tục nhập lệnh khác.

```bash
docker run -d --name my-app -p 3000:80 my-image:v1
# Terminal tự do — có thể nhập lệnh tiếp
```

Container vẫn chạy bình thường, nhưng bạn sẽ **không thấy output** trực tiếp trên terminal.

**Khi nào dùng detached mode?**
- Production: Luôn dùng `-d` để chạy ngầm.
- Khi cần dùng terminal cho các tác vụ khác.
- Khi không cần theo dõi log real-time.

---

## 3. Chuyển Đổi Giữa Hai Chế Độ

### Từ Attached Sang Detached

Nhấn `Ctrl + C` để dừng attached process, sau đó container vẫn có thể được restart ở detached mode.

### Từ Detached Sang Attached

```bash
# Gắn lại vào container đang chạy
docker attach <container_name_or_id>
```

**Lưu ý:** `docker attach` sẽ đưa bạn trở lại tiến trình chính (PID 1) của container. Nếu bạn thoát bằng `Ctrl + C`, container có thể bị dừng.

### Xem Logs Không Cần Attach

```bash
# Xem logs
docker logs <container_name_or_id>

# Theo dõi logs real-time (tương tự attach nhưng an toàn hơn)
docker logs -f <container_name_or_id>
```

Dùng `docker logs` thay vì `docker attach` thường an toàn hơn, vì nó không làm gián đoạn tiến trình chính của container.

---

## 4. So Sánh

| Tính năng | Attached | Detached |
|-----------|----------|----------|
| Terminal | Bị chặn | Tự do |
| Output | Hiển thị real-time | Không thấy (phải dùng `docker logs`) |
| Mặc định | `docker run` | `docker run -d`, `docker start` |
| Phù hợp | Debug, test nhanh | Production, chạy nền |

---

## 5. Tổng Kết

- **Attached mode** gắn terminal của bạn vào container — hữu ích cho debug nhưng chiếm terminal.
- **Detached mode** chạy container nền — phù hợp cho production và làm việc đa nhiệm.
- Dùng `docker attach` để trở lại attached mode, nhưng ưu tiên `docker logs -f` để xem log an toàn hơn.
- `docker start` mặc định chạy detached, `docker run` mặc định chạy attached.
