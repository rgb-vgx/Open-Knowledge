# Pull & Sử Dụng Shared Images: Tận Dụng Kho Tàng Docker Hub

Docker Hub có hàng triệu images sẵn sàng để sử dụng. Bạn không cần phải tự build mọi thứ từ đầu — chỉ cần tìm kiếm và pull về. Bài viết này hướng dẫn cách pull và sử dụng shared images từ Docker Hub.

---

## 1. Tìm Kiếm Image Trên Docker Hub

Truy cập `hub.docker.com` và tìm kiếm image bạn cần. Ví dụ: `nginx`, `postgres`, `redis`, `node`...

Mỗi image chính thức đều có:
- Mô tả chi tiết về cách sử dụng.
- Các tags có sẵn (phiên bản, biến thể).
- Ví dụ về Dockerfile và docker-compose.

---

## 2. Pull Image

```bash
# Pull image mới nhất
docker pull nginx

# Pull phiên bản cụ thể
docker pull nginx:1.25-alpine

# Pull image từ user/repository cụ thể
docker pull username/my-app:v1
```

---

## 3. Sử Dụng Image

```bash
# Chạy container từ image vừa pull
docker run -d --name web-server -p 80:80 nginx

# Hoặc với custom image
docker run -d -p 3000:80 username/my-app:v1
```

---

## 4. Best Practices

| Nguyên tắc | Mô tả |
|-----------|-------|
| Dùng tag cụ thể | `nginx:1.25-alpine` thay vì `nginx` |
| Kiểm tra source | Xem Dockerfile và source code trước khi dùng |
| Ưu tiên official images | Được verify và maintain bởi Docker/team chính thức |
| Đọc kỹ documentation | Mỗi image có cách sử dụng riêng |

---

## 5. Tổng Kết

- Docker Hub là kho tàng images khổng lồ — tận dụng nó thay vì tự build mọi thứ.
- Luôn pull image với tag cụ thể để đảm bảo reproducibility.
- Kiểm tra documentation và source trước khi sử dụng image mới.
- Official images (được gắn biểu tượng chính thức) là lựa chọn an toàn nhất.
