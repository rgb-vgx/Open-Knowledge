# Tổng Kết Module: Docker Images & Containers — Bức Tranh Toàn Cảnh

Chúng ta đã đi qua toàn bộ Module 02 về Docker Images & Containers. Đây là nền tảng cốt lõi mà mọi kiến thức Docker khác đều xây dựng lên trên đó. Hãy cùng ôn lại những điểm mấu chốt nhất.

---

## 1. Khái Niệm Nền Tảng

- **Image:** Bản thiết kế Read-Only chứa code, runtime, dependencies, và OS base.
- **Container:** Phiên bản đang chạy của Image, có lớp Read-Write mỏng ở trên cùng.
- **Dockerfile:** Kịch bản tự động hóa telling Docker cách build Image.

---

## 2. Vòng Đời Container

- Container chỉ sống khi **PID 1** (tiến trình chính) còn hoạt động.
- `docker run` tạo mới + chạy container.
- `docker start` khởi động lại container đã dừng.
- `docker stop` dừng container (gửi SIGTERM).

---

## 3. Chế Độ Chạy

- **Attached mode:** Terminal bị chặn, thấy output real-time. Mặc định của `docker run`.
- **Detached mode:** Chạy nền, terminal tự do. Dùng cờ `-d`.
- **Interactive mode:** Cần input từ người dùng. Dùng cờ `-it`.

---

## 4. Quản Lý

| Thao tác | Lệnh |
|----------|------|
| Liệt kê containers | `docker ps`, `docker ps -a` |
| Dừng container | `docker stop` |
| Xóa container | `docker rm` (phải stopped trước) |
| Tự động xóa | `docker run --rm` |
| Liệt kê images | `docker images` |
| Xóa image | `docker rmi` (không có container tham chiếu) |
| Inspect image | `docker image inspect` |
| Copy files | `docker cp` |
| Dọn dẹp | `docker system prune -f` |

---

## 5. Best Practices

- Luôn dùng **tag cụ thể** thay vì `:latest`.
- **Layer optimization:** Tách dependency trước, source code sau.
- **Immutable Infrastructure:** Không sửa code trong container → rebuild image mới.
- **Auto-cleanup:** Dùng `--rm` hoặc `docker system prune`.
- **Persistence:** Dùng Volumes cho dữ liệu quan trọng.
- **Security:** Không commit secrets/keys vào image.

---

## 6. Cheat Sheet

```bash
# === IMAGES ===
docker images
docker pull <image>
docker build -t <name>:<tag> .
docker rmi <image>
docker image inspect <image>

# === CONTAINERS ===
docker run -d --name <n> -p <H>:<C> <image>
docker ps / docker ps -a
docker stop / docker start
docker rm <container>
docker logs <container>
docker cp <src> <dest>
docker system prune -f

# === FLAGS HỮU ÍCH ===
-d        # Detached mode
-it       # Interactive + TTY
--rm      # Auto-remove khi stop
--name    # Đặt tên container
-p <H>:<C>  # Publish port
```
