# Chế Độ Tương Tác: Khi Container Cần Input Từ Bạn

Cho đến nay, hầu hết các ví dụ của chúng ta đều xoay quanh các web server — những ứng dụng chạy liên tục và lắng nghe request. Nhưng Docker không chỉ giới hạn ở web servers. Hôm nay, chúng ta sẽ thử Dockerize một ứng dụng Python đơn giản cần **nhập dữ liệu từ người dùng**, để hiểu rõ hơn về chế độ tương tác (interactive mode).

---

## 1. Ví Dụ: Ứng Dụng Python Đọc Input

Hãy xem xét một ứng dụng Python đơn giản: đọc min/max từ terminal, kiểm tra dữ liệu, rồi in ra một số ngẫu nhiên.

```python
# rng.py
min_num = int(input("Enter min: "))
max_num = int(input("Enter max: "))
if min_num > max_num:
    print("Min must be less than max!")
else:
    import random
    print(random.randint(min_num, max_num))
```

Ứng dụng này **không chạy web server**, mà cần tương tác trực tiếp với người dùng qua terminal.

---

## 2. Dockerfile Cho Ứng Dụng Tương Tác

```dockerfile
FROM python:3
WORKDIR /app
COPY . .
CMD ["python", "rng.py"]
```

Đơn giản, gọn gàng. Nhưng khi chạy thử:

```bash
docker run <image>
# Container crash ngay lập tức!
```

**Tại sao?** Vì chúng ta chạy `docker run` mà không có cờ `-it`, nên container không có khả năng nhận input từ terminal.

---

## 3. Giải Pháp: Cờ `-it`

```bash
docker run -it <image>
```

**Giải thích:**
- `-i` (`--interactive`): Giữ STDIN mở — cho phép nhập dữ liệu vào container.
- `-t` (`--tty`): Cấp phát terminal ảo (pseudo-TTY) — tạo thiết bị nhập/xuất cho container.

Kết hợp `-it`, bạn có thể gõ min và max trực tiếp trên terminal, và ứng dụng sẽ hoạt động bình thường.

---

## 4. Restart Container Ở Interactive Mode

Khi container dừng và bạn muốn chạy lại:

```bash
# Cách 1: Docker start với attached mode
docker start -a <container_name>

# Cách 2: Docker start với interactive mode
docker start -ai <container_name>
```

**Lưu ý:** Docker ghi nhớ flag `-t` từ lần chạy đầu tiên, nên khi restart bạn chỉ cần thêm `-a` (attached) và `-i` (interactive).

---

## 5. Docker Không Chỉ Là Web Server

Đây là bài học quan trọng: Docker có thể đóng gói **bất kỳ ứng dụng nào** — không chỉ web servers. Những ứng dụng CLI đơn giản, utility scripts, hay batch jobs đều có thể được Dockerize.

Tùy thuộc vào loại ứng dụng, bạn sẽ cần chọn chế độ chạy phù hợp:

| Loại ứng dụng | Chế độ phù hợp |
|---------------|----------------|
| Web server (long-running) | Detached (`-d`) |
| App cần input người dùng | Interactive (`-it`) |
| Batch job, script | Attached hoặc Detached |

---

## Tổng Kết

- Ứng dụng cần input người dùng **bắt buộc** phải chạy với cờ `-it`.
- `-i` giữ STDIN mở, `-t` cấp phát terminal ảo.
- Khi restart, dùng `docker start -ai` để tương tác lại.
- Docker không chỉ cho web servers — mọi loại ứng dụng đều có thể Dockerize.
