# Copy Files Vào & Ra Container: Lệnh `docker cp`

Trong quá trình phát triển, đôi khi bạn cần thêm hoặc trích xuất file từ container mà không muốn rebuild image. Docker cung cấp lệnh `docker cp` giúp bạn làm điều này dễ dàng.

---

## 1. Docker CP Là Gì?

`docker cp` cho phép bạn **copy file và thư mục** giữa container và hệ thống host (máy tính cá nhân của bạn). Lệnh này hoạt động với cả container đang chạy và đã stopped.

---

## 2. Copy Từ Host Vào Container

```bash
# Cú pháp
docker cp <host_path> <container_name>:<container_path>

# Ví dụ: Copy thư mục dummy vào container
docker cp ./dummy/. my-container:/test
```

Nếu thư mục `/test` chưa tồn tại bên trong container, Docker sẽ tự động tạo nó.

---

## 3. Copy Từ Container Ra Host

```bash
# Cú pháp
docker cp <container_name>:<container_path> <host_path>

# Ví dụ: Copy file từ container ra thư mục dummy
docker cp my-container:/test/test.txt ./dummy/
```

---

## 4. Use Cases Phổ Biến

### Copy Vào Container
- Thêm file cấu hình (config file) mà không cần rebuild image.
- Patch tạm thời trong quá trình debug.

### Copy Ra Container
- **Trích xuất log files** từ container — biến "black box" thành hệ thống minh bạch hơn.
- Lưu lại kết quả chạy thử từ container.
- Sao lưu dữ liệu tạm thời.

---

## 5. Lưu Ý Quan Trọng

- **Không nên dùng `docker cp` để update code production** — cách làm này dễ gây sai sót và khó kiểm soát.
- Thay vào đó, hãy **rebuild image** hoặc sử dụng **Bind Mounts** cho mục đích development.
- `docker cp` hoạt động như lệnh `cp -a` trong Unix — copy đệ quy và giữ nguyên quyền truy cập.
- Bạn không thể copy các file hệ thống nhạy cảm (`/dev`, `/proc`, `/sys`).

---

## 6. Tổng Kết

- `docker cp` copy file giữa container và host.
- Hoạt động với cả container đang chạy và đã stopped.
- Hữu ích cho debugging, trích xuất log, và thêm config tạm thời.
- Không dùng để update code production — ưu tiên rebuild image hoặc Bind Mounts.
