# Tài Nguyên Học Tập: Docker Images & Containers

Để tiếp tục học hỏi và thực hành, đây là danh sách các tài nguyên hữu ích mà bạn nên tham khảo.

---

## Tài Liệu Chính Thức

- [Docker Official Documentation](https://docs.docker.com/) — Tài liệu chính thức từ Docker, cập nhật nhất.
- [Docker CLI Reference](https://docs.docker.com/reference/cli/docker/) — Tham chiếu đầy đủ cho tất cả lệnh Docker.
- [Docker Hub](https://hub.docker.com/) — Kho tàng images khổng lồ.
- [Docker Getting Started](https://docs.docker.com/get-started/) — Hướng dẫn bắt đầu từ đầu.

---

## Tài Liệu Học Tập

- [Docker Curriculum](https://docker-curriculum.com/) — Tutorial Docker từ cơ bản đến nâng cao.
- [Play with Docker](https://labs.play-with-docker.com/) — Lab trực tuyến miễn phí để thực hành.
- [Katacoda Docker Scenarios](https://www.katacoda.com/courses/docker) — Scenario-based learning.

---

## Công Cụ Hỗ Trợ

- **VS Code + Docker Extension:** Auto-complete, syntax highlighting, quản lý containers trực tiếp từ IDE.
- **LazyDocker:** Terminal UI để quản lý Docker dễ dàng hơn.
- **Portainer:** Web UI cho Docker management.

---

## Thực Hành

- Thử build custom image cho một dự án của riêng bạn.
- Deploy một ứng dụng đơn giản (Node.js, Python, Go) lên Docker.
- Thực hành quản lý containers: stop, restart, logs, exec.
- Thử push image lên Docker Hub.
- Viết Dockerfile cho nhiều loại ứng dụng khác nhau.

---

## Mẹo Học Hiệu Quả

1. **Đọc documentation trước** — Tài liệu Docker rất tốt và dễ hiểu.
2. **Thực hành trên lab** — Dùng Play with Docker hoặc cài Docker locally.
3. **Đọc Dockerfile của official images** — Học cách chuyên gia viết Dockerfile.
4. **Gỡ lỗi chủ động** — Khi gặp lỗi, đọc kỹ error message và tìm kiếm solution.
5. **Xây dựng dự án thực** — Áp dụng Docker vào dự án hiện tại của bạn.
