# Chia Sẻ Images: Docker Hub Và Việc Publish/Pull Images

Sau khi build được Custom Image chất lượng, bước tiếp theo là chia sẻ nó với cộng đồng hoặc với đồng đội trong tổ chức. Docker Hub — "siêu thị" image lớn nhất thế giới — chính là nơi để bạn làm điều đó.

---

## 1. Docker Hub Là Gì?

Docker Hub (`hub.docker.com`) là nền tảng registry lớn nhất cho Docker images. Tương tự GitHub dành cho mã nguồn, Docker Hub là nơi:
- Các tổ chức lớn duy trì **Official Images** (Node.js, MongoDB, Nginx...).
- Bạn có thể **publish** custom images của mình.
- Đồng đội có thể **pull** và sử dụng chung images.

---

## 2. Push Image Lên Docker Hub

### Bước 1: Đăng Nhập

```bash
docker login
```

Nhập username và password khi được yêu cầu.

### Bước 2: Gắn Tag Đúng Format

```bash
# Format: docker tag <local_image> <username>/<repository>:<tag>
docker tag my-app:v1 username/my-app:v1
```

### Bước 3: Push Lên Docker Hub

```bash
docker push username/my-app:v1
```

Image của bạn sẽ được upload lên Docker Hub và bất kỳ ai cũng có thể pull về sử dụng (nếu là public repository).

---

## 3. Pull & Sử Dụng Shared Image

```bash
# Pull image từ Docker Hub
docker pull username/my-app:v1

# Chạy container
docker run -d -p 3000:80 username/my-app:v1
```

---

## 4. Lưu Ý

- **Public repository:** Miễn phí, ai cũng có thể pull.
- **Private repository:** Cần tài khoản trả phí, chỉ những người được cấp quyền mới truy cập được.
- Luôn gắn tag có ý nghĩa khi push — tránh dùng `:latest` vì nó gây nhầm lẫn.
- Kiểm tra kỹ image trước khi push — không push secrets, keys hay thông tin nhạy cảm.

---

## 5. Tổng Kết

- Docker Hub là nơi chia sẻ images với cộng đồng hoặc tổ chức.
- Quy trình push: `docker login` → `docker tag` → `docker push`.
- Quy trình sử dụng: `docker pull` → `docker run`.
- Luôn gắn tag cụ thể và kiểm tra image trước khi push.
