# Xóa Images & Containers: Dọn Dẹp Hệ Thống Docker

Sau một thời gian làm việc với Docker, bạn sẽ nhận thấy danh sách containers và images ngày càng dài ra. Việc dọn dẹp định kỳ là cần thiết để giải phóng dung lượng ổ cứng và giữ hệ thống gọn gàng.

---

## 1. Xóa Containers

### Nguyên Tắc Cơ Bản

- Container **phải ở trạng thái stopped** trước khi có thể xóa.
- Bạn **không thể xóa container đang chạy** trực tiếp.

```bash
# Thử xóa container đang chạy → Lỗi!
docker rm my-running-container
# Error: You cannot remove a running container

# Phải dừng container trước
docker stop my-running-container
docker rm my-running-container
```

### Xóa Nhiều Containers

```bash
# Xóa nhiều containers cùng lúc (phải stopped trước)
docker rm container1 container2 container3
```

### Tự Động Xóa Container

```bash
# Container tự xóa khi dừng
docker run -d --rm --name my-app -p 3000:80 my-image:v1
```

Cờ `--rm` đảm bảo container sẽ tự động bị xóa ngay sau khi dừng. Rất hữu ích cho các container chỉ dùng một lần.

---

## 2. Xóa Images

### Nguyên Tắc

- Image **không được sử dụng bởi container nào** (kể cả container đã stopped) mới xóa được.
- Nếu có container nào đó tham chiếu đến image, bạn phải xóa container đó trước.

```bash
# Xóa một image
docker rmi <image_id>

# Xóa nhiều images
docker rmi <id1> <id2> <id3>
```

### Dọn Dẹp Tự Động

```bash
# Xóa tất cả images chưa được dùng bởi container nào
docker image prune
```

---

## 3. Dọn Dẹp Toàn Bộ Hệ Thống

```bash
# Xóa tất cả: containers đã stop, dangling images, networks không dùng
docker system prune -f
```

Lệnh này là "cây đũa thần" để dọn dẹp nhanh gọn. Nó sẽ xóa:
- Tất cả containers đã stopped
- Dangling images (images không có tag `<none>`)
- Networks không được sử dụng

---

## 4. Best Practices

| Tình huống | Lệnh phù hợp |
|-----------|--------------|
| Container chạy xong 1 lần | `docker run --rm` |
| Dọn dẹp containers đã stop | `docker system prune -f` |
| Xóa image cụ thể | `docker rmi <id>` |
| Xóa image thừa | `docker image prune` |

---

## Tổng Kết

- Container phải **stopped** trước khi xóa (`docker rm`).
- Image phải **không có container nào** tham chiếu trước khi xóa (`docker rmi`).
- Dùng `--rm` với `docker run` để tự động xóa container khi dừng.
- Định kỳ chạy `docker system prune -f` để giữ hệ thống sạch sẽ.
