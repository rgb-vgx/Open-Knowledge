# Push Images Lên Docker Hub: Hướng Dẫn Từng Bước

Sau khi build được custom image chất lượng, bạn có thể chia sẻ nó với đồng đội hoặc cộng đồng thông qua Docker Hub. Bài viết này hướng dẫn chi tiết cách push image lên Docker Hub.

---

## 1. Đăng Nhập Docker Hub

Trước tiên, bạn cần có tài khoản Docker Hub (miễn phí tại hub.docker.com). Sau đó, đăng nhập qua terminal:

```bash
docker login
```

Nhập username và password khi được yêu cầu. Thông tin đăng nhập sẽ được lưu cục bộ cho các lệnh tiếp theo.

---

## 2. Gắn Tag Cho Image

Docker Hub yêu cầu image phải có tag đúng format: `<username>/<repository>:<tag>`.

```bash
# Xem images hiện có
docker images

# Gắn tag đúng format Docker Hub
docker tag my-app:v1 username/my-app:v1

# Ví dụ cụ thể
docker tag my-go-api:v1 maithdev/go-api:v1
```

---

## 3. Push Lên Docker Hub

```bash
docker push username/my-app:v1
```

Docker sẽ upload từng layer của image lên Docker Hub. Quá trình này có thể mất vài phút tùy thuộc vào kích thước image và tốc độ mạng.

---

## 4. Kiểm Tra Trên Docker Hub

Sau khi push thành công, truy cập `hub.docker.com/repository/docker/<username>` để xác nhận image đã có mặt trên Docker Hub.

---

## 5. Best Practices

- **Không push secrets/keys vào image** — kiểm tra kỹ trước khi push.
- Luôn dùng tag cụ thể (ví dụ: `v1`, `v2`) thay vì `:latest`.
- Viết README mô tả cách sử dụng image.
- Dùng `.dockerignore` để loại bỏ file không cần thiết trước khi build.

---

## Tổng Kết

- `docker login` → `docker tag` → `docker push` là quy trình cơ bản.
- Image phải có tag đúng format `<username>/<repo>:<tag>`.
- Kiểm tra image sạch sẽ trước khi push — không có secrets hay sensitive data.
