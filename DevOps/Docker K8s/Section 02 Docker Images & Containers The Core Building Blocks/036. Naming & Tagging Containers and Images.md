# Đặt Tên & Gắn Tag: Quản Lý Containers và Images Có Trật Tự

Cho đến nay, chúng ta chủ yếu làm việc với các ID tự động sinh ra bởi Docker. Tuy nhiên, việc đặt tên rõ ràng cho containers và images sẽ giúp quản lý dễ dàng hơn rất nhiều, đặc biệt khi hệ thống có nhiều thành phần.

---

## 1. Đặt Tên Cho Container

Khi chạy container, sử dụng cờ `--name` để đặt tên:

```bash
docker run -d --name goals-app -p 3000:80 my-image:v1
```

**Lợi ích:**
- Không cần nhớ/generated ID dài ngoằng.
- Dễ dàng stop, restart, xóa bằng tên quen thuộc.
- Code rõ ràng hơn khi đọc `docker stop goals-app` thay vì `docker stop a3f2b1c`.

---

## 2. Gắn Tag Cho Image

Khi build image, sử dụng cờ `-t` để gắn tag:

```bash
# Cú pháp: docker build -t <tên>:<tag> .

docker build -t goals:latest .
docker build -t my-app:v1 .
docker build -t my-app:v2 .
```

**Cấu trúc tag:** `repository:tag` (ví dụ: `node:14`, `my-app:v1`)

Tag bao gồm hai phần:
- **Repository** (tên): Nhóm tổng quát của image.
- **Tag** (phiên bản): Phiên bản cụ thể trong nhóm đó.

---

## 3. Hệ Thống Tags Trên Docker Hub

Trên Docker Hub, một image có thể có nhiều tags khác nhau:

```bash
docker pull node:14
docker pull node:20-alpine
docker pull node:lts
docker pull node:slim
```

Mỗi tag đại diện cho một phiên bản, cấu hình hoặc biến thể khác nhau của cùng một base image. Việc chọn đúng tag giúp bạn:
- Xác định phiên bản runtime cụ thể.
- Chọn biến thể nhẹ hơn (alpine, slim).
- Tránh bất ngờ khi `:latest` thay đổi.

---

## 4. Best Practices

| Nguyên tắc | Ví dụ |
|-----------|-------|
| Luôn dùng tag cụ thể | `node:20-alpine` thay vì `node` |
| Versioning rõ ràng | `my-app:v1`, `my-app:v2` |
| Tránh lạm dụng `:latest` | `:latest` thay đổi liên tục → nguy hiểm trên production |
| Đặt tên có ý nghĩa | `goals-app` thay vì `container1` |

---

## 5. Tổng Kết

- `--name` đặt tên cho container — giúp quản lý dễ dàng hơn.
- `-t` gắn tag cho image — hỗ trợ versioning và organization.
- Luôn dùng tag cụ thể trên production, tránh `:latest`.
- Hệ thống tag `repository:tag` giúp组织 nhiều phiên bản của cùng một image.
