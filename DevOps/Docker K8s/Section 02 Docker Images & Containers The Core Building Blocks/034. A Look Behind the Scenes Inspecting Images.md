# Khám Phá Bên Trong Image: Lệnh `docker image inspect`

Ở bài trước, chúng ta đã học cách xóa images và containers. Hôm nay, chúng ta sẽ "mở nắp" một image ra để xem bên trong nó chứa những gì — bằng lệnh `docker image inspect`.

---

## 1. Lệnh Inspect Là Gì?

`docker image inspect` cho bạn cái nhìn chi tiết về cấu trúc, cấu hình và metadata của một image.

```bash
docker image inspect <image_id_or_name>
```

Lệnh này trả về một output khá dài dạng JSON. Hãy cùng đi qua các phần quan trọng.

---

## 2. Thông Tin Quan Trọng Từ Inspect

### Định Danh & Thời Gian

- **ID đầy đủ** của image (64 ký tự hexadecimal)
- **Ngày tạo** image

### Cấu Hình Container

Khi bạn chạy container từ image này, Docker sẽ sử dụng các cấu hình mặc định:
- **Ports** nào được expose
- **Environment variables** nào được thiết lập
- **Entrypoint** hoặc **CMD** mặc định

### Hệ Điều Hành Base

Bạn sẽ thấy image này được xây dựng trên nền tảng OS nào (ví dụ: Debian, Alpine, Ubuntu).

### Các Layers

Đây là phần thú vị nhất! Bạn sẽ thấy **tất cả các layers** tạo nên image, bao gồm cả layers từ base image. Mỗi layer tương ứng với một chỉ thị trong Dockerfile (hoặc từ base image).

```bash
# Ví dụ inspect node image
docker image inspect node
```

---

## 3. Khi Nào Cần Dùng Inspect?

- Kiểm tra ports, environment variables mặc định của image trước khi chạy.
- Xem base OS của image (để biết có an toàn không).
- Debug khi container chạy không như mong đợi — inspect image để xem cấu hình gốc.
- Khi pull image từ nguồn không rõ ràng — kiểm tra xem bên trong có gì.

---

## 4. Tổng Kết

- `docker image inspect` cho bạn cái nhìn toàn cảnh về cấu trúc image.
- Bạn có thể xem ID, ngày tạo, ports, env vars, layers, và base OS.
- Hữu ích cho debugging và kiểm tra security trước khi sử dụng image mới.
