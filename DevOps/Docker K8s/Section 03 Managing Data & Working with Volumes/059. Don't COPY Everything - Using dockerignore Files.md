# Không COPY Mọi Thứ: Sử Dụng .dockerignore Hiệu Quả

## Giới thiệu

Instruction `COPY . .` trong Dockerfile copy **tất cả** file từ thư mục project vào image. Nhưng thực tế có nhiều file không cần thiết (hoặc không nên) copy vào image.

## Vấn đề với COPY . .

Khi chạy `COPY . .`, Docker sẽ copy:
- Source code cần thiết
- **node_modules/** (nếu tồn tại trên host)
- File .git/
- File .env chứa secrets
- File tạm thời, log, và nhiều thứ không cần thiết

Điều này dẫn đến:
- **Image lớn hơn** cần thiết
- **Build chậm hơn** vì copy quá nhiều
- **Rủi ro bảo mật** nếu copy nhầm file secrets

## Giải pháp: .dockerignore

Tạo file `.dockerignore` trong thư mục project (cùng cấp với Dockerfile):

```
node_modules
.git
.env
*.log
Dockerfile
docker-compose.yml
```

## Tại sao cần ignore node_modules?

```
node_modules  # Prevent copying local dependencies
```

Nếu copy `node_modules/` từ host vào image:
1. Node dependencies trên host có thể **khác版本** so với trong image
2. Quá trình `npm install` trong image sẽ bị vô hiệu hóa
3. Có thể gây conflict và lỗi không mong muốn

## Các entry phổ biến trong .dockerignore

```
# Dependencies
node_modules

# Version control
.git
.gitignore

# Environment files
.env
.env.*

# IDE files
.vscode
.idea
*.swp
*.swo

# System files
.DS_Store
Thumbs.db

# Docker files
Dockerfile
docker-compose.yml
```

## Lợi ích

1. **Image nhỏ hơn**: Giảm đáng kể dung lượng image
2. **Build nhanh hơn**: Docker không cần xử lý file không cần thiết
3. **Bảo mật hơn**: Tránh copy nhầm secrets
4. **Layer cache tốt hơn**: Ít thay đổi hơn trong build context
