# Mở Rộng .dockerignore: Các Entry Quan Trọng Bổ Sung

## Giới thiệu

Ngoài `node_modules`, có nhiều file và thư mục khác bạn nên thêm vào `.dockerignore` để tối ưu hóa Docker image.

## Các entry quan trọng cần thêm

```
# Docker files - không cần copy vào image
Dockerfile
docker-compose.yml
docker-compose.yaml

# Git - không cần trong production
.git
.gitignore

# IDE và editor files
.vscode
.idea
*.swp
*.swo
*~

# System files
.DS_Store
Thumbs.db

# Logs
*.log
logs/

# Test files
coverage/
.nyc_output/
__tests__/
*.test.js
*.spec.js

# Build artifacts
dist/
build/
.cache/

# Documentation (không cần cho runtime)
README.md
CHANGELOG.md
LICENSE
docs/
```

## Mẹo quan trọng

1. **Luôn thêm Dockerfile**: File này không cần thiết trong image
2. **Thêm .git**: Thư mục git có thể rất lớn và không cần cho runtime
3. **Ignore secrets**: Thêm `.env` và tất cả biến thể `.env.*`
4. **Sử dụng wildcard**: `*.log` để ignore tất cả file log

## Kiểm tra kết quả

Sau khi thêm `.dockerignore`, chạy `docker build` và so sánh:
- Kích thước image nhỏ hơn
- Build context nhanh hơn
- Ít layer hơn

## Checklist trước khi commit .dockerignore

1. Chạy `docker build .` và kiểm tra kích thước context
2. Kiểm tra image với `docker history` — không nên thấy .git hay .env
3. Verify không có secrets trong image: `docker run --rm <image> env`
4. Commit file `.dockerignore` — đừng把它加入 `.gitignore`
