# Quản Lý Docker Volumes: Các Lệnh Cần Thiết

## Giới thiệu

Docker cung cấp nhiều lệnh để quản lý volumes. Hiểu rõ các lệnh này giúp bạn kiểm soát hoàn toàn dữ liệu trong containers.

## Các lệnh cơ bản

```bash
# Liệt kê tất cả volumes
docker volume ls

# Tạo volume mới
docker volume create my-volume

# Kiểm tra chi tiết volume
docker volume inspect my-volume

# Xóa volume cụ thể
docker volume rm my-volume

# Xóa tất cả volumes không sử dụng
docker volume prune
```

## Phân tích output `docker volume ls`

```
DRIVER    VOLUME NAME
local     feedback
local     a1b2c3d4e5f6...
```

- **Named volume**: Tên rõ ràng (feedback)
- **Anonymous volume**: Tên hash ngẫu nhiên (a1b2c3d4e5f6...)
- **Bind mount**: Không xuất hiện trong danh sách (vì không phải Docker-managed)

## Phân tích `docker volume inspect`

```json
[
  {
    "CreatedAt": "2026-08-28T10:00:00Z",
    "Driver": "local",
    "Mountpoint": "/var/lib/docker/volumes/feedback/_data",
    "Name": "feedback",
    "Scope": "local"
  }
]
```

- **Mountpoint**: Đường dẫn thực tế trên host (trong VM của Docker Desktop)
- **Driver**: Loại storage driver (thường là `local`)

## Lưu ý quan trọng

1. **Xóa volume = mất dữ liệu**: Không thể khôi phục sau khi xóa
2. **Volume đang dùng không thể xóa**: Phải dừng container trước
3. **Bind mount không quản lý bởi Docker**: Không xuất hiện trong `docker volume ls`
4. **Docker tự tạo volume**: Nếu volume chưa tồn tại khi chạy container

## Best practices

- Luôn dùng `docker volume ls` trước khi prune
- Backup quan trọng bằng cách copy data ra host
- Dùng named volume thay vì anonymous volume cho production
