# Dockerize Ứng Dụm Demo: Hướng Dẫn Từng Bước

## Giới thiệu

Sau khi đã hiểu cấu trúc ứng dụng Feedback App, giờ chúng ta sẽ cùng **dockerize** ứng dụng này. Nếu bạn đã quen với Dockerfile, đây sẽ là bài thực hành rất quan trọng.

## Tạo Dockerfile

```dockerfile
FROM node:14

WORKDIR /app

COPY package.json .
RUN npm install

COPY . .

EXPOSE 80

CMD ["node", "server.js"]
```

Giải thích từng bước:
- **`FROM node:14`**: Dùng image Node.js phiên bản 14 làm base
- **`WORKDIR /app`**: Đặt thư mục làm việc là `/app`
- **`COPY package.json .`**: Copy file dependencies trước để tận dụng layer cache
- **`RUN npm install`**: Cài đặt các dependencies
- **`COPY . .`**: Copy toàn bộ source code vào image
- **`EXPOSE 80`**: Khai báo port 80
- **`CMD ["node", "server.js"]`**: Lệnh chạy khi container khởi động

## Build và chạy container

```bash
# Build image
docker build -t feedback-node .

# Chạy container
docker run -d -p 3000:80 --name feedback-app feedback-node
```

## Kiểm tra hoạt động

Truy cập `http://localhost:3000`, bạn sẽ thấy form nhập feedback. Nhập "awesome" và submit — file `awesome.txt` sẽ được tạo trong thư mục `feedback/` bên trong container.

Quan trọng: File này **chỉ tồn tại trong container**. Nếu bạn kiểm tra thư mục `feedback/` trên máy host, bạn sẽ không thấy nó. Đây là cơ chế cô lập (isolation) cơ bản của Docker.
