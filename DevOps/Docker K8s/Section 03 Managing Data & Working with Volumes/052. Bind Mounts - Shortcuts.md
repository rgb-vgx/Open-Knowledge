# Bind Mounts Shortcut: Tiết Kiệm Thời Gian Gõ Lệnh

## Giới thiệu

Việc gõ đường dẫn tuyệt đối mỗi lần chạy container rất dài và bất tiện. May mắn thay, Docker hỗ trợ một số shortcut giúp bạn viết nhanh hơn.

## Shortcut theo hệ điều hành

**macOS / Linux:**
```bash
docker run -v $(pwd):/app ...
```

Lệnh `$(pwd)` trả về đường dẫn thư mục hiện tại (print working directory).

**Windows (Command Prompt):**
```bash
docker run -v "%cd%":/app ...
```

**Windows (PowerShell):**
```bash
docker run -v "${PWD}":/app ...
```

## Ví dụ thực tế

```bash
# Thay vì gõ đường dẫn dài
docker run -v /Users/maith/Documents/my-project:/app ...

# Dùng shortcut
docker run -v $(pwd):/app ...
```

## Lưu ý quan trọng

- Shortcut chỉ hoạt động khi bạn đang ở thư mục project
- Nếu dùng bind mount với `--mount` flag thay vì `-v`, cú pháp sẽ khác
- Trong hầu hết trường hợp, bạn nên dùng `-v` flag vì đơn giản hơn

## Mẹo thực tế

Tạo alias trong shell để tiết kiệm thời gian hơn nữa:

```bash
# Thêm vào ~/.bashrc hoặc ~/.zshrc
alias drun='docker run -v $(pwd):/app'
```

Sau đó bạn chỉ cần:
```bash
drun -p 3000:80 feedback-node
```

Shortcut này đặc biệt hữu ích khi bạn thường xuyên chạy nhiều container với bind mount từ cùng một thư mục project.
