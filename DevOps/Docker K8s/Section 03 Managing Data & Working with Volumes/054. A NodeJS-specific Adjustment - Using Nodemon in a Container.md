# Sử Dụng Nodemon Trong Container: Tự Động Restart Khi Thay Đổi Code

## Giới thiệu

Với bind mount, thay đổi HTML/CSS sẽ tự động cập nhật trong container. Nhưng với **JavaScript code** (server.js), bạn cần **khởi động lại server** để thay đổi có hiệu lực. Trong Docker, điều này khá bất tiện.

Giải pháp: **Nodemon** — công cụ theo dõi file và tự động restart Node.js server khi code thay đổi.

## Cài đặt Nodemon

Thêm vào `package.json`:

```json
{
  "devDependencies": {
    "nodemon": "^2.0.4"
  },
  "scripts": {
    "start": "nodemon server.js"
  }
}
```

## Cập nhật Dockerfile

```dockerfile
FROM node:14
WORKDIR /app
COPY package.json .
RUN npm install
COPY . .
EXPOSE 80
CMD ["npm", "start"]  # Thay vì node server.js
```

## Build và chạy

```bash
docker build -t feedback-node:nodemon .
docker run -d -p 3000:80 --rm \
  -v feedback:/app/feedback \
  -v "$(pwd)":/app \
  -v /app/node_modules \
  --name feedback-app \
  feedback-node:nodemon
```

## Kết quả

Bây giờ khi thay đổi `server.js`, Nodemon sẽ **tự động restart** server. Bạn có thể kiểm tra bằng cách thêm `console.log()` và xem output:

```bash
docker logs feedback-app
```

## Lưu ý cho Windows/WSL2

Nếu dùng Docker trên Windows với WSL2, file changes có thể không được detect. Giải pháp:

1. Lưu project trong **Linux file system** (không phải `/mnt/c/`)
2. Truy cập Linux file system qua `\\wsl$\Ubuntu\home\username\`
3. Hoặc bật ** VirtioFS ** trong Docker Desktop settings

## Tại sao dùng npm start thay vì node server.js?

- `npm start` chạy script `"start": "nodemon server.js"` trong `package.json`
- Nodemon theo dõi file changes và tự động restart
- Giúp quá trình phát triển mượt mà hơn nhiều
