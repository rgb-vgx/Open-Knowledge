# Bắt Đầu Với Bind Mounts: Chia Sẻ Code Từ Host Lên Container

## Giới thiệu

Named Volumes giúp dữ liệu tồn tại vĩnh viễn, nhưng có một vấn đề khác trong quá trình phát triển: **khi thay đổi source code trên host, container không tự động cập nhật**. Bạn phải rebuild image mỗi lần thay đổi — rất bất tiện.

**Bind Mounts** giải quyết vấn đề này bằng cách kết nối trực tiếp thư mục source code trên host với thư mục trong container.

## Bind Mount hoạt động như thế nào?

Khác với volumes (Docker tự quản lý), bind mounts cho phép bạn **chỉ định đường dẫn cụ thể** trên host machine:

```bash
docker run -d -p 3000:80 --rm \
  -v feedback:/app/feedback \
  -v "/path/to/your/project":/app \
  --name feedback-app \
  feedback-node:volumes
```

Trong đó:
- `-v "/path/to/your/project":/app`: Mount toàn bộ thư mục project từ host vào `/app` trong container
- Đây là **bind mount** vì phần trước dấu `:` là đường dẫn tuyệt đối trên host

## Kết quả

Bây giờ khi bạn chỉnh sửa file HTML hoặc CSS trên host, thay đổi sẽ **tự động xuất hiện** trong container mà không cần rebuild image!

## Vấn đề: node_modules bị ghi đè

Tuy nhiên, bind mount sẽ gây ra lỗi `Cannot find module 'express'` vì:

1. Thư mục project trên host **không có** `node_modules/`
2. Bind mount ghi đè toàn bộ nội dung `/app` trong container
3. Folder `node_modules/` (được tạo bởi `npm install` trong image) bị xóa

## Giải pháp: Anonymous Volume kết hợp Bind Mount

```bash
docker run -d -p 3000:80 --rm \
  -v feedback:/app/feedback \
  -v "/path/to/your/project":/app \
  -v /app/node_modules \
  --name feedback-app \
  feedback-node:volumes
```

Anonymous volume `/app/node_modules` đảm bảo thư mục dependencies **không bị ghi đè** bởi bind mount.

## Cú pháp ngắn gọn

**macOS/Linux:**
```bash
-v $(pwd):/app
```

**Windows:**
```bash
-v "%cd%":/app
```

## Lưu ý quan trọng

- Bind mount **phải dùng đường dẫn tuyệt đối** trên host
- Docker cần quyền truy cập thư mục được mount (kiểm tra Docker Desktop > Settings > Resources > File Sharing)
- Bind mount **chỉ nên dùng trong development**, không dùng trong production
