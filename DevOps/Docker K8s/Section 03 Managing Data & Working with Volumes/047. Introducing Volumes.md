# Docker Volumes: Giải Pháp Lưu Trữ Dữ Liệu Vĩnh Viễn

## Giới thiệu

Vấn đề dữ liệu bị mất khi container xóa đã rõ ràng. Docker cung cấp một tính năng tích hợp sẵn called **Volumes** để giải quyết triệt để vấn đề này.

## Volumes là gì?

Volumes là **thư mục trên máy host** (không phải trong container hay image) được **mounted** (ghép nối) vào thư mục bên trong container. Khi bạn thêm một volume, Docker sẽ:

1. Tạo một thư mục trên máy host
2. Ghép nối thư mục đó với đường dẫn cụ thể trong container
3. Dữ liệu ghi vào đường dẫn trong container sẽ được lưu ra thư mục trên host

## Volumes hoạt động như thế nào?

Khác với `COPY` trong Dockerfile (chỉ copy snapshot một lần duy nhất), Volumes tạo **kết nối liên tục** giữa host và container:

- File thêm trên host → xuất hiện trong container
- File thêm trong container → xuất hiện trên host

Và điều quan trọng nhất: **Volumes tồn tại vĩnh viễn** ngay cả khi container bị xóa!

## Có gì khác so với COPY?

| COPY | Volume |
|------|--------|
| Copy snapshot một lần | Kết nối liên tục |
| Không thể thay đổi sau khi build | Dữ liệu đồng bộ real-time |
| Dữ liệu nằm trong image (read-only) | Dữ liệu nằm trên host (read-write) |

## Types of Volumes

Docker hỗ trợ 2 loại volume chính:

1. **Anonymous Volume**: Tự động tạo, tên ngẫu nhiên, gắn liền với container
2. **Named Volume**: Bạn đặt tên, tồn tại vĩnh viễn, chia sẻ giữa nhiều container

Và một cơ chế bổ sung:
3. **Bind Mount**: Bạn chỉ định đường dẫn cụ thể trên host machine

Ta sẽ tìm hiểu chi tiết từng loại trong các bài tiếp theo.
