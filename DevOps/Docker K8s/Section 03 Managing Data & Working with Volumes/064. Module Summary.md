# Tóm Tắt Module: Quản Lý Dữ Liệu và Volumes Trong Docker

## Tổng quan

Module này đã cung cấp kiến thức toàn diện về quản lý dữ liệu trong Docker — từ phân loại dữ liệu đến sử dụng volumes, bind mounts, và environment variables.

## Kiến thức chính đã học

### 1. Phân loại dữ liệu
- **Dữ liệu ứng dụng**: Source code — read-only, lưu trong image
- **Dữ liệu tạm thời**: Được tạo khi chạy — OK nếu mất
- **Dữ liệu vĩnh viễn**: Cần persist — phải dùng volumes

### 2. Docker Volumes
- **Anonymous volume**: Tự động tạo, mất khi container xóa (với --rm)
- **Named volume**: Đặt tên, tồn tại vĩnh viễn, chia sẻ được
- **Bind mount**: Đường dẫn host cụ thể, dùng trong development

### 3. Dockerfile instructions
- **COPY**: Tạo snapshot code cho production image
- **VOLUME**: Khai báo anonymous volume trong Dockerfile
- **ENV**: Đặt biến môi trường với giá trị mặc định
- **ARG**: Truyền tham số khi build image

### 4. Bảo mật
- Không đặt secrets trong Dockerfile
- Sử dụng .env files và --env-file
- Luôn thêm .dockerignore

## Bảng tóm tắt các lệnh

| Lệnh | Mục đích |
|-------|----------|
| `docker volume ls` | Liệt kê volumes |
| `docker volume create` | Tạo volume mới |
| `docker volume rm` | Xóa volume |
| `docker volume prune` | Xóa volumes không dùng |
| `docker volume inspect` | Xem chi tiết volume |

## Best Practices

1. **Named volume cho production data**: Luôn dùng cho database, user uploads
2. **Bind mount cho development**: Live code updates khi phát triển
3. **Anonymous volume cho node_modules**: Tránh ghi đè bind mount
4. **.dockerignore**: Giảm kích thước image và bảo mật
5. **Environment variables**: Tách biệt cấu hình khỏi code

## Kết luận

Quản lý dữ liệu là kỹ năng cốt lõi khi làm việc với Docker. Với kiến thức từ module này, bạn có thể:
- Lưu trữ dữ liệu vĩnh viễn an toàn
- Phát triển hiệu quả với live code updates
- Tạo images linh hoạt với environment variables
- Bảo mật secrets và credentials

Hãy thực hành thường xuyên để củng cố kiến thức!
