# Biến Môi Trường và .env Files: Tạo Containers Linh Hoạt Hơn

## Giới thiệu

Cho đến giờ, mọi giá trị trong Dockerfile đều bị **hardcode** (viết cứng). Nhưng thực tế, bạn cần sự linh hoạt — ví dụ: port 80 cho production nhưng port 8000 cho development.

Docker hỗ trợ **biến môi trường (environment variables)** để giải quyết vấn đề này.

## Cách sử dụng ENV trong Dockerfile

```dockerfile
# Khai báo biến môi trường với giá trị mặc định
ENV PORT=80

# Sử dụng biến trong các instruction
EXPOSE $PORT

# Sử dụng trong code
CMD ["node", "server.js"]
```

## Truy cập biến môi trường trong Node.js

```javascript
const port = process.env.PORT || 80;
server.listen(port);
```

## Ghi đè giá trị khi chạy container

```bash
# Dùng giá trị mặc định (port 80)
docker run -d -p 3000:80 feedback-node

# Ghi đè port thành 8000
docker run -d -p 3000:8000 -e PORT=8000 feedback-node
```

Cú pháp:
- `-e PORT=8000` hoặc `--env PORT=8000`
- Có thể thêm nhiều biến: `-e PORT=8000 -e NODE_ENV=development`

## Sử dụng file .env

Thay vì gõ từng biến, bạn có thể dùng file `.env`:

```
# File .env
PORT=8000
NODE_ENV=development
```

```bash
docker run -d -p 3000:8000 --env-file .env feedback-node
```

## Lợi ích

1. **Không hardcode**: Thay đổi cấu hình mà không sửa Dockerfile
2. **Tách biệt cấu hình**: Code và cấu hình riêng biệt
3. **Tái sử dụng**: Cùng image chạy được nhiều môi trường
4. **Bảo mật更好**: Secrets không nằm trong Dockerfile

## So sánh các cách truyền biến

| Cách | Ví dụ | Dùng khi nào |
|------|-------|--------------|
| `ENV` trong Dockerfile | `ENV PORT=80` | Giá trị mặc định |
| `-e` khi `docker run` | `-e PORT=8000` | Ghi đè tạm thời |
| `--env-file` | `--env-file .env` | Nhiều biến cùng lúc |
