# Bắt Đầu Với AWS: Tạo Tài Khoản và Làm Quen

Trong module này, chúng ta sẽ sử dụng AWS làm ví dụ minh họa. Tuy nhiên, cần lưu ý rằng AWS chỉ là một trong nhiều cloud provider. Nếu bạn muốn sử dụng Azure, Google Cloud hay các dịch vụ khác, bạn có thể tìm kiếm "Azure Managed Kubernetes" hoặc "Google Kubernetes Engine" để có được hướng dẫn tương tự.

Điểm quan trọng là: **ứng dụng Kubernetes chúng ta triển khai sẽ luôn giống nhau**, dù sử dụng bất kỳ cloud provider nào.

## Bước 1: Tạo tài khoản AWS

1. Truy cập [aws.amazon.com](https://aws.amazon.com)
2. Click "Create an AWS Account"
3. Làm theo các bước hướng dẫn
4. **Lưu ý**: Bạn cần thẻ tín dụng để đăng ký

Nếu bạn đã có tài khoản AWS từ phần deployment trước, có thể sử dụng lại tài khoản đó.

## Bước 2: Đăng nhập vào AWS Console

Sau khi đăng nhập, bạn sẽ thấy màn hình bắt đầu. Giao diện có thể thay đổi theo thời gian, nhưng bạn sẽ thấy:
- Thanh tìm kiếm services ở trên
- Danh sách các dịch vụ AWS

## Bước 3: Tìm AWS EKS

1. Trong thanh tìm kiếm, nhập **"EKS"**
2. Chọn **Elastic Kubernetes Service** từ kết quả
3. Bạn sẽ được đưa đến trang quản lý EKS

## Cài đặt AWS CLI

AWS CLI (Command Line Interface) là công cụ cho phép bạn chạy các lệnh từ terminal để tương tác với tài khoản AWS.

### Tải và cài đặt

Truy cập trang chính thức của AWS CLI và tải installer phù hợp với hệ điều hành:
- Windows: MSI installer
- macOS: pkg installer  
- Linux: zip hoặc package manager

### Cấu hình AWS CLI

Sau khi cài đặt, bạn cần cấu hình để kết nối với tài khoản AWS:

1. Vào AWS Console → Click tên tài khoản (góc trên bên phải) → **My Security Credentials**
2. Tab **Access Keys** → **Create New Access Key**
3. Download file chứa Access Key ID và Secret Access Key
4. Mở terminal và chạy:

```bash
aws configure
```

5. Nhập các thông tin:
   - **AWS Access Key ID**: Từ file vừa download
   - **AWS Secret Access Key**: Từ file vừa download
   - **Default region name**: Chọn region phù hợp (ví dụ: `us-east-1`, `us-east-2`)
   - **Default output format**: Nhấn Enter (để trống)

## Kiểm tra cài đặt

Chạy lệnh sau để kiểm tra AWS CLI hoạt động đúng:

```bash
aws sts get-caller-identity
```

Nếu hoạt động đúng, bạn sẽ thấy thông tin về tài khoản AWS của mình.

## Cấu hình kubectl cho EKS

Trước khi sử dụng minikube, `kubectl` được cấu hình để nói chuyện với cluster minikube. Bây giờ, chúng ta cần thay đổi cấu hình này để nói chuyện với cluster EKS.

### Sao lưu cấu hình minikube hiện tại

```bash
# Lưu cấu hình minikube
cp ~/.kube/config ~/.kube/config.minikube
```

### Cập nhật cấu hình cho EKS

Sau khi cluster EKS được tạo (section tiếp theo), chạy lệnh:

```bash
aws eks update-kubeconfig \
  --region [region-cua-ban] \
  --name [ten-cluster]
```

Ví dụ:
```bash
aws eks update-kubeconfig \
  --region us-east-2 \
  --name kub-dep-demo
```

Lệnh này sẽ cập nhật file `~/.kube/config` với thông tin kết nối đến cluster EKS.

## Kiểm tra kết nối

Sau khi cập nhật cấu hình:

```bash
# Kiểm tra kết nối đến cluster EKS
kubectl get pods
kubectl get nodes
```

Lúc này, `kubectl` sẽ gửi lệnh đến cluster EKS thay vì minikube.

Bạn có thể xóa minikube cluster mà không ảnh hưởng đến EKS:

```bash
minikube delete
```

Và `kubectl get pods` vẫn hoạt động bình thường vì giờ đây nó kết nối đến EKS cluster.

Với AWS CLI và kubectl đã được cấu hình, chúng ta đã sẵn sàng để tạo cluster EKS trong section tiếp theo.
