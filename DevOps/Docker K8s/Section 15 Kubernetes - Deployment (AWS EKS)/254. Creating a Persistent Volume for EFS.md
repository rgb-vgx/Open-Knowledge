# Tạo Persistent Volume Cho Amazon EFS

Bây giờ chúng ta sẽ cấu hình Kubernetes để sử dụng EFS làm volume. Quy trình bao gồm: tạo StorageClass, PersistentVolume, và PersistentVolumeClaim.

## Bước 1: Tạo StorageClass

Mở file `users.yaml` và thêm definition sau **phía trên** PersistentVolume (trước service):

```yaml
---
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: efs-sc
provisioner: efs.csi.aws.com
```

StorageClass này chỉ định CSI driver nào sẽ được sử dụng để quản lý storage.

## Bước 2: Tạo PersistentVolume

Thêm PersistentVolume definition vào file `users.yaml`, **giữa** StorageClass và Service:

```yaml
---
apiVersion: v1
kind: PersistentVolume
metadata:
  name: efs-pv
spec:
  capacity:
    storage: 5Gi
  volumeMode: Filesystem
  accessModes:
    - ReadWriteMany
  storageClassName: efs-sc
  persistentVolumeReclaimPolicy: Retain
  csi:
    driver: efs.csi.aws.com
    volumeHandle: fs-0123456789abcdef0  # Thay bằng File System ID của bạn
```

### Giải thích các trường:

| Trường | Giá trị | Ý nghĩa |
|--------|---------|----------|
| `capacity.storage` | 5Gi | Dung lượng (với EFS, giá trị này không quan trọng) |
| `volumeMode` | Filesystem | Chế độ卷 - phải là Filesystem cho EFS |
| `accessModes` | ReadWriteMany | Nhiều nodes có thể truy cập cùng lúc |
| `storageClassName` | efs-sc | Liên kết với StorageClass ở trên |
| `persistentVolumeReclaimPolicy` | Retain | Giữ lại PV khi PVC bị xóa |
| `csi.driver` | efs.csi.aws.com | EFS CSI driver |
| `csi.volumeHandle` | fs-xxx | File System ID từ AWS |

## Bước 3: Tạo PersistentVolumeClaim

Thêm PVC definition vào file `users.yaml`, **giữa** PersistentVolume và Service:

```yaml
---
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: efs-pvc
spec:
  accessModes:
    - ReadWriteMany
  storageClassName: efs-sc
  resources:
    requests:
      storage: 5Gi
```

### Lưu ý quan trọng:
- `storageClassName` phải **giống hệt** StorageClass trong PersistentVolume
- `accessModes` phải **khớp** với PersistentVolume

## Bước 4: Mount Volume vào Pod

Trong Deployment definition của `users.yaml`, thêm `volumes` và `volumeMounts`:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: users-deployment
spec:
  replicas: 2
  selector:
    matchLabels:
      app: users
  template:
    metadata:
      labels:
        app: users
    spec:
      containers:
        - name: users
          image: [tên-tài-kho]/kub-dep-users
          ports:
            - containerPort: 3000
          env:
            - name: MONGODB_CONNECTION_URI
              value: "[connection-string-cua-ban]"
            - name: AUTH_SERVICE_ADDRESS
              value: "http://auth-service.default.svc.cluster.local:3000"
          volumeMounts:
            - name: efs-vol
              mountPath: /app/users
      volumes:
        - name: efs-vol
          persistentVolumeClaim:
            claimName: efs-pvc
```

### Giải thích:

- **`volumeMounts`**: Mount volume vào container
  - `name`: Tên volume (phải khớp với volumes ở dưới)
  - `mountPath`: Đường dẫn trong container (`/app/users`)

- **`volumes`**: Định nghĩa volume cho pod
  - `name`: Tên volume để reference
  - `persistentVolumeClaim.claimName`: Tên PVC đã tạo

## Cấu trúc hoàn chỉnh của users.yaml

```yaml
---
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: efs-sc
provisioner: efs.csi.aws.com
---
apiVersion: v1
kind: PersistentVolume
metadata:
  name: efs-pv
spec:
  capacity:
    storage: 5Gi
  volumeMode: Filesystem
  accessModes:
    - ReadWriteMany
  storageClassName: efs-sc
  persistentVolumeReclaimPolicy: Retain
  csi:
    driver: efs.csi.aws.com
    volumeHandle: fs-0123456789abcdef0
---
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: efs-pvc
spec:
  accessModes:
    - ReadWriteMany
  storageClassName: efs-sc
  resources:
    requests:
      storage: 5Gi
---
apiVersion: v1
kind: Service
metadata:
  name: users-service
spec:
  selector:
    app: users
  type: LoadBalancer
  ports:
    - protocol: TCP
      port: 80
      targetPort: 3000
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: users-deployment
spec:
  replicas: 2
  selector:
    matchLabels:
      app: users
  template:
    metadata:
      labels:
        app: users
    spec:
      containers:
        - name: users
          image: [tên-tài-kho]/kub-dep-users
          ports:
            - containerPort: 3000
          env:
            - name: MONGODB_CONNECTION_URI
              value: "[connection-string]"
            - name: AUTH_SERVICE_ADDRESS
              value: "http://auth-service.default.svc.cluster.local:3000"
          volumeMounts:
            - name: efs-vol
              mountPath: /app/users
      volumes:
        - name: efs-vol
          persistentVolumeClaim:
            claimName: efs-pvc
```

## Lưu ý trước khi deploy

1. Đảm bảo thư mục `users` tồn tại trong image (empty folder)
2. Build lại image và push lên Docker Hub
3. Thay thế File System ID trong PersistentVolume
