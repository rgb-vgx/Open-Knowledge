# Giải Pháp Thách Thức: Hướng Dẫn Triển Khai Tasks API

Bạn đã thử thách bản thân chưa? Bây giờ chúng ta sẽ giải quyết cùng nhau.

## Bước 1: Tạo file Tasks YAML

Tạo file `tasks.yaml` trong thư mục `kubernetes/`:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: tasks-deployment
spec:
  replicas: 1
  selector:
    matchLabels:
      app: task
  template:
    metadata:
      labels:
        app: task
    spec:
      containers:
        - name: tasks-api
          image: academind/kub-dep-tasks
          ports:
            - containerPort: 3000
          env:
            - name: MONGODB_CONNECTION_URI
              value: "[connection-string-cua-ban]"
            - name: AUTH_API_ADDRESS
              value: "http://auth-service.default.svc.cluster.local:3000"
---
apiVersion: v1
kind: Service
metadata:
  name: tasks-service
spec:
  selector:
    app: task
  type: LoadBalancer
  ports:
    - protocol: TCP
      port: 80
      targetPort: 3000
```

## Bước 2: Build và Push tất cả images

```bash
# Build Tasks API
cd tasks-api
docker build -t academind/kub-dep-tasks .
docker push academind/kub-dep-tasks

# Rebuild Auth API (code đã thay đổi)
cd ../auth-api
docker build -t academind/kub-dep-auth .
docker push academind/kub-dep-auth

# Rebuild Users API (code đã thay đổi)
cd ../users-api
docker build -t academind/kub-dep-users .
docker push academind/kub-dep-users
```

## Bước 3: Deploy Tasks API

```bash
cd kubernetes
kubectl apply -f tasks.yaml
```

## Bước 4: Cập nhật Auth và Users deployments

Vì code đã thay đổi, cần xóa deployments cũ và tạo lại:

```bash
# Xóa deployments cũ
kubectl delete deployment users-deployment
kubectl delete deployment auth-deployment

# Áp dụng lại
kubectl apply -f users.yaml
kubectl apply -f auth.yaml
```

## Bước 6: Test toàn bộ hệ thống

### 1. Tạo user mới

```http
POST http://[USERS-EXTERNAL-IP]/signup
Content-Type: application/json

{
  "email": "test@test.com",
  "password": "testers"
}
```

### 2. Login để lấy token

```http
POST http://[USERS-EXTERNAL-IP]/login
Content-Type: application/json

{
  "email": "test@test.com",
  "password": "testers"
}
```

Copy token từ response.

### 3. Test Tasks API

```http
# Lấy danh sách tasks (rỗng)
GET http://[TASKS-EXTERNAL-IP]/tasks
Authorization: Bearer [token]

# Tạo task mới
POST http://[TASKS-EXTERNAL-IP]/tasks

Authorization: Bearer [token]
```

## Tổng kết kiến thức đã áp dụng

Qua module này, bạn đã áp dụng:

1. **Triển khai Cluster**: Tạo EKS cluster với VPC, subnets
2. **Worker Nodes**: Thêm node groups với IAM roles
3. **kubectl Configuration**: Chuyển từ minikube sang EKS
4. **Deployments & Services**: Áp dụng cấu hình YAML
5. **LoadBalancer Service**: Tạo Application Load Balancer tự động
6. **Internal Communication**: Service-to-service communication qua DNS
7. **Persistent Storage**: EFS volume với CSI driver
8. **Multi-service Architecture**: Auth, Users, Tasks APIs
