# Thêm EFS Làm Volume Với CSI Driver

Trong section này, chúng ta sẽ cài đặt EFS CSI Driver vào cluster EKS và tạo Elastic File System để sử dụng làm volume cho ứng dụng.

## Bước 1: Cài đặt EFS CSI Driver

### Cài đặt qua manifest

Chạy lệnh sau trên terminal:

```bash
kubectl apply -k "github.com/kubernetes-sigs/aws-efs-csi-driver/deploy/kubernetes/overlays/stable?ref=release-2.2"
```

Hoặc sử dụng Helm:

```bash
# Thêm repo Helm
helm repo add aws-efs-csi-driver https://kubernetes-sigs.github.io/aws-efs-csi-driver/

# Cập nhật repo
helm repo update aws-efs-csi-driver

# Cài đặt driver
helm upgrade --install aws-efs-csi-driver \
  --namespace kube-system \
  aws-efs-csi-driver/aws-efs-csi-driver
```

### Kiểm tra cài đặt

```bash
kubectl get pods -n kube-system | grep efs
```

Bạn sẽ thấy các pods của EFS CSI driver đang chạy.

## Bước 2: Tạo Security Group cho EFS

Trước khi tạo EFS, cần tạo Security Group cho phép NFS traffic.

1. Mở **EC2 Console** → Tab **Security Groups**
2. Click **Create security group**
3. Cấu hình:
   - **Name**: `eks-efs`
   - **VPC**: Chọn VPC của cluster (eksVpc)
   - **Inbound rules** → **Add rule**:
     - Type: **NFS** (tự động điền port 2049)
     - Source: **Custom** → Nhập IPv4 CIDR của VPC
4. Click **Create security group`

### Lấy IPv4 CIDR của VPC

1. Mở **VPC Console** trong tab mới
2. Tìm VPC tên `eksVpc`
3. Copy **IPv4 CIDR** (ví dụ: `10.0.0.0/16`)
4. Dán vào trường Source trong inbound rule

## Bước 3: Tạo Elastic File System

1. Mở **EFS Console** trong tab mới
2. Click **Create file system**
3. Cấu hình:
   - **Name**: `eks-efs`
   - **VPC**: Chọn VPC của cluster
4. Click **Customize** (KHÔNG click Create ngay)

### Cấu hình Network Access

5. Tab **Network access**:
   - Xóa security group mặc định cho mỗi availability zone
   - Thay bằng security group `eks-efs` vừa tạo
   - Làm cho cả 2 availability zones
6. Click **Next**
7. Click **Next** (bỏ qua file system policy)
8. Click **Create**

### Lấy File System ID

Sau khi tạo xong:
1. Click vào file system vừa tạo
2. Copy **File System ID** (ví dụ: `fs-0123456789abcdef0`)
3. **Lưu lại ID này** - sẽ dùng trong phần sau

## Bước 4: Tạo IAM Role cho EFS CSI Driver

EFS CSI Driver cần quyền truy cập EFS:

1. Mở **IAM Console** → **Roles** → **Create role**
2. Chọn **Web identity** làm trusted entity
3. Cấu hình:
   - **Identity provider**: Chọn OIDC provider của cluster
   - **Audience**: `sts.amazonaws.com`
4. Click **Next**
5. Tạo policy mới với nội dung:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "elasticfilesystem:DescribeMountTargets",
        "elasticfilesystem:DescribeFileSystems",
        "elasticfilesystem:DescribeAccessPoints",
        "elasticfilesystem:CreateAccessPoint",
        "elasticfilesystem:DeleteAccessPoint"
      ],
      "Resource": "*"
    }
  ]
}
```

6. Gán policy này cho role
7. Đặt tên role (ví dụ: `EFS CSI Driver Role`)
8. Tạo role

## Xác minh

```bash
# Kiểm tra EFS CSI Driver pods
kubectl get pods -n kube-system | grep efs

# Kiểm tra storage classes (chưa có efs-sc)
kubectl get sc
```

Chúng ta đã cài đặt xong EFS CSI Driver. Section tiếp theo sẽ tạo Persistent Volume và Persistent Volume Claim để sử dụng EFS làm volume.
