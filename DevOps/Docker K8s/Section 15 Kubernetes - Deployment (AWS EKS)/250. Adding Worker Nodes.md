# Thêm Worker Nodes Vào Cluster EKS

Cluster EKS đã được tạo và `kubectl` đã được cấu hình. Tuy nhiên, một phần quan trọng vẫn còn thiếu: **worker nodes** - các máy tính thật sẽ chạy pods và containers của bạn.

## Bước 1: Tạo IAM Role cho Worker Nodes

Tương tự như cluster role, worker nodes cũng cần quyền hạn riêng. Các node cần quyền để:
- Ghi log files
- Kết nối đến các dịch vụ khác
- Pull container images từ registry

### Tạo Node Group Role

1. Mở **IAM Console** trong tab mới
2. Click **Roles** → **Create role**
3. Chọn **EC2** làm trusted entity
4. Click **Next**
5. Tìm và thêm các policies sau:
   - **AmazonEKSWorkerNodePolicy** - Quyền cơ bản cho worker nodes
   - **AmazonEKS_CNI_Policy** - Quyền cho CNI plugin (mạng)
   - **AmazonEC2ContainerRegistryReadOnly** - Quyền đọc từ ECR
6. Click **Next**
7. Đặt tên role (ví dụ: `EKSNodeGroupRole`)
8. Click **Create role**

## Bước 2: Tạo Node Group

1. Quay lại **EKS Console** → Chọn cluster của bạn
2. Tab **Compute** → Click **Add node group**
3. Đặt tên node group (ví dụ: `demo-dep-nodes`)
4. Chọn **IAM Role** vừa tạo
5. Click **Next**

### Cấu hình Instance

6. Chọn **AMI type** (để default)
7. **Instance type**: Chọn **t3.small** (hoặc lớn hơn)
   - **Lưu ý quan trọng**: Không chọn t3.micro vì có thể gây lỗi scheduling pods
   - T3.small có 2 vCPU và 2GB RAM
8. **Disk size**: Để default (20GB)
9. **Scaling config**:
   - Desired size: 2 (số node mong muốn)
   - Minimum size: 1
   - Maximum size: 4
10. Click **Next**

### Cấu hình Network

11. Chọn subnet (để default)
12. **Remote access**: Có thể tắt SSH access nếu không cần
13. Click **Next**

### Review và tạo

14. Kiểm tra tất cả settings
15. Click **Create**
16. Đợi node group Active (có thể mất 5-10 phút)

## Xác minh Worker Nodes

Sau khi node group Active:

```bash
# Kiểm tra nodes
kubectl get nodes
```

Bạn sẽ thấy 2 nodes mới với trạng thái `Ready`.

Kiểm tra trên EC2 Console:
1. Mở **EC2 Console**
2. Tab **Instances** - Bạn sẽ thấy các instances vừa được tạo
3. Đây là các worker nodes của cluster EKS

## Kiểm tra Load Balancers

Trên EC2 Console:
1. Tab **Load Balancers**
2. Hiện tại sẽ **chưa có load balancer nào**
3. Load Balancer sẽ tự động được tạo khi bạn deploy service type LoadBalancer

## Tóm tắt cấu trúc cluster

Sau khi hoàn tất, cluster của bạn bao gồm:

```
EKS Cluster
├── Control Plane (AWS quản lý)
├── VPC Network
├── Node Group
│   ├── Worker Node 1 (EC2 Instance)
│   └── Worker Node 2 (EC2 Instance)
└── Pods sẽ được distribute tự động bởi Kubernetes
```

Cluster đã sẵn sàng! Section tiếp theo, chúng ta sẽ áp dụng cấu hình Kubernetes để triển khai ứng dụng.
