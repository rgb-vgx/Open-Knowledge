# Bắt Đầu Với Volumes Trong Kubernetes

Ứng dụng đã chạy thành công trên cluster EKS. Bây giờ, chúng ta sẽ tìm hiểu về **Volumes** - cách lưu trữ dữ liệu持久化 trong Kubernetes.

## Tại sao cần Volumes?

Trong môi trường production, dữ liệu cần được lưu trữ持久化 (persistent) để không bị mất khi pods restart hoặc bị xóa. Ví dụ, nếu ứng dụng của bạn ghi log hoặc lưu trữ dữ liệu người dùng, bạn cần đảm bảo dữ liệu đó an toàn.

## Các loại Volume đã học

Trong các section trước, chúng ta đã sử dụng:
- **emptyDir**: Thư mục trống, tạo mới cho mỗi pod - không phù hợp cho production
- **hostPath**: Đường dẫn trên node - chỉ hữu ích khi có single node

## Vấn đề với hostPath trong multi-node cluster

Với cluster có nhiều nodes (như EKS cluster 2 nodes), hostPath có hạn chế:
- hostPath chỉ được tạo trên một node
- Pods có thể được schedule trên node khác
- Mỗi node sẽ có dữ liệu riêng biệt trên ổ cứng

Vì vậy, hostPath chủ yếu hữu ích trong phát triển với single node.

## CSI Volume Type - Container Storage Interface

CSI là chuẩn interoperability cho storage trong Kubernetes, cho phép các bên thứ ba tích hợp hệ thống lưu trữ của họ một cách dễ dàng.

### Các loại CSI driver phổ biến:

| Driver | Nhà cung cấp | Đặc điểm |
|---------|-------------|-----------|
| **aws-efs-csi-driver** | AWS | Dùng Amazon EFS - fully managed NFS |
| aws-ebs-csi-driver | AWS | Dùng EBS - block storage |
| gce-pd-csi-driver | Google | Dùng Persistent Disk |
| azure-disk-csi-driver | Azure | Dùng Managed Disks |

## Amazon EFS - Elastic File System

Trong bài này, chúng ta sẽ sử dụng **Amazon EFS** làm volume:

- **Fully managed NFS file system** - Không cần quản lý server
- **Auto-scaling** - Tự động mở rộng dung lượng
- **Multi-AZ** - Dữ liệu được replicate across availability zones
- **ReadWriteMany** - Nhiều nodes/pods có thể truy cập cùng lúc

### So sánh EFS với EBS

| Tiêu chí | EFS | EBS |
|----------|-----|-----|
| Loại | File system (NFS) | Block storage |
| Multi-attach |ReadWriteMany (nhiều node) | ReadWriteOnce (một node) |
| Use case | Shared files, content | Database, boot volumes |
| Pricing | Theo dung lượng sử dụng | Theo dung lượng provision |
