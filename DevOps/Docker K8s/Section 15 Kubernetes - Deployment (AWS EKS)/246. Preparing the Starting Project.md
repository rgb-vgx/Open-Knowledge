# Chuẩn Bị Dự Án Mẫu Để Triển Khai Trên AWS EKS

Để thực hành triển khai trên một cluster thật trong cloud, chúng ta cần một dự án demo. Trong phần này, tôi sẽ giới thiệu dự án mẫu và các bước chuẩn bị cần thiết trước khi deploy lên EKS.

## Tổng quan dự án

Dự án bao gồm hai API chính:
- **Users API** - API quản lý người dùng, có thể truy cập từ bên ngoài
- **Auth API** - API xác thực, chỉ có thể truy cập từ bên trong cluster

Giống như section trước, Users API sẽ giao tiếp với Auth API, và Auth API không được phép truy cập từ bên ngoài cluster.

## Cấu trúc tệp tin

Trong thư mục dự án, bạn sẽ tìm thấy:

### Docker Compose (chạy local)
File `docker-compose.yaml` cho phép chạy toàn bộ ứng dụng locally mà không cần Kubernetes, chỉ với Docker Compose.

### Kubernetes Configuration
Hai file YAML chính:
- `users.yaml` - Chứa Service (type LoadBalancer) và Deployment cho Users API
- `auth.yaml` - Chứa Service (type ClusterIP) và Deployment cho Auth API

Mỗi file YAML kết hợp cả Service và Deployment trong cùng một file - đây là cách tổ chức phổ biến trong thực tế.

## Các điều chỉnh cần thực hiện

### 1. Hình ảnh Docker (Container Images)

Bạn cần xây dựng và đẩy hình ảnh Docker của riêng mình lên Docker Hub. Tạo hai repository trên Docker Hub:
- `kub-dep-users` (hoặc tên theo sở thích)
- `kub-dep-auth`

Thực hiện các lệnh sau:

```bash
# Xây dựng hình ảnh Users API
cd users-api
docker build -t [tên-tài-kho]/kub-dep-users .

# Đẩy lên Docker Hub
docker push [tên-tài-kho]/kub-dep-users

# Tương tự cho Auth API
cd ../auth-api
docker build -t [tên-tài-kho]/kub-dep-auth .
docker push [tên-tài-kho]/kub-dep-auth
```

### 2. Chuẩn bị MongoDB Atlas

Users API cần kết nối đến MongoDB. Bạn cần:
- Tạo tài khoản miễn phí trên [mongodb.com](https://mongodb.com)
- Tạo một MongoDB cluster
- Tạo database user với quyền read/write
- Lấy connection string

Trong file `users.yaml`, thay thế giá trị của environment variable `MONGODB_CONNECTION_URI` bằng connection string của bạn:

```
mongodb+srv://[username]:[password]@[cluster-url]/users?retryWrites=true&w=majority
```

### 3. Cập nhật Image Names

Trong cả hai file YAML, thay thế tên image hiện tại bằng tên image Docker Hub của bạn:

```yaml
# Trong users.yaml
containers:
  - name: users
    image: [tên-tài-kho]/kub-dep-users  # Thay bằng tên của bạn

# Trong auth.yaml
containers:
  - name: auth
    image: [tên-tài-kho]/kub-dep-auth  # Thay bằng tên của bạn
```

### 4. Environment Variables

Trong `users.yaml`, đảm bảo environment variable `AUTH_SERVICE_ADDRESS` sử dụng tên service đúng:

```yaml
env:
  - name: AUTH_SERVICE_ADDRESS
    value: "http://auth-service.default.svc.cluster.local:3000"
```

## Kiểm tra trước khi deploy

Sau khi thực hiện các điều chỉnh trên, hãy kiểm tra:
- [x] Hình ảnh đã được build và push lên Docker Hub
- [x] MongoDB connection string đã được cập nhật
- [x] Tên image trong YAML đã đúng
- [x] Environment variables đã được cấu hình đúng

Bạn có thể thử chạy locally với Docker Compose trước để đảm bảo mọi thứ hoạt động:

```bash
docker-compose up
```

Sau khi xác nhận mọi thứ hoạt động, chúng ta sẽ sẵn sàng để thiết lập cluster EKS và triển khai ứng dụng lên đó.

Trong section tiếp theo, chúng ta sẽ tìm hiểu về chi phí của AWS EKS trước khi bắt đầu.
