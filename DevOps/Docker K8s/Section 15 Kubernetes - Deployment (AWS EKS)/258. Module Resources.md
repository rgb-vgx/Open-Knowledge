## Code templates

### EFS CSI Driver Installation

```bash
# Cài đặt qua Kustomize
kubectl apply -k "github.com/kubernetes-sigs/aws-efs-csi-driver/deploy/kubernetes/overlays/stable?ref=release-2.2"

# Hoặc qua Helm
helm repo add aws-efs-csi-driver https://kubernetes-sigs.github.io/aws-efs-csi-driver/
helm repo update aws-efs-csi-driver
helm upgrade --install aws-efs-csi-driver --namespace kube-system aws-efs-csi-driver/aws-efs-csi-driver
```

### AWS CLI Commands

```bash
# Cấu hình kubectl cho EKS
aws eks update-kubeconfig --region [region] --name [cluster-name]

# Kiểm tra kết nối
aws sts get-caller-identity

# Liệt kê clusters
aws eks list-clusters --region [region]
```

### Kubernetes Commands

```bash
# Kiểm tra cluster
kubectl get nodes
kubectl get pods --all-namespaces
kubectl get services

# Quản lý deployments
kubectl apply -f [file.yaml]
kubectl delete deployment [name]
kubectl rollout status deployment/[name]

# Debug
kubectl describe pod [pod-name]
kubectl logs [pod-name]
kubectl get events
```

## Mẹo khi làm việc với EKS

1. **Luôn xóa resources** sau khi hoàn thành lab để tránh chi phí phát sinh
2. **Sử dụng Spot instances** để tiết kiệm chi phí EC2
3. **Theo dõi chi phí** thường xuyên với AWS Cost Explorer
4. **Upgrade Kubernetes version** trong vòng 14 tháng để tránh extended support fee
5. **Sử dụng eksctl** để quản lý cluster dễ dàng hơn

## Kết thúc module

Bạn đã hoàn thành module Triển khai Kubernetes trên AWS EKS! Kiến thức bạn đã học:

- Thiết lập cluster EKS từ đầu
- Quản lý worker nodes và IAM roles
- Triển khai và quản lý deployments
- Sử dụng LoadBalancer services
- Tích hợp persistent storage với EFS
- Xây dựng multi-service architecture

Tiếp theo, bạn có thể khám phá:
- **Horizontal Pod Autoscaler** - Auto scaling pods
- **Ingress Controllers** - Quản lý traffic phức tạp hơn
- **Helm Charts** - Package manager cho Kubernetes
- **GitOps** - Triển khai tự động từ Git repository

Chúc bạn tiếp tục hành trình với Kubernetes!
