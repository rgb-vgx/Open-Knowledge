# Cài Đặt Docker Compose Trên Linux

Trên macOS và Windows, Docker Compose đã được cài đặt sẵn cùng Docker Desktop. Trên Linux, bạn cần cài đặt riêng.

## Cách Cài Đặt

### Bước 1: Tải Docker Compose

```bash
sudo curl -L "https://github.com/docker/compose/releases/download/v2.29.1/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
```

Lưu ý: Phiên bản `v2.29.1` trong ví dụ trên có thể đã cũ. Kiểm tra phiên bản mới nhất tại: https://github.com/docker/compose/releases

### Bước 2: Cấp Quyền Thực Thi

```bash
sudo chmod +x /usr/local/bin/docker-compose
```

### Bước 3: Tạo Symbolic Link

```bash
sudo ln -s /usr/local/bin/docker-compose /usr/bin/docker-compose
```

### Bước 4: Kiểm Tra

```bash
docker-compose --version
```

Nếu cài đặt thành công, bạn sẽ thấy thông tin phiên bản Docker Compose.

## Docker Compose Plugin (Khuyến Nghị)

Với Docker Engine mới, Docker Compose được tích hợp sẵn dưới dạng plugin. Thay vì dùng `docker-compose` (với dấu gạch ngang), bạn có thể dùng:

```bash
docker compose version
```

Đây là cách tiếp cận hiện đại và được khuyến nghị. Plugin này được viết bằng Go và tích hợp trực tiếp vào Docker CLI.
