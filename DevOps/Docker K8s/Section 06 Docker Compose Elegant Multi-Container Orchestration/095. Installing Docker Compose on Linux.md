# Cài Đặt Docker Compose Trên Linux

Trên macOS và Windows, Docker Compose đã được cài đặt sẵn cùng Docker Desktop. Trên Linux, bạn cài thêm plugin Compose cho Docker Engine.

## Cách Khuyến Nghị: Plugin qua apt (Compose v2)

```bash
sudo apt-get update
sudo apt-get install docker-compose-plugin
```

Kiểm tra:

```bash
docker compose version
```

Nếu cài đặt thành công, bạn sẽ thấy thông tin phiên bản Docker Compose v2. Từ đây về sau trong khóa học, mọi lệnh đều dùng cú pháp plugin `docker compose` (có dấu cách, không gạch nối).

## Cách Legacy: Binary rời (chỉ khi không dùng được apt)

Trước đây Compose v1 được tải dưới dạng binary `docker-compose` (có gạch nối). Cách này đã lỗi thời, chỉ dùng khi máy không cài được plugin qua apt:

```bash
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose
docker-compose --version
```

Kiểm tra phiên bản mới nhất tại: https://github.com/docker/compose/releases. Nếu đã cài plugin ở trên, bạn không cần cách này nữa.
