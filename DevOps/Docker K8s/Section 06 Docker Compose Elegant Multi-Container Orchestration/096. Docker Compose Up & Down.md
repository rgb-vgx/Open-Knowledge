# Docker Compose Up & Down: Khởi Chạy và Dừng Dịch Vụ

Bây giờ đã có file Docker Compose, hãy học cách sử dụng hai lệnh quan trọng nhất.

## `docker compose up` — Khởi Chạy

Để khởi chạy tất cả services, mở terminal, điều hướng đến thư mục chứa file `docker-compose.yml`, rồi chạy:

```bash
docker compose up
```

Lệnh này sẽ:

1. **Tạo network mặc định** — với tên theo mẫu `{project_name}_default`
2. **Tạo named volume** — nếu chưa tồn tại
3. **Pull image** từ Docker Hub (nếu dùng image có sẵn)
4. **Build image** từ Dockerfile (nếu dùng tùy chọn `build`)
5. **Khởi chạy tất cả containers**

### Chạy Ở Chế Độ Detached

Mặc định, `docker compose up` chạy ở chế độ attached — tất cả log đều in ra terminal và bạn không thể gõ lệnh khác. Để chạy nền (detached mode):

```bash
docker compose up -d
```

Khi đó, Docker sẽ khởi chạy containers ở nền và trả quyền kiểm soát terminal lại cho bạn.

### Force Rebuild Image

Nếu bạn muốn Docker Compose rebuild image ngay cả khi image đã tồn tại:

```bash
docker compose up --build
```

Mặc định, Docker Compose chỉ rebuild khi nó phát hiện code đã thay đổi.

## `docker compose down` — Dừng Dịch Vụ

Để dừng tất cả containers và dọn dẹp:

```bash
docker compose down
```

Lệnh này:

- **Dừng tất cả containers** được định nghĩa trong compose file
- **Xóa các containers** đã dừng
- **Xóa network mặc định** mà Docker Compose đã tạo

**Lưu ý quan trọng:** `docker compose down` **không xóa volumes**. Điều này có lý — vì volume thường chứa dữ liệu quan trọng. Nếu volume bị xóa mỗi lần dừng services, dữ liệu sẽ mất.

### Xóa Cả Volume

Nếu bạn muốn xóa cả volume (khi muốn bắt đầu lại từ đầu):

```bash
docker compose down -v
```

## Ví Dụ Thực Tế

```bash
# Khởi chạy toàn bộ ứng dụng
docker compose up -d

# Xem các container đang chạy
docker ps

# Dừng toàn bộ
docker compose down

# Dừng và xóa volume
docker compose down -v
```

## Tóm Tắt

| Lệnh | Chức Năng |
|-------|-----------|
| `docker compose up` | Khởi chạy tất cả services (attached mode) |
| `docker compose up -d` | Khởi chạy nền (detached mode) |
| `docker compose up --build` | Force rebuild images trước khi khởi chạy |
| `docker compose down` | Dừng services, giữ nguyên volumes |
| `docker compose down -v` | Dừng services và xóa volumes |

Hai lệnh `up` và `down` là người bạn đồng hành của bạn khi làm việc với Docker Compose.
