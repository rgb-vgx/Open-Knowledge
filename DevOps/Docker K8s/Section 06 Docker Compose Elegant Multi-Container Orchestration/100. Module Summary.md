# Tóm Tắt Module: Docker Compose

## Docker Compose — Tổng Quan

Docker Compose là công cụ giúp bạn quản lý multi-container application chỉ với **một file cấu hình** và **hai lệnh chính**.

### Những Thứ Bạn Đã Học

**1. File cấu hình Docker Compose**

```yaml
version: "3.8"

services:
  mongodb:
    image: "mongo"
    volumes:
      - data:/data/db
    environment:
      MONGO_INITDB_ROOT_USERNAME: max
      MONGO_INITDB_ROOT_PASSWORD: secret

  backend:
    build: ./backend
    ports:
      - "80:80"
    volumes:
      - logs:/app/logs
      - ./backend:/app
      - /app/node_modules
    env_file:
      - ./env/backend.env
    depends_on:
      - mongodb

  frontend:
    build: ./frontend
    ports:
      - "3000:3000"
    volumes:
      - ./frontend/src:/app/src
    stdin_open: true
    tty: true
    depends_on:
      - backend

volumes:
  data:
  logs:
```

**2. Lệnh chính**

- `docker compose up` — Khởi chạy toàn bộ services
- `docker compose up -d` — Chạy nền (detached mode)
- `docker compose up --build` — Force rebuild images
- `docker compose down` — Dừng và xóa containers (giữ volumes)
- `docker compose down -v` — Dừng và xóa cả volumes
- `docker compose build` — Chỉ build images

**3. Các tùy chọn quan trọng**

- `image` — Sử dụng image có sẵn từ Docker Hub
- `build` — Build image từ Dockerfile
- `ports` — Publish port từ container ra host
- `volumes` — Named volume, bind mount, anonymous volume
- `environment` / `env_file` — Biến môi trường
- `depends_on` — Thứ tự khởi chạy giữa services
- `stdin_open` / `tty` — Interactive mode
- `container_name` — Đặt tên tùy chỉnh cho container

### Docker Compose Không Phải Là Gì?

- **Không thay thế Dockerfile** — Nó dùng Dockerfile để build image
- **Không thay thế Docker commands** — Nó thực thi chúng ở幕后
- **Không quản lý đa host** — Chỉ hoạt động trên cùng một host
- **Không phải công cụ mới hoàn toàn** — Nó là một phần của Docker ecosystem

### Khi Nào Nên Dùng Docker Compose?

- Ứng dụng gồm nhiều container cần giao tiếp với nhau
- Bạn muốn đơn giản hóa quy trình khởi chạy và dừng services
- Bạn muốn chia sẻ cấu hình môi trường với đồng đội
- Bạn cần cấu hình集中 trung, dễ maintain
- Ngay cả với single container, Docker Compose vẫn có giá trị

### Tiếp Tục Học

Docker Compose sẽ xuất hiện trong suốt phần còn lại của khóa học. Bạn sẽ thấy nó được sử dụng trong nhiều ngữ cảnh khác nhau, từ development environment đến deployment.
