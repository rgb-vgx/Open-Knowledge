# Build Image và Hiểu Về Tên Container

Docker Compose có hai lệnh quan trọng khác ngoài `up` và `down`. Và có một điểm cần lưu ý về cách tên container được tạo tự động.

## `docker compose build` — Chỉ Build Không Run

Nếu bạn chỉ muốn build images mà không khởi chạy containers:

```bash
docker compose build
```

Lệnh này build tất cả images được định nghĩa với tùy chọn `build` trong compose file. Images dùng `image` (từ Docker Hub) sẽ không bị ảnh hưởng vì chúng đã được build sẵn.

Tại sao cần lệnh này? Khi bạn chạy `docker compose up`, nó build images nếu cần. Nhưng nếu bạn muốn build trước (ví dụ: để kiểm tra build có thành công không), lệnh này rất tiện lợi.

## `docker compose up --build` — Force Rebuild

Khi chạy `docker compose up`, Docker Compose chỉ rebuild images khi nó phát hiện code đã thay đổi. Nếu muốn force rebuild:

```bash
docker compose up --build
```

Điều này hữu ích khi:
- Bạn thay đổi `Dockerfile`
- Bạn thêm/xóa dependencies trong `package.json`
- Bạn muốn đảm bảo image mới nhất được sử dụng

## Tên Container Tự Động

Khi chạy `docker ps`, bạn sẽ thấy tên container không phải là `backend`, `frontend`, `mongodb` như trong compose file. Thay vào đó, Docker (Compose v2) tạo tên theo mẫu:

```
{ten-du-an}-{ten-service}-{index}
```

Ví dụ (thư mục dự án tên `myproject`):
- `myproject-mongodb-1`
- `myproject-backend-1`
- `myproject-frontend-1`

Trong đó `myproject` là tên project (mặc định lấy từ tên thư mục chứa compose file).

> **Lưu ý:** Các tutorial cũ dùng Compose v1 nên tên container có dạng `{project}_{service}_{index}` với dấu gạch dưới, ví dụ `docker-compose_backend_1`. Với Compose v2 (`docker compose`, không gạch nối), Docker dùng dấu gạch ngang thay vì gạch dưới.

### Đổi Tên Container

Nếu muốn đặt tên tùy chỉnh cho container:

```yaml
services:
  mongodb:
    image: "mongo:7.0"
    container_name: "my-mongodb"
```

Khi đó, container sẽ luôn có tên `my-mongodb` thay vì tên tự động.

Lưu ý: Khi đặt `container_name` thủ công, bạn không thể scale service này lên nhiều instances vì mỗi container cần tên duy nhất.

## Tóm Tắt

| Lệnh | Chức Năng |
|-------|-----------|
| `docker compose build` | Chỉ build images, không khởi chạy containers |
| `docker compose up --build` | Force rebuild images trước khi khởi chạy |
| `docker compose up -d` | Khởi chạy nền với images đã cache |

- Docker Compose thông minh trong việc quản lý images — nó chỉ rebuild khi cần
- Tên container tự động theo mẫu `{project}-{service}-{index}` (Compose v2)
- `container_name` cho phép đặt tên tùy chỉnh

Docker Compose là công cụ cực kỳ mạnh mẽ cho việc quản lý multi-container application trên localhost. Chỉ với một file cấu hình và hai lệnh chính (`up`/`down`), bạn có thể kiểm soát toàn bộ hệ thống container phức tạp.
