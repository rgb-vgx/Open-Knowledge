# Tạo File Docker Compose Đầu Tiên

Hãy bắt tay vào viết file Docker Compose cho dự án backend-frontend-mongo mà chúng ta đã xây dựng ở module trước.

## Cấu Trúc Dự Án

Dự án của chúng ta có cấu trúc thư mục như sau:

```
project/
├── backend/
│   ├── Dockerfile
│   ├── package.json
│   └── ...
├── frontend/
│   ├── Dockerfile
│   ├── package.json
│   └── ...
└── docker-compose.yml    ← File mới
```

Lưu ý quan trọng: Docker Compose **không thay thế** Dockerfile. Cả backend và frontend đều vẫn cần Dockerfile riêng.

## Các Bước Bắt Đầu

Trong thư mục gốc của dự án, tạo file `docker-compose.yml` (hoặc `compose.yml` — cả hai đều được chấp nhận). Đây là file YAML, sử dụng thụt lề (indentation) để thể hiện cấu trúc phân cấp.

## Cấu Trúc Cơ Bản

```yaml
version: "3.8"

services:
  mongodb:
    # Cấu hình container MongoDB
  backend:
    # Cấu hình container Backend (Node.js API)
  frontend:
    # Cấu hình container Frontend (React)
```

### Về `version`

Khóa `version` cho Docker Compose biết bạn muốn sử dụng phiên bản nào của Compose Specification. Phiên bản này ảnh hưởng đến các tính năng khả dụng trong file cấu hình.

Tài liệu tham khảo: https://docs.docker.com/compose/compose-file/

Lưu ý: Trong Docker Compose v2 mới nhất, `version` là tùy chọn. Nếu bạn bỏ qua, Docker sẽ tự sử dụng phiên bản mới nhất.

### Về `services`

`services` là khóa bắt buộc và quan trọng nhất. Mỗi child element bên dưới `services` đại diện cho **một container**. Trong ví dụ của chúng ta:

- `mongodb` — container chạy MongoDB
- `backend` — container chạy Node.js API
- `frontend` — container chạy React SPA

**Lưu ý về indentation:** Mọi service phải nằm cùng cấp (thụt lề giống nhau), thường là 2 khoảng trắng. YAML rất nhạy cảm với thụt lề — sai một khoảng trắng có thể phá vỡ toàn bộ cấu hình.

## Bước Tiếp Theo

Bây giờ chúng ta đã có khung cơ bản, hãy bắt đầu cấu hình chi tiết cho từng service. Bắt đầu với MongoDB — đơn giản nhất vì chúng ta dùng image có sẵn từ Docker Hub.

## Tóm Tắt

Viết file Docker Compose rất đơn giản:
1. Tạo file `docker-compose.yml` trong thư mục gốc dự án
2. Định nghĩa các services — mỗi service tương ứng một container
3. Sử dụng YAML với thụt lề chính xác

Đó là nền tảng. Trong bài tiếp theo, chúng ta sẽ đi sâu vào cấu hình chi tiết cho từng container.
