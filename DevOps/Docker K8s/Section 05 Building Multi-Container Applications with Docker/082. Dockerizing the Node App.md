# Dockerize Node.js Backend: Từ Dockerfile Đến Container

## Giới Thiệu

不同于 MongoDB — có official image — backend Node.js là application tùy chỉnh của chúng ta. Vì vậy, cần viết Dockerfile riêng để build image.

## Viết Dockerfile Cho Backend

### Dockerfile

```dockerfile
FROM node

WORKDIR /app

COPY package.json .

RUN npm install

COPY . .

EXPOSE 80

CMD ["node", "app.js"]
```

**Phân tích từng dòng:**

| Instruction | Mục Đích |
|-------------|----------|
| `FROM node` | Sử dụng official Node.js image làm base |
| `WORKDIR /app` | Đặt working directory trong container |
| `COPY package.json .` | Copy package.json trước (cache optimization) |
| `RUN npm install` | Cài dependencies |
| `COPY . .` | Copy toàn bộ source code |
| `EXPOSE 80` | Document port mà app sử dụng |
| `CMD ["node", "app.js"]` | Lệnh chạy khi container start |

### Tại Sao Copy package.json Trước?

Đây là Docker layer caching optimization:
1. Copy `package.json` → layer cache
2. `npm install` → chỉ chạy lại nếu package.json thay đổi
3. Copy source code → layer cache riêng

Nếu copy tất cả trước rồi mới install, mọi thay đổi source code đều trigger lại `npm install`.

## Build Image

```bash
# Dọn dẹp images cũ (tùy chọn)
docker image prune -a

# Build image
docker build -t goals-node .
```

## Chạy Container

### Lần Chạy Đầu Tiên (Sai)

```bash
docker run --name goals-backend goals-node
```

**Kết quả:** Container crash ngay lập tức!

**Nguyên nhân:** Backend kết nối đến `localhost:27017` — nhưng trong container, `localhost` là container đó, không phải host machine.

### Cách Khắc Phục

#### Phương Pháp 1: host.docker.internal

```bash
docker run -d --name goals-backend --rm -p 80:80 goals-node
```

Trong code, thay `localhost` bằng `host.docker.internal` — Docker sẽ translate thành IP của host machine.

#### Phương pháp 2: Docker Network (Recommended)

```bash
# Tạo network
docker network create goals-net

# Chạy MongoDB trong network
docker run -d --name mongodb --rm --network goals-net mongo

# Chạy backend trong cùng network
docker run -d --name goals-backend --rm --network goals-net -p 80:80 goals-node
```

Giờ backend có thể kết nối đến MongoDB qua tên container `mongodb` thay vì `localhost`.

## Publish Port Bắt Buộc

```bash
docker run -d \
  --name goals-backend \
  --rm \
  -p 80:80 \
  goals-node
```

**Lưu ý:** `EXPOSE` trong Dockerfile chỉ là documentation — KHÔNG publish port. Bạn phải dùng `-p` khi `docker run`.

## Kiểm Tra Kết Nối

```bash
# Xem logs
docker logs goals-backend

# Kiểm tra container status
docker ps
```

## Tóm Tắt

Dockerize Node.js backend gồm 3 bước: viết Dockerfile, build image, chạy container. Bài học quan trọng nhất: `localhost` trong container không phải host machine — sử dụng `host.docker.internal` hoặc Docker network để kết nối giữa các containers.

Trong bài tiếp theo, chúng ta sẽ dockerize React frontend — phần phức tạp hơn vì React code chạy trong browser, không phải server.
