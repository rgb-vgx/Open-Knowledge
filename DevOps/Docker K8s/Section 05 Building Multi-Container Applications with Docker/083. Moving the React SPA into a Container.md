# Dockerize React Frontend: Single Page Application Trong Container

## Tại Sao React Container Khác Biệt?

React không phải là application chạy trên server — JavaScript code chạy trong browser. Tuy nhiên, dự án React vẫn cần Node.js để:
- Chạy development server (serve React app)
- Build và transform JSX thành JavaScript browser hiểu được

Vì vậy, Dockerfile cho React vẫn sử dụng Node.js base image.

## Viết Dockerfile Cho React

### Dockerfile

```dockerfile
FROM node

WORKDIR /app

COPY package.json .

RUN npm install

COPY . .

EXPOSE 3000

CMD ["npm", "start"]
```

**So sánh với Backend Dockerfile:**

| | Backend | Frontend |
|---|---------|----------|
| `EXPOSE` | 80 | 3000 |
| `CMD` | `node app.js` | `npm start` |
| Base image | node | node |
| Mục đích | REST API server | React dev server |

### Tại Sao CMD Là npm start?

React project dùng `react-scripts` (Create React App) — script này:
1. Khởi động development server
2. Serve React app tại `localhost:3000`
3. Tự động reload khi source code thay đổi

## Build Image

```bash
docker build -t goals-react .
```

**Thời gian build:** Khá lâu vì React project có nhiều dependencies (node_modules lớn).

## Chạy Container Cơ Bản

```bash
docker run -d --name goals-frontend --rm -p 3000:3000 goals-react
```

## Vấn Đề: Container Tự Động Dừng

### Dấu Hiệu

Container chạy vài giây rồi dừng. Với `docker ps` thấy không còn running.

### Nguyên Nhân

React dev server cần **interactive mode** để hoạt động. Nếu không nhận input signal, nó tự dừng vì cho rằng "không ai quan tâm".

### Giải Pháp

```bash
# Thêm -it flag
docker run -it --name goals-frontend --rm -p 3000:3000 goals-react
```

**-it flag:**
- `-i` — Interactive: giữ STDIN open
- `-t` — TTY: phân bổ pseudo-terminal

### Lưu Ý Cho Windows Users

Nếu dùng WSL 2 trên Windows, file changes có thể không được detect. Giải pháp:
1. Tạo project trong Linux filesystem (không phải Windows filesystem)
2. Tham khảo bài viết về WSL 2 file system

## Kiểm Tra Frontend Hoạt Động

```bash
# Truy cập browser
localhost:3000

# Thử thêm goal — sẽ gọi backend API
# Nếu backend cũng đang chạy,一切 hoạt động bình thường
```

## Dừng Container

Vì chạy với `-it`, dùng `Ctrl+C` để thoát và dừng container.

## Tóm Tắt

Dockerize React frontend tương tự backend nhưng có 2 khác biệt chính:
1. **CMD** là `npm start` thay vì `node app.js`
2. **Cần `-it` flag** vì React dev server cần interactive mode

Trong bài tiếp theo, chúng ta sẽ thiết lập Docker network để tất cả containers giao tiếp hiệu quả hơn.
