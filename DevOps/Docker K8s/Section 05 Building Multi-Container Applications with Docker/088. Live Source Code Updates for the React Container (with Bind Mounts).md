# React Container: Live Source Code Updates Với Bind Mounts

## Giới Thiệu

Sau khi đã dockerize MongoDB và backend, giờ chúng ta sẽ thêm live source code updates cho React frontend. May mắn thay, React development server đã có built-in file watching — chỉ cần bind mount source code là xong.

## Bind Mount Cho React

### docker run Command

```bash
docker run -it \
  --name goals-frontend \
  --rm \
  -p 3000:3000 \
  -v "C:\path\to\frontend\src:/app/src" \
  goals-react
```

**Phân tích:**
- `-it` — Interactive mode (bắt buộc cho React dev server)
- `-v "...\frontend\src:/app/src"` — Bind mount source folder
- Không cần bind mount toàn bộ project — chỉ cần `src/` vì đây là nơi code thay đổi

### Tại Sao Chỉ Bind src/?

React project có cấu trúc:
```
frontend/
├── src/          # ← Nguồn code React (thay đổi thường xuyên)
├── public/       # ← Static assets (ít thay đổi)
├── package.json  # ← Dependencies (đã cài trong container)
└── node_modules/ # ← Dependencies (đã có trong container)
```

Chỉ bind mount `src/` giúp:
- Development server detect file changes nhanh hơn
- Không ghi đè node_modules trong container
- Ít files sync hơn → performance tốt hơn

## Live Reload Hoạt Động Như Thế Nào?

1. Bạn thay đổi file trong `src/` trên host machine
2. Bind mount sync thay đổi vào `/app/src` trong container
3. React dev server detect file change (webpack hot reload)
4. Browser tự động reload với code mới

### Test Live Reload

```bash
# Truy cập localhost:3000
# Sửa file trong src/ trên host machine
# Browser tự động reload — không cần restart container!
```

## Không Cần Nodemon

Khác với Node.js backend (cần nodemon để auto restart), React dev server đã có built-in hot module replacement (HMR). Khi source code thay đổi:
- Webpack rebuild modules
- Gửi update đến browser
- Browser apply changes mà không cần full reload

## Windows Users: WSL 2 Issue

Nếu dùng WSL 2 trên Windows và file changes không được detect:

### Giải Pháp

1. **Sử dụng Linux filesystem:** Tạo project trong `/home/user/project` thay vì `C:\Users\...\project`

2. **Hoặc mount整个 project:**
```bash
docker run -it \
  --name goals-frontend \
  --rm \
  -p 3000:3000 \
  -v "C:\path\to\frontend:/app" \
  -v /app/node_modules \
  goals-react
```

Anonymous volume `/app/node_modules` ngăn ghi đè dependencies.

## .dockerignore Cho React

```

README.md
```

## Docker Command Đầy Đủ

```bash
docker run -it \
  --name goals-frontend \
  --rm \
  -p 3000:3000 \
  -v "C:\Users\you\frontend\src:/app/src" \
  goals-react
```

## So Sánh Frontend vs Backend Live Reload

| | React Frontend | Node.js Backend |
|---|----------------|-----------------|
| **Cơ chế** | Webpack HMR | Nodemon auto restart |
| **Bind mount** | `src/` folder | Toàn bộ project |
| **Anonymous volume** | Không cần | Cần cho `node_modules` |
| **Restart server** | Không cần | Tự động qua nodemon |

## Docker Network Consideration

React frontend không cần加入 Docker network vì:
- Code chạy trong browser, không phải container
- Browser gọi `localhost:80` (qua port publish) thay vì container name
- Development server chỉ serve static files, không giao tiếp với backend

## Tóm Tắt

Live reload cho React cực kỳ đơn giản — chỉ cần bind mount `src/` folder. React development server đã có built-in HMR, không cần thêm tool như nodemon. Lưu ý WSL 2 users cần đặt project trong Linux filesystem để file changes được detect đúng cách.

Trong bài tiếp theo, chúng ta sẽ tổng kết module và điểm qua các areas cần cải thiện.
