# Tổng Kết Module: Multi-Container Application Với Docker

## Đã Hoàn Thành Gì?

Trong module này, chúng ta đã dockerize toàn bộ ứng dụng Goals Tracker gồm 3 containers:

```
┌─────────────────────────────────────────────────────────┐
│                    goals-net network                    │
│                                                         │
│  ┌──────────┐    ┌──────────────────┐    ┌───────────┐ │
│  │ MongoDB  │◀──▶│  Node.js Backend │    │   React   │ │
│  │          │    │                  │◀──▶│ Frontend  │ │
│  │ Port:    │    │ Port: 80 (host)  │    │ Port:3000 │ │
│  │  27017   │    │ Nodemon + ENV    │    │ Live HMR  │ │
│  └──────────┘    └──────────────────┘    └───────────┘ │
│       │                  │                     │        │
│   Named Volume      Named Volume          Bind Mount   │
│    (data)            (logs)                (src/)      │
└─────────────────────────────────────────────────────────┘
```

## Từng Component

### MongoDB Container
- **Official image:** Không cần Dockerfile
- **Named volume:** `-v data:/data/db` — data persistence
- **Authentication:** `MONGO_INITDB_ROOT_USERNAME` + `MONGO_INITDB_ROOT_PASSWORD`
- **Docker network:** Giao tiếp với backend qua container name

### Node.js Backend Container
- **Custom Dockerfile:** Base image `node`
- **Named volume:** `-v logs:/app/logs` — log persistence
- **Bind mount:** Source code live reload
- **Nodemon:** Auto restart khi code thay đổi
- **Environment variables:** MongoDB credentials configurable
- **.dockerignore:** Tối ưu image build

### React Frontend Container
- **Custom Dockerfile:** Base image `node`
- **Interactive mode:** `-it` flag bắt buộc
- **Bind mount:** `-v src:/app/src` — live reload qua HMR
- **No network needed:** Code chạy trong browser
- **.dockerignore:** Tối ưu image build

## Docker Commands Tổng Hợp

### 1. Tạo Network
```bash
docker network create goals-net
```

### 2. Chạy MongoDB
```bash
docker run -d --name mongodb --rm --network goals-net \
  -v data:/data/db \
  -e MONGO_INITDB_ROOT_USERNAME=max \
  -e MONGO_INITDB_ROOT_PASSWORD=secret \
  mongo
```

### 3. Chạy Backend
```bash
docker run -d --name goals-backend --rm --network goals-net \
  -p 80:80 \
  -v logs:/app/logs \
  -v "/path/to/backend:/app" \
  -v /app/node_modules \
  -e MONGODB_USERNAME=max \
  -e MONGODB_PASSWORD=secret \
  goals-node
```

### 4. Chạy Frontend
```bash
docker run -it --name goals-frontend --rm \
  -p 3000:3000 \
  -v "/path/to/frontend/src:/app/src" \
  goals-react
```

## Bài Học Quan Trọng

### 1. localhost Trong Container ≠ Host Machine
- Containers trong Docker network dùng container name để giao tiếp
- Browser vẫn cần `localhost` (host address)
- `host.docker.internal` — special address cho host machine

### 2. React Là Ngoại Lệ
- Code chạy trong browser, không phải container
- Docker network không giúp được — browser không biết Docker DNS
- Cần publish port cho backend để browser truy cập

### 3. Data Persistence
- Named volume: Dữ liệu tồn tại qua container restart
- Bind mount: Live source code updates
- Anonymous volume: Ngăn ghi đè thư mục con

### 4. Environment Variables
- Đặt trong Dockerfile với `ENV`
- Override khi run container với `-e`
- Truy cập qua `process.env.VARIABLE_NAME` trong Node.js

## Areas Cần Cải Thiện

### 1. Docker Compose
Hiện tại cần chạy 3 lệnh `docker run` riêng biệt. Docker Compose sẽ giúp:
- Định nghĩa tất cả services trong 1 file YAML
- Chạy tất cả containers với 1 lệnh
- Dễ manage và reproduce environment

### 2. Production Optimization
Setup hiện tại chỉ phù hợp cho development:
- Bind mount source code → không phù hợp production
- Nodemon → không cần trong production
- Dev server → cần build static files cho production

### 3. Security
- Hardcoded credentials trong code → cần secrets management
- Chưa có HTTPS/TLS
- Chưa có rate limiting
