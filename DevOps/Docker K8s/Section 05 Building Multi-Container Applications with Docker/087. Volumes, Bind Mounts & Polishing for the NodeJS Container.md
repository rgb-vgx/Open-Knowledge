# Node.js Container: Volumes, Bind Mounts & Environment Variables

## Tổng Quan

Backend Node.js cần hai thứ mà MongoDB đã có:
1. **Data persistence** — Log files phải tồn tại khi container restart
2. **Live source code updates** — Khi thay đổi code, server tự restart

## Thêm Named Volume Cho Log Files

### docker run Command

```bash
docker run -d \
  --name goals-backend \
  --rm \
  --network goals-net \
  -p 80:80 \
  -v logs:/app/logs \
  goals-node
```

**-v logs:/app/logs:**
- Named volume "logs" lưu trữ trên host machine
- `/app/logs` — Thư mục backend ghi log files
- Log files tồn tại ngay cả khi container bị xóa

## Thêm Bind Mount Cho Live Reload

### docker run Command

```bash
docker run -d \
  --name goals-backend \
  --rm \
  --network goals-net \
  -p 80:80 \
  -v logs:/app/logs \
  -v "C:\path\to\backend:/app" \
  -v /app/node_modules \
  goals-node
```

**Phân tích:**

| Volume | Loại | Mục Đích |
|--------|------|-----------|
| `logs:/app/logs` | Named volume | Persist log files |
| `"C:\...\backend:/app"` | Bind mount | Live source code updates |
| `/app/node_modules` | Anonymous volume | Giữ node_modules trong container |

### Tại Sao Cần Anonymous Volume Cho node_modules?

Khi bind mount `/app` từ host, nếu host không có `node_modules`, Docker sẽ ghi đè lên `node_modules` trong container → crash vì thiếu dependencies.

Anonymous volume `/app/node_modules` ngăn Docker ghi đè thư mục này.

## Thêm Nodemon Cho Auto Restart

### package.json

```json
{
  "scripts": {
    "start": "nodemon app.js"
  },
  "devDependencies": {
    "nodemon": "^2.0.4"
  }
}
```

### Dockerfile

```dockerfile
CMD ["npm", "start"]
```

Thay vì `CMD ["node", "app.js"]`, dùng `npm start` để chạy qua nodemon.

### Rebuild Image

```bash
docker stop goals-backend
docker build -t goals-node .
docker run -d --name goals-backend --rm --network goals-net -p 80:80 \
  -v logs:/app/logs \
  -v "C:\path\to\backend:/app" \
  -v /app/node_modules \
  -e MONGODB_USERNAME=max \
  -e MONGODB_PASSWORD=secret \
  goals-node
```

## Environment Variables Trong Dockerfile

### Dockerfile Addition

```dockerfile
ENV MONGODB_USERNAME=root
ENV MONGODB_PASSWORD=secret
```

### Using ENV vars in Code

```javascript
// app.js
const MONGODB_URI = `mongodb://${process.env.MONGODB_USERNAME}:${process.env.MONGODB_PASSWORD}@mongodb:27017/goals?authSource=admin`;
```

### Override Khi Run Container

```bash
docker run -d \
  --name goals-backend \
  --rm \
  --network goals-net \
  -p 80:80 \
  -v logs:/app/logs \
  -v "C:\path\to\backend:/app" \
  -v /app/node_modules \
  -e MONGODB_USERNAME=max \
  -e MONGODB_PASSWORD=secret \
  goals-node
```

## .dockerignore File

```
node_modules
npm-debug.log
Dockerfile
.dockerignore
.git
.gitignore
```

**Tại sao cần .dockerignore?**
- `node_modules` — Đã cài trong container, không cần copy từ host
- Tránh copy files không cần thiết → image nhỏ hơn, build nhanh hơn

## Docker Command Đầy Đủ

```bash
docker run -d \
  --name goals-backend \
  --rm \
  --network goals-net \
  -p 80:80 \
  -v logs:/app/logs \
  -v "C:\Users\you\backend:/app" \
  -v /app/node_modules \
  -e MONGODB_USERNAME=max \
  -e MONGODB_PASSWORD=secret \
  goals-node
```

## Kiểm Tra Hoạt Động

```bash
# Xem logs nodemon
docker logs goals-backend

# Thay đổi code → server tự restart
# Log files persist trong named volume
```

## Tóm Tắt

Backend container giờ có đầy đủ:
- **Named volume** cho log persistence
- **Bind mount** cho live source code updates
- **Nodemon** auto restart khi code thay đổi
- **Environment variables** cho MongoDB credentials
- **.dockerignore** tối ưu image build

Trong bài tiếp theo, chúng ta sẽ áp dụng tương tự cho React frontend.
