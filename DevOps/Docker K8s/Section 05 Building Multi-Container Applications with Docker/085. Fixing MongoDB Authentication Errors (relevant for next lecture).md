# Fix Lỗi MongoDB Authentication Trong Docker

## Khi Nào Gặp Lỗi Này?

Khi cấu hình MongoDB container với username/password, bạn có thể gặp lỗi authentication khi Node.js backend cố gắng kết nối. Đây là vấn đề phổ biến khi:

1. Đặt `MONGO_INITDB_ROOT_USERNAME` và `MONGO_INITDB_ROOT_PASSWORD` cho MongoDB
2. Nhưng backend code chưa cập nhật connection string với credentials

## Dấu Hiệu Nhận Biết

```bash
# Container crash ngay sau khi start
docker logs goals-backend

# Output: Authentication failed hoặc类似 lỗi kết nối
```

## Nguyên Nhân

MongoDB image hỗ trợ hai environment variables:
- `MONGO_INITDB_ROOT_USERNAME` — Tên người dùng root
- `MONGO_INITDB_ROOT_PASSWORD` — Mật khẩu root

Khi cả hai biến này được đặt, MongoDB tự động bật authentication và yêu cầu credentials khi kết nối.

## Giải Pháp

### Bước 1: Cập Nhật Connection String

Trong file `app.js` của backend, sửa connection string:

```javascript
// Trước (không có auth)
await mongoose.connect('mongodb://mongodb:27017/goals');

// Sau (có auth)
await mongoose.connect('mongodb://username:password@mongodb:27017/goals?authSource=admin');
```

### Bước 2: Thêm authSource=admin

Đây là bước quan trọng mà nhiều người quên. Query parameter `authSource=admin` chỉ cho MongoDB biết rằng user được tạo trong database `admin`.

```javascript
// Connection string đầy đủ
`mongodb://${process.env.MONGODB_USERNAME}:${process.env.MONGODB_PASSWORD}@mongodb:27017/goals?authSource=admin`
```

### Bước 3: Rebuild Image và Restart Container

```bash
# Dừng container cũ
docker stop goals-backend

# Rebuild image
docker build -t goals-node .

# Chạy lại container
docker run -d --name goals-backend --rm --network goals-net -p 80:80 goals-node
```

## Lưu Ý Quan Trọng

1. **Cả hai environment variables phải được đặt** — Nếu chỉ đặt một trong hai, MongoDB sẽ trả lỗi
2. **authSource=admin bắt buộc** — User được tạo trong database `admin`, không phải database mục tiêu
3. **Password chứa ký tự đặc biệt** — Nếu password có `@`, `:`, hoặc `/`, cần URL encode

## Tóm Tắt

Lỗi authentication MongoDB thường do connection string thiếu credentials hoặc thiếu `authSource=admin`. Always đảm bảo connection string bao gồm username, password, và authSource parameter.

Trong bài tiếp theo, chúng ta sẽ thêm data persistence cho MongoDB using Docker volumes.
