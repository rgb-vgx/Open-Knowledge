# Tìm Hiểu Ứng Dụng Mục Tiêu: Goals Tracker App

## Tổng Quan Dự Án

Trong bài viết này, chúng ta sẽ tìm hiểu chi tiết về ứng dụng Goals Tracker — một ứng dụng demo nơi người dùng có thể theo dõi các mục tiêu (goals) của họ. Đây là dự án hoàn hảo để practice Docker multi-container.

## Kiến Trúc Ứng Dụng

### Ba Building Blocks

| Component | Công Nghệ | Port | Vai Trò |
|-----------|-----------|------|---------|
| **Frontend** | React SPA | 3000 | Giao diện người dùng, chạy trong browser |
| **Backend** | Node.js + Express | 80 | REST API, xử lý logic business |
| **Database** | MongoDB | 27017 | Lưu trữ dữ liệu goals |

### Cách Các Component Giao Tiếp

```
Browser (localhost:3000)
    │
    ▼ HTTP Request
React App (served by dev server)
    │
    ▼ API Call (localhost:80)
Node.js Backend
    │
    ▼ MongoDB Connection
MongoDB Database
```

**Lưu ý quan trọng:** Frontend là một SPA (Single Page Application) — tất cả JavaScript code chạy trong browser, không phải trên server. Backend chỉ phục vụ các endpoint REST API trả về JSON.

## Cấu Trúc Project

### Backend (Node.js)

```
backend/
├── app.js          # Entry point, cấu hình Express server
├── package.json    # Dependencies
├── routes/         # API routes (GET, POST, DELETE goals)
├── controllers/    # Business logic
└── logs/           # Log files (được ghi ra file)
```

- **Endpoint chính:** `/goals` — CRUD operations cho goals
- **Port:** 80 (configurable)
- **Logs:** Ghi ra thư mục `/logs` — cần persist khi dockerize

### Frontend (React)

```
frontend/
├── src/
│   ├── App.js      # Component chính, gọi API
│   └── components/ # UI components
├── package.json
└── public/
```

- **Dev server:** Port 3000 (default)
- **Giao tiếp với backend:** Fetch API gọi `localhost:80/goals`
- **Chạy trong browser:** Không phải Node.js server

## Yêu Cầu Khi Dockerize

### MongoDB Container
- **Data Persistence:** Dữ liệu goals phải tồn tại khi container restart
- **Authentication:** Cần username/password để bảo mật
- **Port:** Không cần publish port khi chạy trong Docker network

### Node.js Backend Container
- **Log Persistence:** File logs phải được giữ lại
- **Live Reload:** Source code thay đổi cần restart server tự động
- **Environment Variables:** Username/password MongoDB nên dùng env vars

### React Frontend Container
- **Live Reload:** Development server cần reload khi source code thay đổi
- **Interactive Mode:** Cần chạy với `-it` flag để React dev server hoạt động

## Cách Chạy Dự Án (Trước Khi Dockerize)

```bash
# 1. Cài dependencies cho backend
cd backend
npm install

# 2. Khởi động backend (cần MongoDB đang chạy)
node app.js

# 3. Cài dependencies cho frontend (terminal mới)
cd frontend
npm install

# 4. Khởi động frontend dev server
npm start
```

Sau đó truy cập `localhost:3000` để sử dụng ứng dụng.

## Tóm Tắt

Ứng dụng Goals Tracker gồm 3 component chính: React frontend, Node.js backend và MongoDB database. Mỗi component chạy riêng biệt nhưng giao tiếp với nhau qua HTTP/MongoDB connection. Khi dockerize, chúng ta cần đảm bảo data persistence, authentication, và live reload functionality.

Trong bài tiếp theo, chúng ta sẽ bắt đầu dockerize từng service — bắt đầu với MongoDB.
