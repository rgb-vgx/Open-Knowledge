# Dockerize MongoDB Service: Hướng Dẫn Chi Tiết

## Tại Sao Bắt Đầu Với MongoDB?

MongoDB là building block đầu tiên trong ứng dụng multi-container của chúng ta. Vì đã có official image trên Docker Hub nên việc dockerize cực kỳ đơn giản — không cần viết Dockerfile.

## Chạy MongoDB Container Cơ Bản

### Lệnh Cơ Bản

```bash
# Dọn dẹp containers cũ (nếu có)
docker container prune

# Chạy MongoDB container
docker run -d --name mongodb --rm -p 27017:27017 mongo
```

**Giải thích các flag:**
- `-d` — Chạy ở chế độ detached (nền)
- `--name mongodb` — Đặt tên container là "mongodb"
- `--rm` — Tự động xóa container khi dừng
- `-p 27017:27017` — Publish port 27017 từ container ra host machine

### Tại Sao Publish Port?

Khi backend chưa dockerize, Node.js app chạy trên host machine cần kết nối đến MongoDB trong container. Publishing port 27017 cho phép kết nối từ localhost.

## Kiểm Tra Container Hoạt Động

```bash
# Liệt kê containers đang chạy
docker ps

# Xem logs của MongoDB container
docker logs mongodb
```

## Kết Nối Backend Vào MongoDB Container

Sau khi chạy MongoDB container, backend Node.js có thể kết nối như bình thường:

```bash
# Khởi động backend
node app.js
```

Backend sẽ kết nối đến `localhost:27017` — chính là MongoDB container thông qua port đã publish.

## Lưu Ý Quan Trọng

1. **Không publish port khi dùng Docker network:** Khi tất cả containers chạy trong cùng network, chúng có thể giao tiếp qua container name mà không cần publish port.

2. **Chỉ publish port khi cần truy cập từ host:** Ví dụ, khi backend chưa dockerize và cần kết nối từ host machine.

3. **Official image sẵn có:** MongoDB có official image trên Docker Hub, hỗ trợ đầy đủ cấu hình qua environment variables.

## Docker Command Tối Ưu

```bash
docker run -d \
  --name mongodb \
  --rm \
  -p 27017:27017 \
  mongo
```

## Tóm Tắt

Dockerize MongoDB cực kỳ đơn giản nhờ official image. Bạn chỉ cần chạy `docker run mongo` với các flag phù hợp. Quan trọng nhất là publish port khi backend chưa dockerize, và chuyển sang Docker network khi tất cả containers đã sẵn sàng.

Trong bài tiếp theo, chúng ta sẽ dockerize Node.js backend — phần thú vị hơn vì cần viết Dockerfile riêng.
