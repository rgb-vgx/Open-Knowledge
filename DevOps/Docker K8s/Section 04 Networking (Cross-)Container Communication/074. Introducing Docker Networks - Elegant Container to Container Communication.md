# Docker Networks: Giải pháp Elegant cho Cross-Container Communication

Hardcode IP address thật phiền phức. Docker Networks cung cấp cách tiếp cận tốt hơn nhiều — chỉ cần đặt containers vào cùng network, chúng sẽ tự động tìm thấy nhau bằng tên!

## Tạo Docker Network

```bash
# Tạo custom network
docker network create favorites-net

# Kiểm tra networks hiện có
docker network ls
```

## Chạy containers trong cùng network

```bash
# Chạy MongoDB trong network mới
docker run -d --name mongodb --network favorites-net mongo

# Chạy Node.js app trong cùng network
docker run -d --name favorites \
  --network favorites-net \
  -p 3000:3000 --rm favorites-node
```

## Container name = Domain name

Giờ đây, trong code Node.js, bạn chỉ cần dùng **tên container** thay vì IP:

```javascript
// Thay vì IP address
const mongoUrl = 'mongodb://172.17.0.2:27017/favorites';

// Dùng tên container
const mongoUrl = 'mongodb://mongodb:27017/favorites';
```

Docker tự động phân giải tên `mongodb` thành IP address của MongoDB container!

## Tại sao điều này hoạt động?

Docker Networks sử dụng **DNS server nội bộ** để quản lý phân giải tên. Khi bạn tạo network, Docker:
1. Tạo isolated network namespace
2. Kết nối tất cả containers trong cùng network
3. Cấu hình DNS để phân giải tên container
4. Quản lý IP assignment tự động

## Port publishing: Khi nào cần?

- **Container → Container:** Không cần publish port (trong cùng network)
- **Container → Host:** Cần publish port bằng `-p` flag
- **Host → Container:** Cần publish port bằng `-p` flag

## Kết quả

Giờ đây, hai containers có thể giao tiếp bằng tên — không cần hardcode IP, không cần rebuild image khi thay đổi. Đây là best practice cho multi-container applications!
