# Container to Container: Giải pháp cơ bản với IP Address

Giờ chúng ta sẽ chuyển sang kịch bản phức tạp nhất: container giao tiếp với container khác. Đây là nền tảng cho microservices architecture.

## Thiết lập multi-container environment

Đầu tiên, stop container Node.js hiện tại và chạy MongoDB trong container:

```bash
# Dừng container cũ
docker stop favorites

# Chạy MongoDB container
docker run -d --name mongodb mongo
```

**Lưu ý:** MongoDB image chính thức từ Docker Hub — không cần Dockerfile riêng.

## Vấn đề: Container không biết nhau

Khi chạy 2 containers riêng biệt, container Node.js không thể truy cập container MongoDB bằng tên. Bạn cần tìm IP address của MongoDB container:

```bash
docker inspect mongodb | grep IPAddress
```

Output sẽ hiển thị IP类似 `172.17.0.2`. Hardcode IP này vào code Node.js:

```javascript
const mongoUrl = 'mongodb://172.17.0.2:27017/favorites';
```

## Kết quả hoạt động

Container Node.js giờ có thể kết nối MongoDB container! Gửi POST request đến `/favorites` — dữ liệu được lưu thành công.

## Nhược điểm lớn

- **IP thay đổi:** Mỗi lần restart container, IP address có thể thay đổi
- **Hardcode:** Phải rebuild image mỗi khi IP thay đổi
- **Không scalable:** Khó quản lý khi có nhiều containers

Đây là lý do tại sao Docker Networks ra đời — giải pháp elegant cho cross-container communication!
