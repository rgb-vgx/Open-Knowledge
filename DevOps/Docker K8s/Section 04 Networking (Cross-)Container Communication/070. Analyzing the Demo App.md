# Phân tích Demo App: Ứng dụng Node.js với Star Wars API

Trước khi đi sâu vào networking, hãy cùng phân tích demo application mà chúng ta sẽ sử dụng throughout module này. Đây là Node.js web API với 4 endpoints chính.

## Cấu trúc ứng dụng

**Dependencies:** axios, express, body-parser, mongoose

**Endpoints:**

| Endpoint | Method | Chức năng |
|----------|--------|-----------|
| `/favorites` | GET | Lấy danh sách favorites từ MongoDB |
| `/favorites` | POST | Lưu favorite mới vào MongoDB |
| `/movies` | GET | Gọi Star Wars API lấy danh sách phim |
| `/people` | GET | Gọi Star Wars API lấy danh sách nhân vật |

## Flow hoạt động

1. **GET /movies & /people:** App gửi HTTP request đến `swapi.dev/api/films` và `/api/people`, lấy dữ liệu rồi trả về cho client
2. **POST /favorites:** Nhận data từ client, lưu vào MongoDB qua Mongoose
3. **GET /favorites:** Truy vấn MongoDB, trả về tất cả favorites đã lưu

## Tại sao chọn demo này?

Ứng dụng này hoàn hảo để demo networking vì nó kết hợp cả 3 kịch bản giao tiếp:
- **Container → WWW:** Gọi Star Wars API
- **Container → Host:** Kết nối MongoDB (giai đoạn đầu)
- **Container → Container:** Kết nối MongoDB container (giai đoạn sau)

## Chạy thử trên local

```bash
npm install
node app.js
```

Sử dụng Postman hoặc curl để test:
```bash
curl http://localhost:3000/movies
curl -X POST http://localhost:3000/favorites -H "Content-Type: application/json" -d '{"name":"Luke","type":"character","url":"https://swapi.dev/api/people/1/"}'
```

Sau khi hiểu cách app hoạt động, chúng ta sẽ dockerize nó!
