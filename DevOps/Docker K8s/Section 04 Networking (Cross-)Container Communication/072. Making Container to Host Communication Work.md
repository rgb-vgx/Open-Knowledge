# Giải quyết Container → Host Communication với host.docker.internal

Vấn đề đã rõ: container không thể truy cập `localhost` của host. Giải pháp nằm ở domain đặc biệt `host.docker.internal` — công cụ mạnh mẽ mà Docker cung cấp.

## host.docker.internal là gì?

`host.docker.internal` là domain special do Docker quản lý. Khi container gửi request đến domain này, Docker tự động phân giải thành IP address của host machine (từ góc nhìn của container).

```javascript
// Thay đổi trong code Node.js
// Trước:
const mongoUrl = 'mongodb://localhost:27017/favorites';

// Sau:
const mongoUrl = 'mongodb://host.docker.internal:27017/favorites';
```

## Build lại và chạy container

```bash
# Rebuild image sau khi thay đổi code
docker build -t favorites-node .

# Chạy container
docker run -d --name favorites -p 3000:3000 --rm favorites-node
```

## Kết quả

Gửi GET request đến `/favorites` — bạn sẽ nhận được response thành công! Container giờ có thể kết nối MongoDB chạy trên host machine.

## host.docker.internal hoạt động như thế nào?

Docker Desktop (Mac/Windows) tự động cấu hình domain này. Trên Linux, bạn cần thêm flag:

```bash
docker run -d --name favorites \
  --add-host=host.docker.internal:host-gateway \
  -p 3000:3000 --rm favorites-node
```

**Lưu ý:** `host.docker.internal` chỉ hoạt động khi service trên host lắng nghe trên `0.0.0.0` hoặc interface Docker có thể truy cập.

## Bước tiếp theo

Giờ container đã kết nối host thành công. Nhưng kịch bản thực tế thường là container cần kết nối container khác — và đó là lúc Docker Networks phát huy tác dụng!
