# Tạo Container & Giao tiếp với WWW: Docker化 đầu tiên

Sau khi phân tích demo app, giờ chúng ta sẽ dockerize nó và kiểm tra networking. Đây là bước đầu tiên để hiểu cách Docker xử lý giao tiếp mạng.

## Dockerfile cơ bản

```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install --only=production
COPY . .
CMD ["node", "app.js"]
```

## Build và Run container

```bash
# Build image
docker build -t favorites-node .

# Run container
docker run -d --name favorites -p 3000:3000 --rm favorites-node
```

## Kết quả: Container → WWW hoạt động!

Khi chạy container, thử gửi request đến `/movies` và `/people`:

```bash
curl http://localhost:3000/movies
```

**Kết quả:** Dữ liệu Star Wars API được trả về thành công!

Điều này chứng minh: **Container có thể giao tiếp với WWW ngay lập tức** — không cần cấu hình đặc biệt. Docker tự động xử lý routing và NAT qua network bridge.

## Container → Host: Vấn đề!

Tuy nhiên, nếu bạn thử truy cập `/favorites` (cần kết nối MongoDB trên host), bạn sẽ gặp lỗi:

```
MongoNetworkError: connect ECONNREFUSED 127.0.0.1:27017
```

**Nguyên nhân:** `localhost` trong container không phải host machine's localhost. Docker có cơ chế riêng để giải quyết vấn đề này — chúng ta sẽ tìm hiểu ở phần tiếp theo!
