# Cài Đặt Docker Trên Máy Ảo: Quy Trình Chi Tiết

Trong bài viết này, chúng ta sẽ thực hiện cài đặt Docker trên EC2 instance từ xa. Đây là bước cần thiết trước khi triển khai Docker containers lên production.

## Kết Nối EC2 Instance

Trước tiên, kết nối tới EC2 instance qua SSH:
```bash
ssh -i "your-key.pem" ec2-user@your-public-ip
```

Sau khi kết nối thành công, bạn sẽ thấy prompt:
```bash
[ec2-user@ip-172-31-xx-xx ~]$
```

## Cài Đặt Docker

### Bước 1: Cập Nhật Hệ Thống
```bash
sudo yum update -y
```

Lệnh này đảm bảo tất cả packages trên hệ thống được cập nhật lên phiên bản mới nhất.

### Bước 2: Cài Đặt Docker
```bash
sudo yum -y install docker
```

Đây là lệnh cài Docker trên Amazon Linux 2. Quá trình này sẽ:
- Download Docker package từ repositories
- Cài đặt tất cả dependencies cần thiết
- Cấu hình Docker service

### Bước 3: Khởi Động Docker
```bash
sudo service docker start
```

Sau khi chạy lệnh này, Docker daemon sẽ bắt đầu chạy background.

### Bước 4: Thêm User Vào Nhóm Docker
```bash
sudo usermod -a -G docker ec2-user
```

Lệnh này thêm user ec2-user vào nhóm docker, cho phép chạy Docker commands mà không cần sudo.

### Bước 5: Đăng Nhập Lại
```bash
exit
```

Sau đó SSH lại:
```bash
ssh -i "your-key.pem" ec2-user@your-public-ip
```

### Bước 6: Bật Docker Tự Động Khởi Động
```bash
sudo systemctl enable docker
```

## Kiểm Tra Docker

```bash
docker version
```

Nếu看到 version information cho cả Client và Server, Docker đã được cài đặt thành công.

```bash
docker run hello-world
```

Lệnh này sẽ download image hello-world từ Docker Hub và chạy một container test.

## Lưu Ý Quan Trọng

1. **Luôn sử dụng sudo** nếu chưa thêm user vào nhóm docker
2. **Kiểm tra security group** đảm bảo port 22 (SSH) đã mở
3. **Theo dõi chi phí** - EC2 instance đang chạy phát sinh cost
4. **Backup key file** an toàn, không share hay commit lên git

## Kết Luận

Cài đặt Docker trên EC2 instance là bước đệm quan trọng để triển khai containers lên production. Bây giờ bạn đã có Docker chạy trên server từ xa, sẵn sàng cho việc pull image và chạy containers.
