# Xây Dựng Multi-Stage Image: Hướng Dẫn Thực Hành

Sau khi hiểu lý thuyết, chúng ta sẽ thực hành build multi-stage image cho React application. Bài viết này đi qua từng bước chi tiết.

## Chuẩn Bị

### Source Code Structure
```
frontend/
├── src/
├── public/
├── package.json
├── Dockerfile
└── Dockerfile.prod
```

### Package.json Scripts
```json
{
  "scripts": {
    "start": "react-scripts start",
    "build": "react-scripts build"
  }
}
```

## Dockerfile.prod

### Stage 1: Build
```dockerfile
FROM node:18-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build
```

### Stage 2: Production
```dockerfile
FROM nginx:stable-alpine
COPY --from=builder /app/build /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

## Build Commands

### Build Multi-Stage Image
```bash
docker build -f frontend/Dockerfile.prod -t goals-react .
```

Flag `-f` chỉ định Dockerfile path.

### Tag Image
```bash
docker tag goals-react yourusername/goals-react
```

### Push Image
```bash
docker push yourusername/goals-react
```

## Verify Image Size

```bash
docker images goals-react
```

So sánh với single-stage build:
- Multi-stage: ~23MB
- Single-stage: ~1.2GB

## Test Locally

```bash
docker run -d -p 3000:80 goals-react
```

Truy cập `http://localhost:3000` để verify.

## Environment Variables

### Development
```bash
REACT_APP_API_URL=http://localhost:80
```

### Production
```bash
REACT_APP_API_URL=http://backend-lb-dns
```

React automatically replaces `process.env.REACT_APP_*` during build.

## Deploy Lên ECS

### Task Definition
1. Create new task definition
2. Add container: goals-react
3. Port mapping: 80
4. Environment variables: REACT_APP_API_URL

### Service
1. Create service từ task definition
2. Load balancer: Tạo mới
3. Target group: health check /

## Kết Luận

Multi-stage build đơn giản nhưng powerful. Nó giúp tạo production-ready images chỉ với một Dockerfile. Quan trọng nhất là test image trước khi deploy.
