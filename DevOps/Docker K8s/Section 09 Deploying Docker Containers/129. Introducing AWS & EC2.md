# Giới Thiệu AWS & EC2: Máy Chủ Ảo Trên Cloud

Amazon Web Services (AWS) là nền tảng cloud computing lớn nhất thế giới, và EC2 (Elastic Compute Cloud) là một trong những dịch vụ phổ biến nhất của AWS. Trong bài viết này, chúng ta sẽ tìm hiểu cách sử dụng EC2 để triển khai Docker containers.

## AWS Là Gì?

AWS cung cấp hàng trăm dịch vụ cloud từ compute, storage, database đến machine learning. Với developer, các dịch vụ quan trọng nhất bao gồm:
- **EC2**: Máy chủ ảo (Virtual Private Servers)
- **ECS/EKS**: Dịch vụ quản lý containers
- **S3**: Lưu trữ对象
- **RDS**: Database managed service

## EC2 - Virtual Servers

EC2 cho phép bạn tạo máy chủ ảo trong cloud. Think of it như việc thuê một chiếc máy tính từ xa:
- Bạn chọn cấu hình (CPU, RAM, storage)
- Bạn cài đặt hệ điều hành
- Bạn kết nối và sử dụng như máy cục bộ

### Các Instance Types
- **t2.micro/t3.micro**: Free tier, phù hợp cho demo và nhỏ apps
- **t3.medium**: Web applications, development environments
- **m5.large**: Production workloads, medium databases
- **c5/c6**: Compute-intensive workloads

## Bắt Đầu Với EC2

### Tạo Instance
1. Đăng nhập AWS Console
2. Tìm kiếm EC2 → Launch Instance
3. Chọn AMI (Amazon Linux 2 hoặc Ubuntu)
4. Chọn instance type (t2.micro cho free tier)
5. Tạo key pair (để SSH kết nối)
6. Cấu hình security group
7. Launch!

### Kết Nối SSH
```bash
chmod 400 my-key.pem
ssh -i "my-key.pem" ec2-user@public-dns-name
```

### Cài Đặt Docker
```bash
sudo yum update -y
sudo yum install docker -y
sudo service docker start
sudo usermod -a -G docker ec2-user
```

### Chạy Container
```bash
docker pull nginx
docker run -d -p 80:80 nginx
```

## Free Tier Của AWS

AWS cung cấp free tier hấp dẫn cho EC2:
- **750 giờ sử dụng t2.micro/tháng** trong 12 tháng đầu
- Phù hợp cho learning và small projects
- Luôn kiểm tra pricing page để tránh surprise bills

## Lưu Ý Quan Trọng

1. **Luôn shut down instance** khi không sử dụng để tránh chi phí phát sinh
2. **Sử dụng IAM roles** thay vì access keys
3. **Cấu hình security group** cẩn thận, chỉ mở port cần thiết
4. **Monitor chi phí** với AWS Cost Explorer

## Kết Luận

EC2 là cách đơn giản nhất để bắt đầu với cloud computing. Bạn có toàn quyền kiểm soát server, từ hệ điều hành đến ứng dụng. Tuy nhiên, điều này cũng đồng nghĩa với trách nhiệm lớn hơn về bảo mật và maintenance. Trong bài tiếp theo, chúng ta sẽ thực hành deploy Docker container lên EC2.
