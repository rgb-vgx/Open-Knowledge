# Chạy và Publish Ứng Dụng Trên EC2: Hướng Dẫn Từ A Đến Z

Trong bài viết này, chúng ta sẽ hoàn tất quy trình triển khai ứng dụng Docker lên EC2 instance. Từ việc pull image, chạy container, đến cấu hình security group để ứng dụng có thể truy cập từ internet.

## Pull Image Từ Docker Hub

Trên EC2 instance (qua SSH):
```bash
docker pull yourusername/goals-node
```

Nếu image là public, bạn không cần login. Docker sẽ download image từ Docker Hub về server.

## Chạy Container

```bash
docker run -d -p 80:80 --name goals-app yourusername/goals-node
```

Giải thích các flag:
- `-d`: Chạy container ở chế độ detached (background)
- `-p 80:80`: Map port 80 của host với port 80 của container
- `--name goals-app`: Đặt tên cho container

Nếu gặp lỗi permission, thêm `sudo`:
```bash
sudo docker run -d -p 80:80 --name goals-app yourusername/goals-node
```

## Kiểm Tra Container

```bash
docker ps
```

Bạn sẽ thấy container đang chạy với port mapping 0.0.0.0:80->80/tcp.

## Vấn Đề: Truy Cập Từ Internet

Nếu bạn mở trình duyệt và truy cập public IP của EC2 instance, có thể sẽ không thấy gì. Đây không phải lỗi mà là tính năng bảo mật!

### Security Group
Mặc định, EC2 instance chỉ mở port 22 (SSH). Để mở port 80 (HTTP):

1. Vào EC2 Dashboard → Security Groups
2. Chọn security group gắn với instance
3. Edit Inbound Rules
4. Click "Add Rule"
5. Type: HTTP
6. Source: Anywhere (0.0.0.0/0)
7. Save Rules

## Kiểm Tra Kết Quả

Mở trình duyệt, truy cập `http://your-public-ip`. Bạn sẽ thấy ứng dụng đang chạy!

## Manage Container

### Dừng Container
```bash
docker stop goals-app
```

### Khởi Động Lại
```bash
docker start goals-app
```

### Xóa Container
```bash
docker rm goals-app
```

## Xóa EC2 Instance

Khi đã test xong, remember terminate EC2 instance để tránh chi phí phát sinh:
- Vào EC2 Dashboard → Instances
- Chọn instance → Actions → Instance State → Terminate

## Kết Luận

Chúng ta đã hoàn tất quy trình triển khai ứng dụng Docker lên EC2. Mặc dù đây là cách tiếp cận manual, nó cho thấy tiềm năng to lớn của Docker containers. Tuy nhiên, trong thực tế, bạn sẽ muốn sử dụng managed services như AWS ECS để tự động hóa quy trình này.
