# Kiến Trúc Cập Nhật và Mục Tiêu: Frontend + Backend + MongoDB Atlas

Sau khi chuyển sang MongoDB Atlas, chúng ta cần hoàn thiện kiến trúc bằng cách thêm frontend React application. Bài viết này overview kiến trúc hiện tại và hướng tới kiến trúc mục tiêu.

## Kiến Trúc Hiện Tại

### Components
1. **Backend Container**: Node.js REST API
2. **Database**: MongoDB Atlas (managed service)
3. **Load Balancer**: Distribution traffic

### Data Flow
```
User Request
    ↓
Load Balancer
    ↓
Backend Container (ECS Task)
    ↓
MongoDB Atlas (Cloud)
    ↓
Response
```

## Kiến Trúc Mục Tiêu

### Thêm Frontend Container
```
User Request
    ↓
Frontend Load Balancer → Frontend Container (React App)
    ↓
Backend Load Balancer → Backend Container (Node.js API)
    ↓
MongoDB Atlas (Cloud)
    ↓
Response
```

### Tách Biệt Frontend và Backend
- **Frontend**: Serve static files (HTML, CSS, JS)
- **Backend**: Handle API requests
- **Communication**: Frontend gọi API của Backend

## Challenge: Port Mapping

### Vấn Đề
Cả frontend và backend đều exposes port 80:
- Frontend: Nginx trên port 80
- Backend: Node.js trên port 80

Trong cùng một ECS task, chỉ có thể map 1 container đến port 80.

### Giải Pháp
1. **Tách thành 2 tasks riêng**: Mỗi task có service riêng
2. **Sử dụng 2 Load Balancers**: Mỗi service có load balancer riêng
3. **Frontend gọi backend qua load balancer URL**

## Multi-Service Architecture

### Service 1: Frontend
- Container: Nginx serve React build
- Task: goals-react-task
- Load Balancer: goals-react-lb
- URL: http://frontend-lb-dns

### Service 2: Backend
- Container: Node.js REST API
- Task: goals-backend-task
- Load Balancer: goals-backend-lb
- URL: http://backend-lb-dns

### Communication
Frontend React app gọi backend qua environment variable:
```javascript
const API_URL = process.env.REACT_APP_API_URL;
fetch(`${API_URL}/goals`);
```

## Lợi Ích Của Architecture Này

### 1. Independent Scaling
- Scale frontend riêng khi có nhiều users
- Scale backend riêng khi có nhiều API calls

### 2. Independent Deployment
- Update frontend mà không affect backend
- Rollback dễ dàng hơn

### 3. Technology Diversity
- Frontend: React + Nginx
- Backend: Node.js
- Database: MongoDB Atlas

## Kết Luận

Kiến trúc multi-service với ECS giúp building scalable applications. Mỗi component có thể independently develop, deploy, và scale. Đây là foundation cho microservices architecture.
