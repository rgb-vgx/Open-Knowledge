# Sử Dụng Load Balancer Cho Domain Ổn Định

Mỗi lần deploy container mới trên ECS, Public IP sẽ thay đổi. Điều này gây bất tiện vì bạn phải update URL liên tục. Load Balancer giải quyết vấn đề này bằng cách cung cấp URL cố định.

## Vấn Đề: IP Thay Đổi

Khi deploy container mới:
1. ECS tạo task mới với IP mới
2. IP cũ bị terminate
3. Application với IP cũ không còn truy cập được

## Giải Pháp: Application Load Balancer

### Cách Load Balancer Hoạt Động
1. **Load Balancer có DNS name cố định**: Không bao giờ thay đổi
2. **Forward requests** đến healthy containers
3. **Health check**: Tự động restart unhealthy containers
4. **Distribution**: Phân phối traffic evenly

### Cấu Hình Health Check

Vấn đề phổ biến: Health check request trả về 404 vì endpoint không tồn tại.

Giải pháp:
1. Vào Target Groups
2. Chọn target group
3. Edit Health Check Settings
4. Change health check path: `/goals`

## Setup Load Balancer

### Bước 1: Tạo Load Balancer
```
EC2 Console → Load Balancers → Create
- Type: Application Load Balancer
- Name: ecs-lb
- Scheme: Internet-facing
- Listener: HTTP 80
- VPC: Chọn VPC của ECS
```

### Bước 2: Tạo Target Group
```
- Target type: IP (cho Fargate)
- Name: goals-tg
- Health check path: /goals
```

### Bước 3: Kết Nối Với ECS
```
ECS → Service → Update
- Load balancer: ecs-lb
- Target group: goals-tg
```

## Sử Dụng Load Balancer URL

1. Vào EC2 Console → Load Balancers
2. Copy DNS name
3. Truy cập: `http://load-balancer-dns/goals`

## Verify

- POST /goals: Thêm goal
- GET /goals: Liệt kê goals
- DELETE /goals/:id: Xóa goal

Load Balancer URL không thay đổi dù container có restart.

## Kết Luận

Load Balancer là essential cho production deployment. Nó cung cấp stable URL, health checking, và load distribution. Bắt buộc phải có cho bất kỳ production application nào.
