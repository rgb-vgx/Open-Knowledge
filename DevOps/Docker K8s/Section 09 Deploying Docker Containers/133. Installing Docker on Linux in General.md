# Cài Đặt Docker Trên Linux: Hướng Dẫn Cho Mọi Distro

Trong bài trước, chúng ta đã thấy cách cài đặt Docker trên Amazon Linux 2 sử dụng lệnh `yum`. Tuy nhiên, nếu bạn sử dụng Linux distro khác (Ubuntu, Debian, CentOS, Fedora), quy trình sẽ khác một chút.

## Tài Liệu Chính Thức

Docker cung cấp hướng dẫn cài đặt chi tiết cho mọi distro Linux tại: https://docs.docker.com/engine/install/

Tại trang này, chọn "Server" và tìm distro của bạn.

## Ubuntu/Debian

```bash
# Cập nhật package index
sudo apt-get update

# Cài đặt prerequisites
sudo apt-get install \
    ca-certificates \
    curl \
    gnupg \
    lsb-release

# Thêm Docker's official GPG key
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | \
    sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg

# Thiết lập repository
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] \
  https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# Cài đặt Docker Engine
sudo apt-get update
sudo apt-get install docker-ce docker-ce-cli containerd.io
```

## CentOS/RHEL/Fedora

```bash
# Cài đặt yum-utils
sudo yum install -y yum-utils

# Thêm Docker repository
sudo yum-config-manager --add-repo \
    https://download.docker.com/linux/centos/docker-ce.repo

# Cài đặt Docker Engine
sudo yum install docker-ce docker-ce-cli containerd.io
```

## Bật Docker Tự Động Khởi Động

Sau khi cài đặt, bật Docker service:
```bash
sudo systemctl start docker
sudo systemctl enable docker
```

## Thêm User Vào Nhóm Docker

Để chạy Docker không cần sudo:
```bash
sudo usermod -aG docker $USER
```

Đăng nhập lại để thay đổi có hiệu lực.

## Verify Cài Đặt

```bash
docker version
docker run hello-world
```

## Tại Sao Phải Tuân Thủ Tài Liệu Chính Thức?

Mỗi distro có package manager và repository riêng. Sử dụng tài liệu chính thức đảm bảo:
- Version Docker mới nhất và tương thích
- Dependencies đầy đủ
- Cấu hình đúng cho distro của bạn

## Kết Luận

Docker hoạt động trên hầu hết mọi distro Linux. Điểm chung là: cài đặt Docker Engine, bật service, và thêm user vào nhóm docker. Chi tiết từng bước sẽ khác nhau tùy distro, nên luôn tham khảo tài liệu chính thức.
