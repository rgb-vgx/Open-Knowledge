## Kiến Thức Kỹ Thuật

### Docker Commands
```bash
# Build image
docker build -t my-app .

# Tag image
docker tag my-app username/my-app

# Push image
docker push username/my-app

# Run container
docker run -d -p 80:80 my-app
```

### ECS Concepts
- **Task Definition**: Container configuration
- **Service**: Task management
- **Cluster**: Network isolation
- **Load Balancer**: Traffic distribution

## Best Practices

### 1. Development vs Production
- Bind mounts chỉ cho development
- COPY trong Dockerfile cho production
- Environment-specific configuration

### 2. Security
- Never hardcode secrets
- Use environment variables
- Minimal image size

### 3. Performance
- Multi-stage builds
- Docker layer caching
- Optimize image size

### 4. Monitoring
- Container logging
- Health checks
- Performance metrics
