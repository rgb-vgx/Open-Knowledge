# Triển Khai Với AWS ECS: Dịch Vụ Managed Container

AWS ECS (Elastic Container Service) là giải pháp managed container của Amazon, giúp bạn triển khai và quản lý Docker containers mà không cần lo về infrastructure management. Trong bài viết này, chúng ta sẽ đi qua toàn bộ quy trình từ tạo cluster đến chạy container.

## ECS Thinking Models

AWS ECS hoạt động với 4 khái niệm chính:

### 1. Container
Đơn vị cơ bản - chính là Docker container của bạn. Bạn sẽ define container trong task definition.

### 2. Task
Task là blueprint cho application. Nó określa:
- Container nào sẽ chạy
- Bao nhiêu resource (CPU, memory)
- Port mappings
- Environment variables
- Volumes (nếu có)

### 3. Service
Service quản lý task definition:
- Quyết định bao nhiêu tasks chạy cùng lúc
- Auto-scaling policy
- Load balancing
- Rolling update strategy

### 4. Cluster
Cluster là network surrounding cho services:
- Nhóm các related services
- Network configuration
- VPC và subnets

## Bước 1: Tạo Cluster

1. Vào ECS Console → Clusters → Create Cluster
2. Chọn "Networking only" (cho Fargate)
3. Đặt tên cluster
4. Tạo VPC mới
5. Click Create

## Bước 2: Tạo Task Definition

1. Vào Task Definitions → Create new Task Definition
2. Chọn Fargate
3. Đặt tên task (ví dụ: "goals")
4. Chọn task execution role
5. Chọn最小 CPU và Memory (để test)
6. Click Add Container

### Cấu Hình Container

- **Container name**: goals-backend
- **Image**: yourusername/goals-node
- **Port mappings**: 80 (TCP)
- **Memory limits**: 0.5 GB
- **Environment variables**: Thêm các biến cần thiết

## Bước 3: Tạo Service

1. Từ cluster, click Create Service
2. Chọn Fargate launch type
3. Chọn task definition vừa tạo
4. Đặt tên service
5. Number of tasks: 1
6. Click Next

### Cấu Hình Network

1. Chọn VPC
2. Chọn subnets (cả public và private)
3. Auto-assign Public IP: Enabled
4. Click Next

### Cấu Hình Load Balancer (Optional)

1. Chọn Application Load Balancer
2. Tạo target group mới
3. Configure health check path
4. Click Next

### Hoàn Tất

Review và Create. ECS sẽ tự động:
- Pull image từ Docker Hub
- Khởi động container
- Configure networking
- Set up load balancer (nếu có)

## Verify Deployment

1. Vào ECS Console → Clusters → Service
2. Click vào Task
3. Tìm Public IP
4. Truy cập trong trình duyệt

## Kết Luận

AWS ECS đơn giản hóa đáng kể quy trình deploy containers. Bạn chỉ cần define cách chạy containers, ECS sẽ lo phần infrastructure management. Đây là sự lựa chọn tuyệt vời cho production deployment.
