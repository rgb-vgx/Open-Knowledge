# Cài Đặt Docker Trên EC2 Instance: Hướng Dẫn Cập Nhật

> **Lưu ý quan trọng**: Lệnh `amazon-linux-extras install docker` đã không còn hoạt động trên Amazon Linux 2. Sử dụng các lệnh sau thay thế.

## Cách Cài Đặt Docker Mới Trên Amazon Linux 2

```bash
# Cập nhật hệ thống
sudo yum update -y

# Cài đặt Docker
sudo yum -y install docker

# Khởi động Docker service
sudo service docker start

# Thêm ec2-user vào nhóm docker (để chạy docker không cần sudo)
sudo usermod -a -G docker ec2-user
```

## Bước Quan Trọng Sau Cài Đặt

### 1. Đăng Xuất và Đăng Nhập Lại
Sau khi chạy lệnh `usermod`, bạn **phải đăng xuất và đăng nhập lại** để nhóm docker có hiệu lực:

```bash
exit
```

Sau đó SSH lại vào instance:
```bash
ssh -i "your-key.pem" ec2-user@your-public-ip
```

### 2. Bật Docker Tự Động Khởi Động
```bash
sudo systemctl enable docker
```

Lệnh này đảm bảo Docker tự động start khi instance restart.

### 3. Kiểm Tra Docker
```bash
docker version
```

Nếu看到 thông tin về Docker Client và Server, chúc mừng bạn đã cài đặt thành công!

## Tại Sao Phải Thêm User Vào Nhóm Docker?

Mặc định, chỉ có user root mới có quyền chạy Docker commands. Bằng cách thêm ec2-user vào nhóm docker:
- Bạn có thể chạy `docker` mà không cần `sudo`
- Tránh được lỗi "permission denied" thường gặp
- An toàn hơn vì không cần chạy toàn bộ lệnh với sudo

## Lưu Ý Về Chi Phí

EC2 instance đang chạy sẽ phát sinh chi phí. Để tránh bill surprises:
- Terminate instance khi không sử dụng
- Sử dụng AWS Cost Explorer để theo dõi
- Kiểm tra free tier limits

## Kết Luận

Cài đặt Docker trên EC2 tương đối đơn giản với vài lệnh cơ bản. Điểm quan trọng nhất là đảm bảo user có quyền chạy Docker và service tự động khởi động. Bây giờ bạn đã sẵn sàng để triển khai Docker containers lên production!
