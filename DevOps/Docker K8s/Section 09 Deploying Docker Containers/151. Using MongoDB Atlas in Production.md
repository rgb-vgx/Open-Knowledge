# Sử Dụng MongoDB Atlas Trong Production

Khi đã setup MongoDB Atlas và test locally, bước tiếp theo là tích hợp vào production deployment trên ECS. Bài viết này hướng dẫn chi tiết quy trình migration.

## Cập Nhật Task Definition

### Bước 1: Tạo New Revision
1. Vào ECS Task Definitions
2. Chọn task hiện tại
3. Click Create new revision

### Bước 2: Xóa MongoDB Container
1. Click vào mongodb container
2. Click Remove container

### Bước 3: Update Backend Container

#### Environment Variables
Cập nhật các biến:
- `MONGODB_URL`: Connection string từ Atlas
- `MONGODB_USERNAME`: Username từ Atlas
- `MONGODB_PASSWORD`: Password từ Atlas
- `MONGODB_NAME`: goals (production database name)

### Bước 4: Xóa EFS Volume
Vì không còn MongoDB container, không cần persistent storage:
1. Remove volume từ task definition
2. Xóa EFS file system (nếu chỉ dùng cho MongoDB)
3. Xóa security group của EFS

### Bước 5: Create và Update Service
1. Click Create
2. Vào Service → Update
3. Force new deployment
4. Click Update Service

## Quan Trọng: Rebuild Image

**LƯU Ý**: Sau khi thay đổi code hoặc Dockerfile:
```bash
docker build -t goals-node .
docker tag goals-node yourusername/goals-node
docker push yourusername/goals-node
```

**KHÔNG rebuild image** = ECS vẫn dùng image cũ = application không hoạt động đúng.

## Verify

1. Chờ task mới running
2. Lấy Public IP
3. Test endpoints:
   - POST /goals: Thêm goal
   - GET /goals: Liệt kê goals
   - DELETE /goals/:id: Xóa goal

## Lưu Ý Production

### 1. Database Security
- Sử dụng password phức tạp
- Restrict IP whitelist
-启用 authentication

### 2. Connection Pooling
- Atlas có built-in connection pooling
- Configure appropriate pool size

### 3. Monitoring
- Atlas cung cấp monitoring dashboard
- Set up alerts cho performance issues

### 4. Backups
- Atlas tự động backups
- Configure backup schedule nếu cần

## Kết Luận

Di chuyển sang MongoDB Atlas giúp bạn loose coupling giữa application và database management. Bạn có thể focus vào business logic thay vì database operations.
