# Bắt Đầu Với Ví Dụ Đầu Tiên: Deploy Node.js App Lên AWS EC2

Trong bài viết này, chúng ta sẽ thực hành triển khai một ứng dụng Node.js đơn giản lên AWS EC2 instance. Đây là bước đầu tiên để hiểu cách thức đưa Docker container từ máy cục bộ lên production server.

## Ví Dụ: Ứng Dụng Node.js Đơn Giản

Chúng ta sẽ sử dụng một ứng dụng Node.js demo đơn giản:
- Serve một file HTML chứa thông báo chào mừng
- Lắng nghe trên port 80
- Không có database hay service nào khác

Dockerfile cho ứng dụng này khá cơ bản:
```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package.json .
RUN npm install
COPY . .
EXPOSE 80
CMD ["npm", "start"]
```

## Quy Trình Triển Khai Lên EC2

### Bước 1: Tạo EC2 Instance
- Đăng nhập AWS Console → EC2 → Launch Instance
- Chọn Amazon Linux AMI (64-bit x86)
- Chọn t2.micro (free tier eligible)
- Tạo và download key pair (.pem file)
- Launch instance

### Bước 2: Kết Nối SSH
Trên macOS/Linux:
```bash
chmod 400 your-key.pem
ssh -i "your-key.pem" ec2-user@your-public-ip
```

Trên Windows: Sử dụng PuTTY hoặc WSL 2.

### Bước 3: Cài Đặt Docker
```bash
sudo yum update -y
sudo yum -y install docker
sudo service docker start
sudo usermod -a -G docker ec2-user
```

Đăng nhập lại sau khi chạy usermod, sau đó verify:
```bash
docker version
```

### Bước 4: Build và Push Image
Trên máy cục bộ:
```bash
docker build -t yourusername/node-example .
docker tag node-example yourusername/node-example
docker push yourusername/node-example
```

### Bước 5: Pull và Run Container
Trên EC2 instance:
```bash
docker pull yourusername/node-example
docker run -d -p 80:80 --name my-app yourusername/node-example
```

### Bước 6: Cấu Hình Security Group
- Vào EC2 Dashboard → Security Groups
- Chỉnh sửa inbound rules
- Thêm rule: HTTP (port 80) từ Anywhere (0.0.0.0/0)

## Kiểm Tra Kết Quả
Mở trình duyệt và truy cập public IP của EC2 instance. Bạn sẽ thấy thông báo "This works! Congratulations, this app seems to run fine".

## Điểm Ấn Tượng Nhất
Bạn chỉ cần cài Docker trên EC2, không cần cài Node.js hay bất kỳ runtime nào khác. Container chứa đầy đủ mọi thứ cần thiết để chạy ứng dụng. Đây chính là sức mạnh thực sự của Docker!

## Kết Luận
Chúng ta đã thành công triển khai ứng dụng Docker lên EC2. Mặc dù đây là cách tiếp cận đơn giản, nó cho thấy tiềm năng to lớn của containerization trong việc đơn giản hóa deployment.
