# Chuẩn Bị Ứng Dụng Multi-Container: MongoDB Backend

Sau khi triển khai thành công single container, chúng ta sẽ tiếp tục với multi-container application. Bài viết này hướng dẫn cách configure backend Node.js container để kết nối với MongoDB trên ECS.

## Thay Đổi Quan Trọng: Container Networking

### Local Development
Trong docker-compose, bạn có thể dùng tên container làm hostname:
```javascript
mongoose.connect('mongodb://mongodb:27017/goals');
```

Docker compose tự động resolve tên container thành IP address.

### AWS ECS
Trên ECS, networking phức tạp hơn:
- Containers có thể chạy trên nhiều physical machines
- Container name resolution không hoạt động
- Cần approach khác để container communicate

### Giải Pháp: Same Task = Same Machine
Khi các containers nằm trong cùng một task:
- Chúng được guarantee chạy trên cùng một machine
- ECS cho phép dùng `localhost` làm hostname
- Containers communicate qua localhost

```javascript
// Production (ECS)
mongoose.connect(`mongodb://localhost:27017/${dbName}`);

// Development (Docker Compose)
mongoose.connect(`mongodb://mongodb:27017/${dbName}`);
```

## Sử Dụng Environment Variables

Để code linh hoạt giữa environments:

### Dockerfile
```dockerfile
ENV MONGODB_URL=mongodb
```

### Code
```javascript
const mongoUrl = process.env.MONGODB_URL || 'mongodb';
mongoose.connect(`${mongoUrl}:27017/goals`);
```

### Backend.env
```
MONGODB_URL=mongodb
```

## Build và Push Image

```bash
docker build -t goals-node .
docker tag goals-node yourusername/goals-node
docker push yourusername/goals-node
```

## Quy Trình Deploy Multi-Container

1. **Tạo Task Definition** chứa cả hai containers
2. **Configure environment variables** cho từng container
3. **Đảm bảo containers trong cùng task** để dùng localhost
4. **Test kết nối** giữa containers

## Lưu Ý Quan Trọng

1. **Không dùng Docker networks** trên ECS - use same task instead
2. **Environment variables** là cách tốt nhất để configuration
3. **Luôn rebuild image** khi thay đổi Dockerfile
4. **Test locally** trước khi deploy lên ECS

## Kết Luận

Multi-container deployment trên ECS đòi hỏi hiểu rõ networking model. Điểm mấu chốt là: containers trong cùng task có thể communicate qua localhost. Sử dụng environment variables để code linh hoạt giữa environments.
