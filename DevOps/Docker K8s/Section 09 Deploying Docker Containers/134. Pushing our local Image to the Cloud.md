# Push Image Lên Docker Hub: Cách Đưa Image Từ Local Lên Cloud

Khi đã build image trên máy cục bộ, bước tiếp theo là đưa nó lên cloud để có thể pull về server từ xa và chạy. Docker Hub là registry pública phổ biến nhất, cho phép bạn store và share Docker images.

## Tại Sao Cần Push Image Lên Cloud?

Có hai cách đưa image lên server từ xa:

**Cách 1: Build trên server**
- Copy source code lên server
- Run `docker build` trên server
- Nhược điểm: Server cần cài đặt development tools, chậm hơn

**Cách 2: Push image đã build sẵn**
- Build image trên máy cục bộ
- Push lên Docker Hub
- Pull image trên server
- Ưu điểm: Server chỉ cần Docker, nhanh hơn, gọn hơn

## Quy Trình Push Image

### Bước 1: Tạo Repository Trên Docker Hub
1. Đăng nhập Docker Hub (docker.com)
2. Click "Create Repository"
3. Đặt tên repository (ví dụ: `goals-node`)
4. Chọn Public hoặc Private
5. Click Create

### Bước 2: Tạo .dockerignore
Để tránh push những file không cần thiết:
```
node_modules
npm-debug.log
Dockerfile
docker-compose.yml
.env
*.pem
```

### Bước 3: Build Image
```bash
docker build -t goals-node .
```

### Bước 4: Tag Image
```bash
docker tag goals-node yourusername/goals-node
```

Lệnh này tạo một bản sao của image với tên mới phù hợp Docker Hub format.

### Bước 5: Login Docker Hub
```bash
docker login
```

Nhập username và password Docker Hub.

### Bước 6: Push Image
```bash
docker push yourusername/goals-node
```

Image sẽ được push lên Docker Hub. Với các layer đã có trên Hub, chỉ layer mới được push (incremental push).

## Verify

Truy cập Docker Hub, bạn sẽ thấy repository với image vừa push.

## Lưu Ý

1. **Image name format**: `username/repository-name`
2. **Public repository**: Miễn phí nhưng ai cũng thấy
3. **Private repository**: Giới hạn số lượng với free account
4. **Tags**: Sử dụng version tags (latest, v1.0, etc.) để quản lý

## Kết Luận

Push image lên Docker Hub là bước cần thiết để triển khai container lên production. Quy trình đơn giản: build, tag, login, push. Bây giờ image đã sẵn sàng trên cloud, chờ bạn pull về server và chạy!
