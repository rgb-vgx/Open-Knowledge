# Triển Khai Container Thứ Hai và Load Balancer

Khi backend đã chạy ổn định, chúng ta sẽ thêm container MongoDB và cấu hình load balancer để application hoàn chỉnh.

## Thêm MongoDB Container

### Task Definition Updates
1. Vào Task Definition hiện tại
2. Click Create new revision
3. Thêm container mới:
   - **Container name**: mongodb
   - **Image**: mongo
   - **Port mappings**: 27017
   - **Environment variables**:
     - `MONGO_INITDB_ROOT_USERNAME`: max
     - `MONGO_INITDB_ROOT_PASSWORD`: secret

### Boot Dependency Ordering
Đặt dependencies để ensure containers start đúng thứ tự:
- `goals-backend` phụ thuộc vào `mongodb`
- MongoDB phải start trước backend

## Cấu Hình Load Balancer

### Tạo Application Load Balancer
1. Vào EC2 Console → Load Balancers
2. Click Create Load Balancer
3. Chọn Application Load Balancer
4. Đặt tên (ví dụ: ecs-lb)
5. Internet-facing
6. Listeners: Port 80
7. VPC: Chọn VPC của ECS cluster

### Tạo Target Group
1. Target type: IP (vì dùng Fargate)
2. Đặt tên (ví dụ: goals-tg)
3. Health check path: /goals (endpoint hợp lệ)

### Kết Nối Load Balancer Với ECS
1. Vào ECS Service
2. Click Update
3. Chọn Load Balancer
4. Chọn target group vừa tạo
5. Click Update Service

## Verify

### Test Backend
```bash
GET http://load-balancer-dns/goals
```

### Test với Postman
- POST /goals: Thêm goal mới
- GET /goals: Liệt kê goals
- DELETE /goals/:id: Xóa goal

## Kết Luận

Multi-container deployment trên ECS đòi hỏi configure cả networking và load balancing. Load balancer giúp ensure high availability và provide stable URL cho application.
