# Cập Nhật Managed Containers: Quy Trình Rolling Update

Khi application có thay đổi code, bạn cần update containers trên ECS mà không gây downtime. Bài viết này hướng dẫn quy trình rolling update trên AWS ECS.

## Quy Trình Cập Nhật

### Bước 1: Rebuild Image Locally
```bash
docker build -t goals-node .
docker tag goals-node yourusername/goals-node
```

### Bước 2: Push Image Lên Docker Hub
```bash
docker push yourusername/goals-node
```

### Bước 3: Tạo New Task Definition Revision

1. Vào ECS Console → Task Definitions
2. Chọn task definition hiện tại
3. Click "Create new revision"
4. Giữ nguyên tất cả settings
5. Click Create

Việc tạo revision mới sẽ trigger ECS pull image mới nhất từ Docker Hub.

### Bước 4: Update Service

1. Vào ECS → Clusters → Service
2. Click Actions → Update Service
3. Chọn task definition revision mới
4. Click "Force new deployment"
5. Click Update Service

### Bước 5: Verify

1. Chờ cho service稳定 định
2. Click vào task mới
3. Lấy Public IP
4. Test trong trình duyệt

## Rolling Update Strategy

ECS sử dụng rolling update strategy:
1. **Task mới bắt đầu chạy** với image mới
2. **Health check** đảm bảo task mới hoạt động
3. **Task cũ được stop** khi task mới healthy
4. **Zero downtime** trong quá trình update

## Lưu Ý

### Public IP Thay Đổi
Mỗi lần tạo task mới, AWS sẽ gán Public IP mới. Để giải quyết:
- Sử dụng Load Balancer với fixed DNS name
- Map custom domain

### Image Cache
Docker Hub có image caching. Nếu dùng tag `latest`, ensure bạn pull mới nhất.

## Kết Luận

Cập nhật containers trên ECS đơn giản với quy trình: build → push → create revision → update service. Rolling update strategy đảm bảo zero downtime cho production applications.
