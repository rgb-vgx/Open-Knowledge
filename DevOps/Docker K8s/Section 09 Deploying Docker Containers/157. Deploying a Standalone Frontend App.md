# Triển Khai Frontend App Độc Lập: React + Nginx

Sau khi build multi-stage image thành công, chúng ta sẽ deploy frontend React app lên ECS. Bài viết này hướng dẫn quy trình deploy và cấu hình networking.

## Chuẩn Bị

### Docker Image
```bash
docker build -f frontend/Dockerfile.prod -t goals-react .
docker tag goals-react yourusername/goals-react
docker push yourusername/goals-react
```

### Code Adjustments

#### Frontend Code
```javascript
// src/App.js
const API_URL = process.env.REACT_APP_API_URL || '';

fetch(`${API_URL}/goals`);
```

#### Environment Variables
- Development: `REACT_APP_API_URL=http://localhost:80`
- Production: `REACT_APP_API_URL=http://backend-lb-dns`

## Tạo ECS Task Definition

### Bước 1: Create Task Definition
1. ECS Console → Task Definitions
2. Create new Task Definition
3. Launch type: Fargate
4. Task name: goals-react
5. Memory: 0.5 GB, CPU: 0.25 vCPU

### Bước 2: Add Container
- Container name: goals-frontend
- Image: yourusername/goals-react
- Port mappings: 80

### Bước 3: Create
Click Create để tạo task definition.

## Tạo ECS Service

### Bước 1: From Cluster
1. Vào cluster hiện tại
2. Click Create Service

### Bước 2: Configure Service
- Launch type: Fargate
- Task definition: goals-react
- Service name: goals-react
- Number of tasks: 1

### Bước 3: Network Configuration
- VPC: Chọn VPC hiện tại
- Subnets: Chọn cả hai subnets
- Security group: Chọn hoặc tạo mới
- Auto-assign Public IP: Enabled

### Bước 4: Load Balancer
1. Chọn Application Load Balancer
2. Tạo load balancer mới: goals-react-lb
3. Tạo target group: react-tg
4. Health check path: /

### Bước 5: Create Service
Review và Create.

## Verify

1. Vào Service → Tasks
2. Click vào task
3. Lấy Public IP hoặc Load Balancer DNS
4. Truy cập trong trình duyệt

## Kiểm Tra Frontend-Backend Communication

1. Mở browser console
2. Kiểm tra network requests
3. Verify API calls đến đúng backend

## Troubleshooting

### Không Load Được
- Kiểm tra security group
- Verify health check path
- Xem container logs

### API Calls Thất Bại
- Verify REACT_APP_API_URL
- Kiểm tra CORS settings
- Test backend trực tiếp

## Kết Luận

Deploy frontend app trên ECS đòi hỏi configure networking và load balancing. Điểm quan trọng nhất là ensure frontend có thể communicate với backend qua正确的 URLs.
