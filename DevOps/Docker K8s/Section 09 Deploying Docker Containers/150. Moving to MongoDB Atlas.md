# Di Chuyển Sang MongoDB Atlas: Managed Database Service

Sau khi hiểu rõ những thách thức của database trong container, chúng ta sẽ di chuyển sang MongoDB Atlas - managed database service tốt nhất cho MongoDB.

## MongoDB Atlas Là Gì?

MongoDB Atlas là fully managed cloud database service:
- Không cần quản lý servers
- Automated backups
- Built-in monitoring
- Easy scaling
- Free tier available

## Bắt Đầu Miễn Phí

### Bước 1: Tạo Tài Khoản
1. Truy cập mongodb.com/atlas
2. Click "Start Free"
3. Đăng ký tài khoản

### Bước 2: Tạo Cluster
1. Chọn Cloud Provider (AWS, GCP, Azure)
2. Chọn Region
3. Cluster Tier: M0 Sandbox (Free)
4. Cluster Name: Giữ default
5. Click Create

### Bước 3: Configure Database Access
1. Vào Database Access
2. Add New User
3. Username và Password
4. Roles: Read and Write

### Bước 4: Configure Network Access
1. Vào Network Access
2. Add IP Address
3. Allow access from anywhere (0.0.0.0/0)

## Kết Nối Từ Application

### Lấy Connection String
1. Click Connect trong Atlas
2. Choose "Connect your application"
3. Copy connection string

### Connection String Format
```
mongodb+srv://username:password@cluster.mongodb.net/databaseName?retryWrites=true&w=majority
```

### Cấu Hình Trong Code
```javascript
const mongoUrl = process.env.MONGODB_URL;
mongoose.connect(mongoUrl);
```

### Environment Variables
```
MONGODB_URL=mongodb+srv://username:password@cluster.mongodb.net/goals?retryWrites=true&w=majority
```

## Local Development

### Cập Nhật Docker Compose
Bỏ service MongoDB, chỉ giữ backend:
```yaml
services:
  goals-node:
    build: ./backend
    ports:
      - "80:80"
    env_file:
      - ./backend.env
```

### Backend.env
```
MONGODB_URL=mongodb+srv://username:password@cluster.mongodb.net/goals-dev?retryWrites=true&w=majority
```
