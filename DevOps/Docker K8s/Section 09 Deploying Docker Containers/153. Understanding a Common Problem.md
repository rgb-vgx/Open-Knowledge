# Hiểu Rõ Vấn Đề Phổ Biến: Build Step Trong Frontend Applications

Một vấn đề quan trọng khi deploy frontend applications (React, Angular, Vue): chúng cần build step để chuyển đổi development code thành production-ready code. Bài viết này giải thích tại sao và cách giải quyết.

## Vấn Đề: Development vs Production Code

### Development Code
```javascript
// JSX syntax - không chạy trực tiếp trên browser
const App = () => {
  return <h1>Hello World</h1>;
};
```

JSX không phải JavaScript chuẩn. Browser không thể chạy trực tiếp.

### Production Code
```javascript
// Compiled JavaScript - browser có thể chạy
const App = () => {
  return React.createElement('h1', null, 'Hello World');
};
```

### Build Step
React, Angular, Vue đều cần build step để:
- Compile JSX → JavaScript
- Minify code
- Optimize bundle
- Tree shaking

## Docker Challenge

### Development Container
```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
CMD ["npm", "start"]
```

Container chạy development server với hot reloading.

### Production Container
```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build  # Build step
CMD ["npm", "start"]  # Không tối ưu cho production
```

Vấn đề: `npm start` chạy development server, không serve production build.

## Giải Pháp: Separate Dockerfiles

### Dockerfile (Development)
```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
EXPOSE 3000
CMD ["npm", "start"]
```

### Dockerfile.prod (Production)
```dockerfile
FROM node:18-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build

FROM nginx:stable-alpine
COPY --from=builder /app/build /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

## Multi-Stage Builds

Docker multi-stage builds cho phép:
1. Stage 1: Build code với Node.js
2. Stage 2: Serve với Nginx
3. Chỉ ship stage cuối cùng → image nhỏ hơn

## Kết Luận

Frontend applications đòi hỏi build step riêng cho production. Docker multi-stage builds là giải pháp tối ưu để build và serve production-ready code trong container.
