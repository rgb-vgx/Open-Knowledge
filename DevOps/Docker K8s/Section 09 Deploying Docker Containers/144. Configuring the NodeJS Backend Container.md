# Cấu Hình NodeJS Backend Container Trên ECS

Trong bài viết này, chúng ta sẽ đi qua chi tiết cách cấu hình backend container trên ECS, bao gồm environment variables, command override, và các settings quan trọng khác.

## Tạo Task Definition

### Bước 1: Tạo Cluster
1. ECS Console → Clusters → Create Cluster
2. Chọn "Networking only" (Fargate)
3. Đặt tên cluster
4. Tạo VPC
5. Click Create

### Bước 2: Tạo Task Definition
1. Task Definitions → Create new Task Definition
2. Chọn Fargate
3. Task name: goals
4. Task role: ecsTaskExecutionRole
5. Memory: 0.5 GB, CPU: 0.25 vCPU

### Bước 3: Add Container

#### Container Basic Settings
- **Container name**: goals-backend
- **Image**: yourusername/goals-node
- **Memory limits**: 0.5 GB

#### Port Mappings
- **Container port**: 80
- **Protocol**: TCP

#### Environment Variables
Thêm key-value pairs:
- `MONGODB_USERNAME`: max
- `MONGODB_PASSWORD`: secret
- `MONGODB_URL`: localhost
- `MONGODB_NAME`: goals

#### Command Override
Trong Production, thay `npm start` bằng:
```
node, app.js
```

Lý do: `npm start` dùng nodemon (cho development), production cần chạy trực tiếp với node.

## Tạo Service

1. Từ cluster, click Create Service
2. Launch type: Fargate
3. Task Definition: goals
4. Service name: goals_service
5. Number of tasks: 1
6. Click Next

### Network Configuration
1. VPC: Chọn VPC vừa tạo
2. Subnets: Chọn cả hai subnets
3. Auto-assign Public IP: Enabled
4. Security Group: Chọn hoặc tạo mới

### Load Balancer (Optional)
1. Chọn Application Load Balancer
2. Tạo target group mới
3. Health check path: /goals (vì app chỉ có endpoint này)

### Hoàn Tất
Review và Create. ECS sẽ deploy containers và configured infrastructure.

## Verify

1. Vào Service → Tasks
2. Click vào task
3. Lấy Public IP
4. Test: `GET http://public-ip/goals`

## Lưu Ý

1. **Luôn rebuild image** khi thay đổi Dockerfile
2. **Environment variables** override Dockerfile defaults
3. **Command override** cho phép chạy different commands cho dev/prod
4. **Load balancer health check** cần đúng path

## Kết Luận

Cấu hình backend container trên ECS đòi hỏi attention to detail. Điểm quan trọng nhất là environment variables và command override để đảm bảo application chạy đúng trong production.
