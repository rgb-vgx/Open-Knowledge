# Tìm Hiểu Thêm Về AWS: Fargate và Auto Scaling

Trước khi đi sâu hơn vào ECS, có một số khái niệm quan trọng cần hiểu rõ để sử dụng AWS ECS hiệu quả.

## Fargate - Serverless Container Execution

Fargate là launch type “serverless” cho ECS. Thay vì chạy containers trên EC2 instances mà bạn quản lý, Fargate sẽ:

### Cách Fargate Hoạt Động

1. **Không tạo EC2 instance cố định**: AWS sẽ tạo server on-demand khi có request
2. **Chỉ trả tiền khi chạy**: Không có idle cost
3. **Fully managed**: AWS lo patches, updates, monitoring

### Task Size

Khi tạo task definition, bạn chọn:
- **CPU**: 0.25 vCPU, 0.5 vCPU, 1 vCPU, 2 vCPU, 4 vCPU
- **Memory**: Phụ thuộc vào CPU selection

Với demo, chọn minimal size để test. Production cần chọn size phù hợp workload.

## Auto Scaling

ECS hỗ trợ auto scaling để xử lý traffic spikes:

### Scaling Types

1. **Service Auto Scaling**: Thay đổi number of tasks
2. **Target Tracking Scaling**: Duy trì metric ở mức mục tiêu
3. **Step Scaling**: Scale theo CloudWatch alarms

### Khi Nào Cần Auto Scaling?

- Traffic không predictable
- Có seasonal patterns (Black Friday, etc.)
- Cần high availability

## VPC và Subnets

Khi tạo ECS cluster, AWS sẽ tạo:

### VPC (Virtual Private Cloud)
- Network ảo riêng cho cluster
- Isolated từ internet (nếu cần)
- Control inbound/outbound traffic

### Subnets
- **Public Subnets**: Containers có thể truy cập internet
- **Private Subnets**: Containers chỉ truy cập internal resources
- across multiple AZ (Availability Zones) cho high availability

## Security Groups

Security groups đóng vai trò firewall:
- Control inbound traffic
- Control outbound traffic
- At instance level (không phải subnet level)

## Best Practices

1. **Bắt đầu đơn giản**: Test với minimal configuration
2. **Monitor chi phí**: Luôn check billing dashboard
3. **Sử dụng最小 resources** cho demo/test
4. **Xóa resources** khi không sử dụng
5. **Đọc documentation**: AWS có docs rất tốt

## Kết Luận

Hiểu rõ Fargate, Auto Scaling, VPC và Security Groups giúp bạn sử dụng ECS hiệu quả hơn. Đây là foundation để build production-ready container architecture trên AWS.
