# Kết Nối EC2 Instance Qua SSH: Hướng Dẫn Chi Tiết

Khi đã tạo EC2 instance thành công, bước tiếp theo là kết nối tới nó để cài đặt Docker và triển khai ứng dụng. SSH (Secure Shell) là protocol chuẩn để kết nối từ xa đến server.

## Chuẩn Bị

### Key Pair
Khi tạo EC2 instance, bạn đã download một file key pair (.pem hoặc .ppk). File này:
- **Quan trọng như chìa khóa nhà bạn** - ai có file này sẽ truy cập được server
- Chỉ download được MỘT LẦN duy nhất
- Không bao giờ share hay commit lên git

### SSH Client
- **macOS/Linux**: Terminal tích hợp sẵn SSH
- **Windows**: PuTTY hoặc WSL 2

## Kết Nối Từ macOS/Linux

### Bước 1: Set Permissions Cho Key File
```bash
chmod 400 your-key.pem
```

Lệnh này đảm bảo chỉ owner mới có quyền đọc file key. Nếu không chạy lệnh này, SSH sẽ từ chối kết nối vì lý do bảo mật.

### Bước 2: Kết Nối
```bash
ssh -i "your-key.pem" ec2-user@your-public-ip
```

Bạn sẽ thấy prompt xác nhận (type yes), sau đó được đưa vào terminal của EC2 instance.

## Kết Nối Từ Windows

### Phương Pháp 1: PuTTY
1. Download và cài PuTTY
2. Mở PuTTY, nhập Host Name: `ec2-user@your-public-ip`
3. Trong PuTTY, SSH → Auth → Credentials → Browse chọn file .ppk
4. Open kết nối

### Phương Pháp 2: WSL 2
Nếu đã cài WSL 2, bạn có thể sử dụng SSH giống như Linux.

## Verify Kết Nối

Sau khi kết nối thành công, bạn sẽ thấy:
```bash
[ec2-user@ip-172-31-xx-xx ~]$
```

Đây là terminal của remote server. Mọi lệnh bạn chạy giờ đây sẽ thực thi trên EC2 instance, không phải máy cục bộ.

## Cài Đặt Docker

```bash
sudo yum update -y
sudo yum install docker -y
sudo service docker start
sudo usermod -a -G docker ec2-user
```

Sau khi chạy `usermod`, bạn cần đăng nhập lại để nhóm docker có hiệu lực:
```bash
exit
ssh -i "your-key.pem" ec2-user@your-public-ip
```

Verify Docker hoạt động:
```bash
docker version
```

## Troubleshooting

### Lỗi "Permission denied (publickey)"
- Kiểm tra file key có đúng permissions (chmod 400)
- Đảm bảo dùng đúng username (ec2-user cho Amazon Linux)
- Kiểm tra public IP có đúng không

### Lỗi "Connection refused"
- Instance có đang chạy không?
- Security group có mở port 22 không?
- Kiểm tra elastic IP (nếu có)

## Kết Luận

SSH là cánh cửa dẫn đến EC2 instance. Khi đã kết nối thành công, bạn có toàn quyền kiểm soát server từ xa - từ cài đặt phần mềm đến triển khai ứng dụng Docker. Đây là kỹ năng cơ bản nhưng vô cùng quan trọng cho mọi DevOps engineer.
