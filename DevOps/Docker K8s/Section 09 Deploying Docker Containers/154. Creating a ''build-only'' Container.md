# Tạo Build-Only Container: GitHub Actions Setup

GitHub Actions giúp tự động hóa workflow, bao gồm build và push Docker images. Bài viết này hướng dẫn setup pipeline để tự động build multi-stage images.

## GitHub Actions Basics

### Workflow File
Tạo file `.github/workflows/docker-build.yml`:

```yaml
name: Build and Push Docker Image

on:
  push:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v3

      - name: Set up Docker Buildx
        uses: docker/setup-buildx-action@v2

      - name: Login to Docker Hub
        uses: docker/login-action@v2
        with:
          username: ${{ secrets.DOCKERHUB_USERNAME }}
          password: ${{ secrets.DOCKERHUB_TOKEN }}

      - name: Build and push
        uses: docker/build-push-action@v4
        with:
          context: .
          file: ./Dockerfile.prod
          push: true
          tags: ${{ secrets.DOCKERHUB_USERNAME }}/goals-react:latest
```

### Configure Secrets
1. Vào GitHub repo → Settings → Secrets
2. Thêm:
   - `DOCKERHUB_USERNAME`: Docker Hub username
   - `DOCKERHUB_TOKEN`: Docker Hub access token

## Multi-Stage Build Strategy

### Stage 1: Build
```dockerfile
FROM node:18-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build
```

### Stage 2: Production
```dockerfile
FROM nginx:stable-alpine
COPY --from=builder /app/build /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

### Benefits
- Image nhỏ hơn đáng kể
- Chỉ chứa production code
- Không có development dependencies
- Attack surface giảm

## CI/CD Pipeline

### Trigger
- Push to main branch
- Pull requests
- Manual trigger

### Steps
1. Checkout code
2. Set up Docker Buildx
3. Login Docker Hub
4. Build multi-stage image
5. Push to Docker Hub

## Verify

1. Push code lên GitHub
2. Vào Actions tab
3. Xem workflow running
4. Kiểm tra Docker Hub cho image mới

## Kết Luận

GitHub Actions giúp tự động hóa quy trình build và push Docker images. Multi-stage builds ensure images production-ready và tối ưu. Đây là foundation cho modern CI/CD pipeline.
