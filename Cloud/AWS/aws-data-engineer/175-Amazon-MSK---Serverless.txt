Instructor: So, here is another very short lecture
called MSK Serverless.
In MSK, as we know, we provision a Kafka cluster
and we pay per hour,
but with MSK Serverless, we run Apache Kafka on MSK
without managing the capacity,
and MSK will automatically provision resources
and will scale the compute and storage,
so it makes it very easy for us
to understand what's happening.
And so therefore, from a user perspective,
all you have to do is to define what topics you want
and how many partitions per topic and you're good to go.
In terms of security, you get IAM Access Control
for all clusters.
And here's an example pricing.
So you're going to pay $0.75 per cluster per hour,
which gives you $558 monthly dollars per cluster.
Then you're going to pay a pricing per partition per hour,
which is about $1 per partition per month.
Then you're going to pay per storage,
per data in and per data out,
and that is a different way of seeing pricing on MSK
and maybe a model that works better for you.
