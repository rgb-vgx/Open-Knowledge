-: This section's a weird one.
Machine learning is explicitly out of scope
for the data engineering exam.
AWS has an entire specialty exam dedicated just
to machine learning, so it's generally not covered here.
However, Amazon's primary service
for machine learning, SageMaker,
also includes some features that are relevant
to data engineering.
Processing the features
that machine learning models learn from
is a very big part of the job in the ML field,
and so there's some overlap between SageMaker's capabilities
and things like Glue Data Studio.
We'll only have a high-level overview of SageMaker
with all that in mind,
but after that, I'm gonna go into some depth with you
on the data engineering parts of SageMaker
that the exam does expect you to know about,
the SageMaker Feature Store,
SageMaker ML Lineage Tracking,
and perhaps most importantly, SageMaker Data Wrangler,
which is really all about data engineering.
So let's dive in and explore the overlap between SageMaker
and the tools you need as a data engineer.
