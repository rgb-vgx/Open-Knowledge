So if you're using some sort of continuous integration

you'll have the need to validate your deployments
to make sure that you don't need to roll them back
or make sure it's safe to actually roll that out
at a larger scale.
One tool for that is synthetic user workflow.
So the ability to actually simulate
how a user will use your system from end to end.
Now, unit testing probably isn't good enough
for generative AI applications
because it's non-deterministic.
So it's very hard to say this is the expected output
of this foundation model because it's got to change.
It has a temperature.
And even if you change the temperature to be very low,
the model itself changes pretty often too.
So it's very difficult to have a test framework
where you're saying this is the input,
this is the expected output.
It's not that simple with generative AI.
However, you can set up these systems
that simulate the end-to-end usage of your application
and see that it's actually at least behaving correctly
before and after your deployments
and then in an ongoing manner.
Some useful tools for setting up such a system
would be CloudWatch Synthetic Monitoring or Canaries.
You can also roll your own using step functions
to manage the actual flow of events,
EventBridge to kick off these workflows,
and Lambda to execute any actual logic that happens
at each one of these steps in the workflow.
