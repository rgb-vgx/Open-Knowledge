Well, let's talk about model distillation.
Kind of a hot topic these days.
A lot of the AI labs keep accusing each other of distilling their models on each other.
Kind of a way to cheat, but it can be used for legitimate purposes too.
How does it work?
Well, it's actually pretty simple.
The idea is that you're just getting responses from another foundation model and using that
to train your model.
And the idea is to take a large model and potentially use that to make a smaller model better.
So the goal is just to approach the teacher's quality for your specific workload.
So model distillation can be a way of taking the performance from a large model and just
using the bits of it that you need for what you're trying to do.
Now the idea is that the teacher will generate synthetic responses.
So you're giving it a set of prompts and capturing its responses to that set of prompts.
And then your student model will be fine tuned using the data that was generated by the teacher model.
And again, the idea here is not to steal other people's models and their work.
It's usually more legitimately to take a large model and distill that down to a smaller purpose
built model by just getting its responses on a narrow slice of what it can do.
The result can be lower inference cost and latency because you've reduced the size of
the model effectively by doing this and still retaining the task specific quality that you
want for what you've been training it on.
Now this is not the same thing as quantization or pruning.
Those are different techniques for optimizing models.
So quantization just basically compresses the amount of information that you're storing
in the actual model itself.
Pruning might be pruning layers from the model that you might not need.
Distillation is a different approach.
It's basically taking a larger model, taking its output and using that to fine tune a smaller
model rather than compressing the original.
How does this work?
So you start with a set of representative prompts.
So you need to take care in how you choose those prompts.
They need to represent what you want your new model to do, your distilled model.
You then send those prompts into your large teacher foundation model.
That teacher foundation model will hopefully produce high quality synthetic responses that
you can then turn around and use as a training data set for fine tuning on your smaller model.
And then you do that fine tuning on the smaller student model and you end up with a lower
cost lower latency specialized model that's been distilled from the behavior of the larger model.
So that's model distillation.
Basically taking one model, giving it a set of representative prompts for what you want
your smaller model to be able to do, using that output as a training data set for fine
tuning for the lower cost smaller model that specializes in what those prompts represented.
