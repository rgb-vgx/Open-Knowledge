Really quick, let's talk about CodeCommit and CodeConnections, two tightly related technologies.
They're both source control, version control systems.
Kind of a good story here.
They actually tried deprecating CodeCommit at one point and there was this big uproar
from the developers and said, no, we want it back.
So they brought it back.
And as a result, it's back in the exam guide for this exam.
What CodeCommit is, is a AWS hosted Git repository, which is of course a version control system.
It's a private Git repository and it has all the AWS stuff surrounding it, like IAM
and integration with other services.
But what made it special is that this can act as the source stage for a code pipeline.
So if you had a continuous integration, continuous deployment pipeline built in AWS, you could
set things up so that if you do a Git push into CodeCommit, that could automatically
trigger your pipeline for CICD.
So I could push updated training code for machine learning, and then a pipeline could
kick off to actually retrain my data using that training code and redeploy the model automatically.
So the pipeline would look very simply like this, CodeCommit gets a push or something.
That code change can then trigger a pipeline through CodePipeline to do whatever the heck you want.
Now, when they tried to deprecate CodeCommit, what they wanted to do was push people toward
CodeConnections.
And CodeConnections is just a connection between AWS and third party Git repositories.
So if you want to use an existing Git repo, as opposed to CodeCommit, then you can use
CodeConnections to do that.
So that can connect to GitHub, GitHub Enterprise, GitLab, or Bitbucket.
And from that point, it kind of works the same way as CodeCommit.
So if you have CodeConnections hooked up, you can actually see those commits into your
third party repository, and then trigger a code pipeline that way as well.
So in this world, you have some external repository running on GitHub or GitLab or Bitbucket.
CodeConnections monitors that, and then that can trigger your code pipeline for doing continuous
integration and continuous deployment.
So CodeCommit is AWS hosted GitHub, CodeConnections, basically external Git repositories or whatever it might be.
But they both serve the same purpose of integrating your code commits into a code pipeline for
CI, CD under AWS.
