of criteria you have, you need some sort of a threshold there as opposed to exact string
or numerical matches on the output.
So that's how life is a little bit different when you're doing regression testing on generative AI.
The trick is to maintain a fixed evaluation data set or a fixed prompt data set and then
running that evaluation data set across your new prompt or your new model whenever it changes.
And these evaluations should cover normal cases, edge cases, and the key business scenarios
that you care about just like with any other testing that you might be doing, right?
Now optionally, you can also have ground truth responses.

But again, you can't do an exact string match, you just have to say, well, how close semantically
was my answer to what I think is the correct answer here?
