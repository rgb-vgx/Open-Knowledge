So now let's talk about Trusted Advisor.
So it's a service in which
you do not need to install anything.
It gives you a high level assessment of your AWS accounts.
So on the UI, you will see checks, for example,
if you have Amazon EBS Public Snapshots,
RDS Public Snapshots if you use IAM correctly and so on.
And it allows you to analyze your AWS accounts
and provides you recommendations on six categories,
cost optimization, performance, security, fault tolerance,
service limits, and operational excellence.
So it's available for free, but if you have the business
or enterprise support plan, then you get the full set
of checks and on top of it, you get programmatic access
to Trusted Advisor using the AWS Support API.
It also has integration with Security Hub,
Config and Compute Optimizer.
So if you wanted to automate notifications coming out
of Trusted Advisor, for example, if you wanted
to get notifications on metrics such as service limit usage,
then you could integrate it with directly
with a CloudWatch alarm and then invoke SNS
to get yourself emails as an administrator.
You also have the option to use Trusted Advisor
with AWS organizations to get
an aggregated view across all your accounts.
For this, your organization must have enabled
all the features and also have a business enterprise
on ramp or enterprise support plan.
So here we have multiple member accounts
and each trusted advisor will report
to the management account.
Finally, in Trusted Advisor,
you need to enable trusted access with AWS Organization
in the management account, or whichever account
has been named as the delegated administrator account.
