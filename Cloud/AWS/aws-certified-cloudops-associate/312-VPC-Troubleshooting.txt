So some quick troubleshooting wisdom.
You cannot change or modify the IPv4 CIDR block
of an existing VPC.
You can remove and add a new IPv4 CIDR block instead
or add a secondary IPv4 CIDR block.
Or you can create a new VPC
with a different IPv4 CIDR block.
For example, this would be the case
when your VPC CIDR conflicts with another VPC
or with on-premises CIDR block.
You cannot also change or modify the IPv4 CIDR block
of an existing Subnet.
What you can do is you can create a new Subnet
with a new IPv4 CIDR block.
So for example, this is when you would not have enough
IPv4 addresses in your Subnet.
Then you create a new Subnet
with a larger CIDR block.
So these are common networking questions
that can come up the exam, you should know by then,
but it's good to get a refresher.
