# 257. Security Hub - Managing Multiple Accounts

# Caption: en_US (manual)

So, it is possible for you
to manage multiple accounts using Security Hub.
For this, you're going to integrate Security Hub
with AWS Organizations so you can manage
all of your member accounts from straight
from an administrator accounts.
So you can either use the admin account
or you can designate a Security Hub delegated administrator,
and then, Security Hub will be automatically enabled
across all your member accounts as well.
Then you manage your Security Hub directly
with a centralized configuration
from that one administrator account.
For example, it's possible for you
to run the CIS AWS Benchmark to scan all the accounts
and monitor them from a central Security Hub.
