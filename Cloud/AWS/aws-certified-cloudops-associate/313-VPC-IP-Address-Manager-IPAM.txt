So now let's talk about
VPC IP Address Manager, or IPAM.
It's a way for you to centrally plan, track,
and monitor your IP address spaces.
It gives you a single source of truth
for all your IP address information.
And this can be done across hundreds of accounts and VPC.
So it's one way for you to manage all the addresses.
So you have a scope, which is a top-level container
that encapsulates all the IP address space that you want.
You have the default public and private scope.
And then you have an IP pool,
which is the collection of IP address ranges, or CIDRs,
that can be divided into sub-pools for regional IP pool.
I'll show you a diagram so you better understand
right now in the next slide.
And you can also monitor your IP addresses
and provide alerts when it detects potential issues,
such as potential overlapping IP addresses.
So the use cases is, number one,
a multi-account way to manage your IP address space
across multiple accounts and make sure they don't overlap,
but also to edit public IP usage,
to identify unused IP addresses,
to monitor CIDR allocation,
and to reclaim unused IP addresses.
So here is the example.
We have, in one account,
the VPC IP Address Manager, or IPAM.
And you create a scope.
And in scope, you create this pool.
And so this is the parent IP pool,
and you're saying, "Okay, all the private IP addresses
with a CIDR 10.0.0.0/8 is what I wanna use
across all my accounts."
And then you have different regions or sub-accounts.
And the first region, Region A, will have a child IP pool
with a different CIDR, so /16.
And so any VPC that falls within this child IP pool is okay.
But if you have a VPC that falls outside of this IP pool,
it's not gonna be okay and it's going to be refused.
And so in Region B, you have a different child IP pool
with a different CIDR that don't overlap,
and so therefore, all the VPCs created within
that Region B will not overlap with the VPCs of Region A.
But you can see how this can scale
to all the regions and hundreds of accounts
to make sure nothing overlaps across all your network
and avoid you some headaches in the future.
