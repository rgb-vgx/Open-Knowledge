# 🎨 AWS Console UI mới: Có gì thay đổi và bạn cần lưu ý gì?

> Nguồn: `009-Important-AWS-Console-UI-Update.txt` · [Udemy](https://ua.udemy.com/course/aws-certified-cloud-practitioner-new/learn/lecture/47890637)

Trước khi bắt đầu khóa học, có một lưu ý nhanh về việc **UI (giao diện) của AWS vừa được cập nhật**. *Đừng lo — mọi thứ chỉ khác về hình thức, còn cách dùng thì y nguyên.*

---

### 🎨 UI mới trông như thế nào?

* Console mới có nền **trắng sáng, rộng rãi**, các nút bấm **bo tròn** màu **xanh dương sáng**.
* UI cũ trông **xám hơn**, màu xanh **nhạt hơn**, nút bấm **vuông** chứ không bo tròn.
* Tổng thể UI mới **bo tròn nhiều hơn, hiện đại hơn (more roundness, more modernness)**.

*Nói cách khác: nếu console của bạn trông sáng và bo tròn hơn, đó chính là UI mới.*

| Tiêu chí | UI cũ | UI mới |
|---|---|---|
| Màu nền | Xám hơn | Trắng sáng |
| Màu xanh | Nhạt | Xanh dương sáng |
| Nút bấm | Vuông | Bo tròn |
| Cảm giác | Cũ hơn | Hiện đại hơn |

---

### ✅ Điều quan trọng nhất: Usability không đổi

* Nhìn thì khác, nhưng **usability (khả năng sử dụng) hoàn toàn giống nhau**.
* Nếu các bạn xem video được quay với UI mới, cứ yên tâm: trải nghiệm dùng sẽ **y hệt** — không chỉ giống về mặt hình ảnh.
* Vậy nên các bạn cứ học bình thường, không cần lo lắng về việc giao diện đổi mới.

---

### 🎬 Còn các video quay bằng UI cũ thì sao?

* Mình sẽ **giữ nguyên các video cũ** vì có rất nhiều video đang chạy trên UI cũ.
* UI mới sẽ để các bạn tự làm quen — nó **chỉ khác màu sắc và hình dạng nút bấm**.
* Nếu mọi thứ thay đổi quá nhiều, ví dụ **nút bấm đổi vị trí**, các bạn hãy **báo cho mình biết**; mình sẽ cố gắng cập nhật lại một số video.

---

Vậy là các bạn đã sẵn sàng. Dù console nhìn thế nào, kiến thức vẫn vậy — và chúng ta sẽ bắt đầu ngay ở bài tiếp theo. Hẹn gặp các bạn! 🚀
