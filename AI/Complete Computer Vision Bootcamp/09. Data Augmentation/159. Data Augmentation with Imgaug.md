# 🧰 Data Augmentation với imgaug — pipeline cổ điển

> Nguồn: `159 - Data Augmentation with Imgaug.md` · [Udemy](https://viettel.udemy.com/course/complete-computer-vision-bootcamp-with-pytoch-tensorflow/learn/lecture/49130489)

**imgaug** là thư viện augmentation lâu đời, từng rất phổ biến (nhiều star trên GitHub). Transcript thẳng thắn: phần lớn code đã **deprecated 5–6 năm**, nhưng vẫn đáng biết vì nhiều pipeline cũ dùng nó. Bài này mình xem các phép biến đổi cơ bản và cách sinh ảnh hàng loạt.

### 📦 Import

```python
import imgaug as ia
import imgaug.augmenters as iaa
```

`iaa` chứa các augmenter; `ia` chứa tiện ích. Dataset mẫu vẫn là **6 ảnh** trong thư mục `sample_images`.

### 🖼️ Visualize từng phép biến đổi

Hàm visualize áp lần lượt nhiều phép lên cùng một ảnh:

* **Flipped** — lật ảnh.
* **Rotated** — xoay.
* **Blurred** — làm mờ.
* **Brightness** — đổi độ sáng.
* **Noise** — thêm nhiễu.
* **Cropped** — cắt.
* **Grayscale** — chuyển xám.

Kết quả plot thành một hàng: ảnh gốc, flipped, rotated, blurred, grayscale, cropped, noise. Cách này giúp chọn nhanh phép nào phù hợp với dữ liệu.

---

### 🔁 Pipeline augmentation

Hàm `augment_images` thực hiện:

1. Tạo **output directory** nếu chưa có.
2. Load ảnh.
3. Đổi **BGR → RGB** vì đọc bằng OpenCV.
4. Áp pipeline gồm nhiều augmenter.

Các phép trong pipeline:

* **`iaa.Fliplr`** — lật ngang.
* **`iaa.Affine`** — xoay/affine.
* **`iaa.GaussianBlur`** — blur.
* **`iaa.Multiply`** — thay đổi độ sáng.
* **`iaa.Crop`** — cắt ảnh.
* Các phép khác tùy chọn.

Tham số **0.5** quyết định **xác suất** áp dụng — thường đặt qua `iaa.Sometimes(0.5, ...)` để mỗi ảnh có 50% cơ hội bị biến đổi.

Sau khi augment, ảnh được lưu bằng **`cv2.imwrite`**.

### 💡 Lời khuyên cuối

Transcript nhấn mạnh: **nên dùng data augmentation** bất kể dataset lớn hay nhỏ.

* Dataset nhỏ → augment để tăng số lượng.
* Dataset lớn → vẫn nên augment, ví dụ lấy **10%** ảnh và sinh thêm biến thể.

Lợi ích: model **generalize tốt hơn**, ít overfit hơn, robust hơn với dữ liệu thực tế. Đây cũng là kết thúc của section Data Augmentation — cầu nối sang các bài về **object detection**.
