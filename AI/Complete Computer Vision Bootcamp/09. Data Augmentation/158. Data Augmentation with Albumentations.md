# 🎨 Data Augmentation với Albumentations — một pipeline, nhiều biến thể

> Nguồn: `158 - Data Augmentation with Albumentations.md` · [Udemy](https://viettel.udemy.com/course/complete-computer-vision-bootcamp-with-pytoch-tensorflow/learn/lecture/49130485)

**Albumentations** là thư viện augmentation chuyên dụng, được transcript đánh giá là lựa chọn số một hiện nay. Bài này mình đi từ một phép biến đổi đơn lẻ, đến pipeline nhiều phép, rồi viết hàm sinh hàng loạt ảnh từ một thư mục — biến **6 ảnh** thành **60**.

### 📦 Import

```python
import cv2
import albumentations as A
from albumentations.pytorch import ToTensorV2
import numpy as np
from tqdm import tqdm
import matplotlib.pyplot as plt
import random
```

* **OpenCV (`cv2`)** — đọc/ghi ảnh.
* **Albumentations (`A`)** — các phép augmentation.
* **`ToTensorV2`** — chuyển ảnh sang tensor PyTorch.
* **NumPy**, **tqdm**, **Matplotlib**, **random**.

Dữ liệu mẫu chỉ có **6 ảnh**, đủ để minh họa. Ảnh đọc bằng OpenCV ở hệ **BGR**, cần đổi sang **RGB** trước khi hiển thị.

---

### ↔️ Horizontal Flip với xác suất

```python
transform = A.HorizontalFlip(p=0.5)
augmented = transform(image=image)["image"]
```

`p=0.5` nghĩa là mỗi ảnh có **50%** khả năng bị lật. Với dataset 10 ảnh, trung bình khoảng 5 ảnh được biến đổi. Kết quả trả về là **dict**, lấy ảnh qua key `"image"`.

Có thể đặt **random seed** để tái lập kết quả.

---

### 🔄 ShiftScaleRotate

```python
A.ShiftScaleRotate(...)
```

Phép này dịch, scale và xoay ảnh. Hệ quả dễ thấy: khi ảnh dịch ra khỏi khung, phần trống được lấp bằng **nền đen**.

---

### 🧪 Pipeline nhiều phép

```python
transform = A.Compose([
    A.Transpose(p=...),
    A.RandomRotate90(p=...),
    A.Blur(p=...),
    A.GridDistortion(p=...)
])
```

`A.Compose` gộp nhiều phép thành một pipeline, áp lên ảnh trong **một lần gọi**. Vì các phép có yếu tố ngẫu nhiên, mỗi lần chạy cho một kết quả khác — có khi blur, có khi noise, có khi xoay.

Các phép blur/noise như **MotionBlur**, **MedianBlur** cũng nằm trong nhóm này.

---

### 📁 Sinh ảnh hàng loạt

Hàm `augment_images(input_folder, output_folder, num_augmented=10)`:

1. Nếu **output folder** chưa có thì tạo mới.
2. Quét các file **`.png`, `.jpg`, `.jpeg`**.
3. Tạo augmenter bằng `A.Compose([...])`.
4. Với từng ảnh:
   * Đọc bằng `cv2.imread`.
   * Chạy augmenter. Nếu pipeline trả tensor ở dạng **CHW**, cần **`permute(1, 2, 0)`** về HWC.
   * Transcript nhân giá trị pixel với **255** rồi chuyển về **`np.uint8`** trước khi ghi ảnh.
   * Ghi ảnh vào output folder.

Chạy với `num_augmented=10` trên 6 ảnh sẽ tạo ra khoảng **60 ảnh**. Transcript kiểm tra thư mục `augmented_images` và thấy nhiều biến thể với các phép khác nhau.

Sau đó thêm **ColorJitter** vào pipeline để thấy rõ thay đổi về màu sắc.

---

### ⚠️ Chọn phép cho đúng dataset

Đây là lưu ý quan trọng nhất: **không phải phép nào cũng phù hợp mọi dataset**.

Ví dụ kinh điển: xoay chữ số **6** có thể thành **9**. Với bài nhận dạng chữ số, phép xoay 180° sẽ tạo nhãn sai. Vì vậy phải hiểu dữ liệu trước, rồi mới chọn augmentation.

Bài tiếp theo mình làm điều tương tự với thư viện **imgaug**.
