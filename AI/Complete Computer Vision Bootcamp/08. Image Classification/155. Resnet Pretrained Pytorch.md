# 🦓 ResNet50 Pretrained PyTorch — nhanh và gọn hơn Keras

> Nguồn: `155 - Resnet Pretrained Pytorch.md` · [Udemy](https://viettel.udemy.com/course/complete-computer-vision-bootcamp-with-pytoch-tensorflow/learn/lecture/49109357)

Bản PyTorch của ResNet50 pretrained. Điểm hay: **class labels** đã nằm sẵn trong metadata của weights, không cần tải file `.txt` như Keras. Vẫn ảnh zebra, vẫn kết quả đúng.

### 📦 Import

```python
import torch
import torchvision.models as models
from torchvision import transforms
from PIL import Image
```

---

### 🏗️ Load model

```python
model = models.resnet50(pretrained=True)
model.eval()
```

`model.eval()` bật chế độ inference. Model summary rất lớn vì ResNet50 dùng **bottleneck block** ở các stage.

> ⚠️ Cần kiểm chứng: `pretrained=True` là API cũ; torchvision mới dùng `weights=ResNet50_Weights.IMAGENET1K_V2`.

---

### 🖼️ Transform

```python
transform = transforms.Compose([
    transforms.Resize(...),
    transforms.ToTensor(),
    transforms.Normalize(mean=[...], std=[...])
])
```

Resize, chuyển tensor, normalize bằng **mean/std của ImageNet** — công thức lặp lại ở mọi bài pretrained.

---

### 🔍 Inference

1. Mở ảnh zebra bằng **PIL**.
2. Áp transform.
3. **Thêm chiều batch**.
4. `torch.no_grad()`.
5. `model(image)`.
6. Lấy **top-3** dự đoán (`k=3`, có thể đổi thành 5).

---

### 🏷️ Class labels từ metadata

Điểm khác biệt so với Keras:

```python
weights = models.ResNet50_Weights.DEFAULT
categories = weights.meta["categories"]
```

Trong Keras phải load một file `.txt` chứa tên class; ở PyTorch, danh sách category có sẵn trong **metadata của weights**. Chỉ cần đọc ra là dùng.

### 💡 Tóm lại

PyTorch pretrained ResNet50 gói trong bốn bước: load model + eval, transform, forward không gradient, đọc labels từ metadata. Bài tiếp theo là phần thực hành cuối của ResNet: **transfer learning** trên dataset hoa.
