# 🍓 ResNet50 Transfer Learning — bài thực hành lớn nhất section

> Nguồn: `156 - Resnet Transfer Learning.md` · [Udemy](https://viettel.udemy.com/course/complete-computer-vision-bootcamp-with-pytoch-tensorflow/learn/lecture/49109365)

Bài cuối của section 8 là một bài transfer learning "đúng nghĩa": dataset **5 loại trái cây**, gần **9.700 ảnh**, dùng **ResNet50** pretrained trên GPU **L4**. Sau 5 epoch, validation loss **0.2**, accuracy gần **90%** — nhưng vẫn có vài dự đoán sai đáng để học.

### 🍎 Dataset

Cấu trúc thư mục gồm `train`, `test`, `valid`. Bài chỉ dùng **train** và **test** cho đơn giản.

* **5 class**: apple, banana, grape, mango, strawberry.
* Khoảng **9.700 ảnh** train, mỗi class khoảng **1.940 ảnh**.
* Tập validation/test khoảng **2.020 ảnh**.

Vì dataset lớn hơn các bài trước, transcript chọn GPU **L4** thay vì T4.

---

### 🔄 Transform và DataLoader

```python
transform = transforms.Compose([
    transforms.Resize(...),
    transforms.ToTensor(),
    transforms.Normalize(mean=[...], std=[...])
])
```

Resize, ToTensor, Normalize theo **mean/std ImageNet** — giữ nhất quán với các bài pretrained.

`ImageFolder` load ảnh theo cấu trúc thư mục; `DataLoader` dùng **batch_size = 30** cho cả train và test. Transcript in thêm thông tin dataset: số class, tên class, tổng ảnh, phân bố ảnh từng class.

---

### 🏗️ ResNet50 và thay classifier

```python
from torchvision.models import ResNet50_Weights

model = models.resnet50(weights=ResNet50_Weights.IMAGENET1K_V2)
model.fc = nn.Linear(model.fc.in_features, len(train_dataset.classes))
model = model.to(device)
```

Điểm khác biệt so với VGG: ResNet không có `classifier` dạng `Sequential`, mà có một lớp **`fc`** duy nhất. Chỉ cần thay `model.fc` bằng `nn.Linear` đúng số class — ở đây là **5**.

> ⚠️ Cần kiểm chứng: transcript dùng `pretrained=True`; API này deprecated từ torchvision 0.13 và bị bỏ ở 0.15. API hiện tại dùng `weights=ResNet50_Weights.IMAGENET1K_V2` (hoặc `ResNet50_Weights.DEFAULT`, tương đương V2).

Loss là **CrossEntropyLoss**, optimizer là **Adam**.

---

### 🚂 Train loop

Cấu trúc quen thuộc:

* `model.train()`.
* Ghi `start_time` để đo tổng thời gian.
* Mỗi epoch: khởi tạo loss, duyệt batch, chuyển ảnh/nhãn lên GPU, `optimizer.zero_grad()`, forward, tính loss, `loss.backward()`, `optimizer.step()`.
* Cộng `running_loss`, in thông tin.

Số epoch: **5**.
