# 🔥 AlexNet với PyTorch — cùng dataset hoa, cách làm khác

> Nguồn: `143 - AlexNet with Pytorch.md` · [Udemy](https://viettel.udemy.com/course/complete-computer-vision-bootcamp-with-pytoch-tensorflow/learn/lecture/49092889)

Vẫn là dataset hoa hai lớp, nhưng lần này dùng **PyTorch** với `ImageFolder`, `transforms` và một vòng train viết tay. Sau 2 epoch, model đạt **71.98%** test accuracy — cao hơn bản Keras trong cùng điều kiện. Bài này cũng là dịp so sánh hai framework.

### 📦 Import và transform

Các import quen thuộc: `torch`, `torch.nn`, `torch.optim`, `torchvision.transforms`, `DataLoader`, `matplotlib`.

PyTorch không có `ImageDataGenerator` như Keras; thay vào đó dùng **`transforms.Compose`** để nối nhiều phép biến đổi:

```python
transform = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
    transforms.Normalize(mean=[...], std=[...])
])
```

* **Resize** ảnh về **224 × 224 × 3** (từ 150 × 150 ban đầu).
* **ToTensor** chuyển ảnh thành tensor.
* **Normalize** theo **mean/std của ImageNet** — transcript nói rõ đây là giá trị dùng chung cho ImageNet, không tính riêng cho dataset hoa, nhưng thường vẫn hoạt động tốt với các class phổ thông.

### 📂 `ImageFolder` và DataLoader

```python
dataset = torchvision.datasets.ImageFolder(root=data_path, transform=transform)
```

`ImageFolder` đọc ảnh theo cấu trúc thư mục, mỗi thư mục con là một class. `DataLoader` chia batch và đưa dữ liệu lên GPU. Transcript cũng in thông tin dataset: tổng số mẫu, batch size, shape, danh sách class và số class.

---

### 🔁 Hàm `train`

Hàm `train(num_epochs)` mặc định **10 epoch**, nhưng trong bài chỉ chạy **2** vì dataset hơn **1000 ảnh** sẽ mất thời gian.

Mỗi epoch:

1. `model.train()`.
2. Khởi tạo `running_loss`, `correct`, `total`.
3. Duyệt `for images, labels in train_loader`.
4. Chuyển ảnh và nhãn lên **device** (CPU hoặc GPU).
5. `optimizer.zero_grad()` — xóa gradient cũ, tránh cộng dồn.
6. `outputs = model(images)`.
7. Tính loss bằng `criterion`.
8. `loss.backward()` — tính gradient.
9. `optimizer.step()` — cập nhật trọng số.
10. Cộng `loss.item()` vào `running_loss`.
11. `_, predicted = outputs.max(1)` — lấy class có score cao nhất.
12. `correct += predicted.eq(labels).sum().item()` — đếm dự đoán đúng.
13. `total` cộng số ảnh trong batch.

Cuối epoch: `epoch_loss = running_loss / len(train_loader)` và `accuracy = 100 * correct / total`.

### 🏗️ Class `AlexNet`

Class kế thừa `nn.Module`, chia làm hai phần:

* **`self.features`** — các **convolution block**: conv → ReLU → max pooling, lặp lại và tăng dần số filter. Kernel có thể là **5 × 5** hoặc **3 × 3**; đây đều là hyperparameter.
* **`self.classifier`** — các **linear layer**, ReLU, **dropout**, và lớp cuối với **num_classes**.

Bản này không dùng **LRN**; PyTorch thực ra có sẵn `nn.LocalResponseNorm` nếu muốn thêm. Transcript gợi ý có thể thêm **batch normalization** vào các block conv nếu muốn.

`forward` rất gọn:

```python
def forward(self, x):
    x = self.features(x)
    x = torch.flatten(x, 1)
    x = self.classifier(x)
    return x
```

### 📊 Evaluate

Hàm evaluate làm gần giống train, nhưng:

* Duyệt **test_loader**.
* `model.eval()`.
* `torch.no_grad()`.

Kết quả sau 2 epoch: **test accuracy = 71.98%**. Training loss giảm và training accuracy tăng, nhưng vẫn cần nhiều epoch hơn để đạt kết quả tốt.

### 🔍 Inference ảnh tự chọn

```python
from PIL import Image

image = Image.open(image_path)
image = transform(image).unsqueeze(0).to(device)
model.eval()
with torch.no_grad():
    output = model(image)
predicted = output.argmax(1)
```

`unsqueeze(0)` thêm chiều batch cho một ảnh đơn. Có thể dùng PIL, OpenCV hoặc thư viện khác để load ảnh. Transcript thử với ảnh dandelion và daisy, kết quả khớp.
