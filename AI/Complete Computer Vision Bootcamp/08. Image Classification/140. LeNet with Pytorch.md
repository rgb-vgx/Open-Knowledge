# 🔥 LeNet với PyTorch — nhiều code hơn nhưng thấy rõ từng bước

### 🏗️ Định nghĩa `LeNet5(nn.Module)`

Class kế thừa **`nn.Module`**, trong `__init__` gọi `super().__init__()` rồi khai báo các layer.

**Conv 1** dùng `nn.Conv2d` với tham số theo thứ tự của PyTorch:

```python
nn.Conv2d(in_channels=1, out_channels=6,
          kernel_size=5, stride=1, padding=2)
```

Khác Keras, PyTorch nhận **in_channels trước, out_channels sau**. Ảnh grayscale nên `in_channels=1`, 6 filter. **`padding=2`** được thêm để giữ nguyên kích thước **28 × 28**.

Sau đó là **`nn.ReLU`** và **`nn.AvgPool2d(kernel_size=2, stride=2)`**. Pooling giảm **28 → 14**, số channel không đổi.

**Conv 2** nhận **6 channel** từ lớp trước, tăng lên **16 filter**, kernel 5 × 5, stride 1. Với input 14 × 14, output còn **10 × 10**; qua pooling còn **5 × 5 × 16**.

Sau conv là **ba lớp fully connected** (transcript không nêu con số cụ thể): **FC1 → ReLU**, **FC2 → ReLU**, **FC3** là output layer.

---

### 🔁 Forward pass

```python
def forward(self, x):
    x = self.pool(F.relu(self.conv1(x)))
    x = self.pool(F.relu(self.conv2(x)))
    x = x.view(x.size(0), -1)      # flatten
    x = F.relu(self.fc1(x))
    x = F.relu(self.fc2(x))
    x = self.fc3(x)
    return x
```

Thứ tự trong mỗi block là **convolution → ReLU → pooling**. Flatten chuyển **5 × 5 × 16** thành vector 1D trước khi vào FC.

Hai thay đổi so với bản gốc: dùng **ReLU** thay **tanh**, nhưng vẫn giữ **average pooling** thay vì max pooling.

### 🖼️ Transform và DataLoader

```python
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.1307,), (0.3081,))
])
```

`ToTensor()` đưa pixel về tensor trong khoảng **0–1**; `Normalize` đưa về phân phối quanh **0** để train nhanh và ổn định hơn. Hai con số mean/std này **tính sẵn cho MNIST**; dataset khác phải tự tính.

> ⚠️ Cần kiểm chứng: transcript đọc mean là **0.307**; giá trị thường dùng cho MNIST trong ví dụ chính thức của PyTorch là **0.1307**, std **0.3081**.

Dataset tạo bằng `torchvision.datasets.MNIST(root='data', train=True/False, transform=transform, download=True)`. `DataLoader` chia batch **64**, **shuffle=True** cho train (xáo trộn mỗi epoch) và **False** cho test.

### 🚂 Train loop

```python
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = LeNet5().to(device)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)
```

Mỗi epoch:

1. `model.train()` — bật chế độ training.
2. Duyệt `for images, labels in train_loader`.
3. Chuyển ảnh và nhãn lên **device**.
4. `optimizer.zero_grad()` — xóa gradient cũ, vì PyTorch **cộng dồn gradient** mặc định.
5. Forward: `outputs = model(images)`.
6. Tính loss bằng **cross-entropy**.
7. `loss.backward()` — backward propagation.
8. `optimizer.step()` — cập nhật trọng số.
9. Cộng `loss.item()` vào `running_loss`.

Cuối epoch, loss trung bình = `running_loss / len(train_loader)`.

---

### 📊 Evaluate

* `model.eval()` — chuyển sang chế độ evaluation (dropout, batch norm hoạt động khác khi train).
* `torch.no_grad()` — tắt tính gradient để tiết kiệm bộ nhớ và tăng tốc inference.
* Dự đoán bằng `torch.max(outputs, 1)`, so với nhãn để cộng `correct` và `total`.
* Accuracy = `100 * correct / total`.

---

### 🔍 Inference một ảnh

Hàm `predict_image` bật `eval()`, dùng `no_grad()`, đưa ảnh lên device và **`unsqueeze(0)`** để thêm chiều batch cho một ảnh đơn, rồi trả về `predicted.item()`.
