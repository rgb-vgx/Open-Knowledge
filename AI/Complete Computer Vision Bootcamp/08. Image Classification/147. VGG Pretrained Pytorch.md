# 🐍 VGG Pretrained PyTorch — inference với torchvision.models

> Nguồn: `147 - VGG Pretrained Pytorch.md` · [Udemy](https://viettel.udemy.com/course/complete-computer-vision-bootcamp-with-pytoch-tensorflow/learn/lecture/49092915)

Cùng ảnh green mamba, nhưng lần này dùng **PyTorch**. Cách làm gọn hơn Keras ở chỗ model nằm ngay trong `torchvision.models`; bù lại ta phải tự chuyển **logits** thành xác suất bằng **softmax** và tự map class id sang tên.

### 📦 Import và load model

```python
import torch
import torchvision.models as models
from torchvision.models import VGG16_Weights
```

`torchvision.models` có sẵn **AlexNet**, **VGG**, **ResNet**, **MobileNetV2** và nhiều bản khác. Ở đây gọi **VGG16** với trọng số ImageNet:

```python
model = models.vgg16(weights=VGG16_Weights.IMAGENET1K_V1)
model.eval()
```

> ⚠️ Cần kiểm chứng: transcript không nêu rõ tham số trọng số. Bản gốc dùng `pretrained=True`; API này deprecated từ torchvision 0.13 và bị bỏ ở 0.15. API hiện tại dùng `weights=VGG16_Weights.IMAGENET1K_V1` (tương đương `VGG16_Weights.DEFAULT`).

`model.eval()` là bắt buộc vì chỉ **inference**, không train — dropout và batch norm cần chạy ở chế độ evaluation.

Model summary cho thấy cấu trúc quen thuộc: một phần **`features`** (các convolution block) và một phần **`classifier`**, output **1000 class** cho ImageNet. Lần chạy đầu sẽ download trọng số.

### 🖼️ Transform ảnh

```python
transform = transforms.Compose([
    transforms.Resize(...),
    transforms.ToTensor(),
    transforms.Normalize(mean=[...], std=[...])
])
```

* **Resize** ảnh.
* **ToTensor**.
* **Normalize** bằng **mean/std định sẵn cho ImageNet**.

Hàm tiền xử lý mở ảnh, áp transform, rồi **thêm chiều batch** để model nhận input 4D.

### 🔍 Hàm inference

```python
def infer(image_path):
    image = preprocess(image_path)
    with torch.no_grad():
        output = model(image)
    probabilities = torch.nn.functional.softmax(output, dim=1)
    top5 = torch.topk(probabilities, 5)
    ...
```

Luồng xử lý:

1. **`torch.no_grad()`** — tắt gradient, tiết kiệm bộ nhớ và tăng tốc.
2. **`model(image)`** — trả về **logits** cho từng class.
3. **`softmax`** — chuyển logits thành **xác suất**.
4. **`topk`** — lấy **5 xác suất cao nhất** kèm category id.
5. Map category id sang tên class, trả về danh sách tuple.

### 💡 Nhận xét

PyTorch pretrained chỉ mất vài bước: load model, eval, transform, forward, softmax, top-k. Cách này áp dụng được cho mọi model trong `torchvision.models`, không riêng VGG.

Bài tiếp theo mình bước sang phần thú vị hơn: **transfer learning với VGG** — freeze các lớp đầu và train phần classifier trên dataset riêng.
