# 🦓 ResNet50 Pretrained Keras — 25 triệu tham số, một dòng lệnh

> Nguồn: `154 - Resnet Pretrained Keras.md` · [Udemy](https://viettel.udemy.com/course/complete-computer-vision-bootcamp-with-pytoch-tensorflow/learn/lecture/49109351)

Bài ngắn, đúng tinh thần "pretrained cho xong": load **ResNet50** từ Keras Applications, đưa ảnh **zebra** vào, nhận kết quả **0.99**. Đây cũng là dịp thấy ResNet nhẹ hơn VGG rất nhiều dù sâu hơn.

### 📦 Import

```python
from tensorflow.keras.applications.resnet50 import (
    ResNet50, preprocess_input, decode_predictions
)
from tensorflow.keras.preprocessing.image import load_img, img_to_array
import numpy as np
import matplotlib.pyplot as plt
```

Cấu trúc import giống hệt các bài VGG/Inception: model + `preprocess_input` + `decode_predictions`.

---

### ⬇️ Load model

```python
model = ResNet50(weights='imagenet')
model.summary()
```

Model được **download** về máy với trọng số ImageNet. `model.summary()` rất dài, nhưng con số đáng chú ý: khoảng **25 triệu tham số** — trong khi VGG16 là **138 triệu**. ResNet sâu hơn mà nhẹ hơn nhiều nhờ bottleneck và global average pooling.

---

### 🔍 Predict

Hàm `predict_image(model, image_path)`:

1. **Load ảnh**.
2. **`img_to_array`**.
3. **`expand_dims`** thêm chiều batch.
4. **`preprocess_input`**.
5. **`model.predict`**.
6. **`decode_predictions`** lấy **top 5**.
