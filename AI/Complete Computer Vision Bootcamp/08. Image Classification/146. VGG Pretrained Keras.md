# 🐍 VGG Pretrained Keras — dùng model có sẵn để dự đoán

> Nguồn: `146 - VGG Pretrained Keras.md` · [Udemy](https://viettel.udemy.com/course/complete-computer-vision-bootcamp-with-pytoch-tensorflow/learn/lecture/49092909)

Không cần train gì cả: chỉ cần gọi **VGG16** hoặc **VGG19** từ **Keras Applications** với `weights='imagenet'`, rồi đưa ảnh vào là có dự đoán. Bài này mình thử với ảnh một con **green mamba** và so sánh kết quả giữa hai phiên bản.

### 📦 Keras Applications

**Keras Applications** là nơi chứa các model pretrained, phần lớn được train trên **ImageNet**. Chỉ cần import đúng tên model là dùng được.

Các import cần thiết:

```python
import tensorflow as tf
from tensorflow.keras.applications.vgg16 import VGG16, preprocess_input, decode_predictions
from tensorflow.keras.preprocessing.image import load_img, img_to_array
import numpy as np
import matplotlib.pyplot as plt
```

Với VGG19 thì đổi import sang `vgg19`.

---

### ⬇️ Load model với trọng số ImageNet

```python
model = VGG16(weights='imagenet')
model.summary()
```

`weights='imagenet'` nói rõ chỉ dùng trọng số đã train trên ImageNet. Lần đầu chạy sẽ **download** model từ storage API, mất một chút thời gian.

So sánh nhanh:

* **VGG16** — khoảng **138 triệu** tham số.
* **VGG19** — khoảng **143 triệu** tham số.

`model.summary()` của VGG rất dài, nhưng đó cũng là cách nhanh nhất để thấy model nặng cỡ nào.

---

### 🖼️ Chuẩn bị ảnh

Ảnh mẫu là **green mamba** — một class có sẵn trong ImageNet, nên model pretrained có thể nhận ra.

Quy trình tiền xử lý:

1. **`load_img`** — đọc ảnh.
2. **`img_to_array`** — chuyển thành array.
3. **`expand_dims`** — thêm chiều batch, vì model cần input 4D.
4. **`preprocess_input`** — chuẩn hóa theo cách VGG yêu cầu.
5. **`model.predict`**.
6. **`decode_predictions(top=5)`** — lấy 5 dự đoán có xác suất cao nhất, kèm tên class.

`preprocess_input` của VGG16 dùng được cho cả VGG19 vì hai model có cùng kiểu tiền xử lý.

---

### 🔍 Kết quả

```python
preds = model.predict(img_array)
print(decode_predictions(preds, top=5)[0])
```

Với **VGG19**:

* **Green mamba: 0.77**.

Với **VGG16**:

* **Green mamba: 0.60**.

Cả hai đều dự đoán đúng, nhưng **VGG19** tự tin hơn trên ảnh này (**0.77** so với **0.60**). Transcript kết luận VGG19 đang cho kết quả tốt hơn với ảnh cụ thể này.

---

### ✅ Khi nào dùng cách này?

Dùng pretrained rất đơn giản khi:

* Class bạn cần **đã có trong ImageNet**.
* Bạn chỉ cần **inference**, không cần train thêm.

Nếu class không có trong ImageNet, phải chuyển sang **transfer learning** — train lại một phần model trên dữ liệu của mình. Bài tiếp theo mình làm điều tương tự bằng **PyTorch**.
