# 🪼 Inception Pretrained Keras — pretrained model trong vài bước

> Nguồn: `150 - Inception Pretrained Keras.md` · [Udemy](https://viettel.udemy.com/course/complete-computer-vision-bootcamp-with-pytoch-tensorflow/learn/lecture/49109299)

Sau khi hiểu kiến trúc, bài này mình dùng **InceptionV3 pretrained** từ Keras Applications để dự đoán một ảnh **jellyfish** (sứa). Điểm khác biệt so với VGG: input **299 × 299** thay vì 224, và kết quả rất tự tin — **0.95**.

### 📦 Import từ Keras Applications

```python
from tensorflow.keras.applications.inception_v3 import (
    InceptionV3, preprocess_input, decode_predictions
)
from tensorflow.keras.preprocessing.image import load_img, img_to_array
import numpy as np
```

Keras cung cấp sẵn cả ba hàm quan trọng:

* **`InceptionV3`** — model.
* **`preprocess_input`** — tiền xử lý đúng chuẩn của Inception.
* **`decode_predictions`** — đổi output thành tên class.

---

### ⬇️ Load model

```python
model = InceptionV3(weights='imagenet')
```

`weights='imagenet'` tải trọng số đã train trên ImageNet. Lần đầu chạy sẽ download về máy.

`model.summary()` cho thấy input layer là **299 × 299 × 3**. Bảng summary rất dài vì Inception v3 có nhiều block lặp và các nhánh song song — đúng như kiến trúc đã học ở bài trước.

---

### 🔍 Hàm `predict_image`

```python
def predict_image(model, image_path):
    img = load_img(image_path, target_size=(299, 299))
    img_array = img_to_array(img)
    img_array = np.expand_dims(img_array, axis=0)
    img_array = preprocess_input(img_array)
    preds = model.predict(img_array)
    return decode_predictions(preds, top=5)[0]
```

Năm bước:

1. **`load_img`** với `target_size=(299, 299)` — bắt buộc đúng kích thước input của Inception v3.
2. **`img_to_array`**.
3. **`expand_dims`** thêm chiều batch.
4. **`preprocess_input`** — hàm có sẵn của Keras, nhận batch ảnh và chuẩn hóa theo yêu cầu của model.
5. **`model.predict`** rồi **`decode_predictions(top=5)`**.

### 📊 Kết quả với ảnh jellyfish

Ảnh sứa là class có sẵn trong ImageNet, nên chỉ cần inference:

* **Jellyfish: 0.95** — xác suất rất cao.
* Các dự đoán tiếp theo: **sea animal**, **parachute**, **swimsuit**…

Transcript lặp qua từng tuple `(class_id, label, score)` để in kết quả. Với **0.95**, có thể nói model đang rất chắc chắn.

---

### 💡 Nhận xét

Cách dùng pretrained của Keras rất gọn: import model + ba hàm tiện ích là xong. Khác biệt chính giữa các model là **kích thước input** và **hàm `preprocess_input`** — VGG dùng 224 × 224, Inception v3 dùng 299 × 299.

Khi class cần nhận diện không có trong ImageNet, phải chuyển sang **transfer learning**. Bài tiếp theo mình làm điều đó với Inception v3 trên PyTorch.
