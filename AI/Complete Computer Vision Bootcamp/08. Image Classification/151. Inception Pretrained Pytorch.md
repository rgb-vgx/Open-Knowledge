# 🪼 Inception Pretrained PyTorch — load, transform, predict

> Nguồn: `151 - Inception Pretrained Pytorch.md` · [Udemy](https://viettel.udemy.com/course/complete-computer-vision-bootcamp-with-pytoch-tensorflow/learn/lecture/49109311)

Bản PyTorch của bài trước, lần này dùng **Inception v3** từ `torchvision.models`. Vẫn là công thức quen thuộc: load model pretrained, transform ảnh, forward, map class id sang tên. Kết quả với ảnh green mamba: **87.83%**.

### 🏗️ Load model

```python
import torchvision.models as models

model = models.inception_v3(pretrained=True)
model.eval()
```

Transcript chọn thẳng **v3** vì nhiều cải tiến so với v1 và v2. `model.eval()` bật chế độ inference. Sau khi load có thể xem toàn bộ kiến trúc — rất dài vì Inception có nhiều block.

> ⚠️ Cần kiểm chứng: `pretrained=True` là API cũ; torchvision mới khuyến nghị `weights=Inception_V3_Weights.IMAGENET1K_V1`.

---

### 🖼️ Transform ảnh

```python
transform = transforms.Compose([
    transforms.Resize((299, 299)),
    transforms.ToTensor(),
    transforms.Normalize(mean=[...], std=[...])
])
```

* **Resize 299 × 299** — đúng input của Inception v3.
* **ToTensor**.
* **Normalize** theo mean/std của ImageNet.

Hàm xử lý ảnh mở file, **chuyển sang RGB**, áp transform rồi trả về tensor.

---

### 🏷️ Load class labels

Cần file danh sách **class ImageNet** để đổi index số thành tên người đọc được. Nếu không, output chỉ là các con số 0, 1, 2… rất khó hiểu.

---

### 🔍 Hàm predict

```python
def predict(image_tensor, model):
    with torch.no_grad():
        output = model(image_tensor)
    ...
```

`torch.no_grad()` tránh tích gradient khi chỉ inference. Output được map sang tên class qua danh sách labels.

---

### 📊 Visualization

Hàm visualize nhận **image path**, **predictions** và **labels**:

1. Mở ảnh và plot.
2. Lấy **top 5** dự đoán.
3. In tên class kèm xác suất.

Với ảnh green mamba, kết quả đứng đầu là **Green Mamba — 87.83**.

---

### 💡 Kết luận

Pretrained trong PyTorch gói gọn ở: `models.inception_v3(pretrained=True)` + transform đúng kích thước + `no_grad` + map labels. Nếu class cần nhận diện đã có trong ImageNet, chỉ cần vậy là đủ.

Bài tiếp theo mình mở rộng sang **transfer learning với Inception v3** — thay classifier và train trên dataset hoa.
