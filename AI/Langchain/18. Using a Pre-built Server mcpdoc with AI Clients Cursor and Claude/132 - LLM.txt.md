# Bài 132 — llms.txt cho AI đọc website

> Bài học được biên soạn từ transcript "LLM.txt".

## 1. Mục tiêu bài học

Sau bài này bạn có thể:

1. Nói được `llms.txt` là gì, nằm ở đâu, viết bằng gì.
2. Giải thích lợi ích: accuracy, discoverability, context, SEO cho AI search.
3. Phân biệt `llms.txt` gọn với `llms-full.txt` đồ sộ của LangChain/LangGraph.
4. Nêu được 2 usage patterns: agent + scraper lấy real-time, và chunk-index vào vector store.
5. Giữ đúng thuật ngữ Anh: llms.txt, llms-full.txt, web scraping, RAG, context cache.

## 2. Kiến thức cốt lõi

### Định nghĩa

- `llms.txt` là standard file giúp LLMs và AI agents hiểu và xử lý website content tốt hơn.
- Thường đặt ở root directory của website, là bản tóm tắt ngắn gọn nội dung và cấu trúc quan trọng nhất của site, ở machine-readable Markdown format.
- Nội dung: URLs tới important pages kèm brief description của mỗi page và purpose, có thể kèm optional additional information.
- Đối tượng phục vụ: ChatGPT, Google Gemini, hoặc application-based AI agents của chính bạn.

### Lợi ích

1. Cải thiện AI accuracy khi extract thông tin từ website.
2. Tăng content discoverability — chủ website có incentive tạo file này.
3. Cho better context về cấu trúc website.
4. Cải thiện SEO bằng cách mở content cho AI-driven search engines.
5. Lưu ý: chưa phải official standard nhưng gaining massive popularity trong GenAI community.

### Hai biến thể của LangChain

- LangChain team đi trước một bước: docs LangGraph có cả `llms.txt` thường và `llms-full.txt`, cho cả Python và JavaScript.
- `llms.txt`: chỉ URLs + short description.
- `llms-full.txt`: toàn bộ texts của những pages đó — huge file.

### Khi nào dùng bản nào

- Dùng `llms.txt` gọn khi có agent/MCP server kèm web scraping tool (ví dụ Firecrawl): bỏ bản đồ website vào context, LLM chọn tool với đúng URL để download đúng phần cần (ví dụ docs về LangChain memory) — kind of similar like RAG. Được real-time information, agents chất lượng hơn, nhưng latency cao hơn vì phải fetch → LLM xử lý → fetch tiếp → xử lý mới ra kết quả.
- Dùng `llms-full.txt` khi muốn download một lần rồi tự chunk, index vào vector store; hoặc LLM context lớn thì gửi cả cục; hoặc có context cache thì cache lại.
- Transcript hẹn video sau demo hands-on dùng `llms.txt` + MCP để fetch real-time.

## 3. Ví dụ và diễn giải

- Trang demo: LangGraph official documentation có `llms.txt`.
- Flow với bản gọn: context có mapping → LLM chọn URL memory → scraper download → xử lý → đáp án.
- Flow với bản full: download → chunk → embed vào vector store, hoặc nhét thẳng vào large context.
- Giữ đúng phép ví trong transcript: bản gọn như RAG động, bản full như index tĩnh.

## 5. Tóm tắt một trang

| Ý | Nội dung |
|---|---|
| Là gì | Markdown tóm tắt site ở root, cho LLMs/agents |
| Gồm gì | URLs + mô tả + purpose từng page quan trọng |
| Lợi ích | Accuracy, discoverability, context, SEO |
| Bản gọn | `llms.txt`: index nhẹ, agent + scraper fetch real-time |
| Bản full | `llms-full.txt`: tất cả text, hợp chunk-index hoặc large context |
| Đánh đổi | Real-time thì latency cao hơn |

**Một câu chốt:** `llms.txt` là bản đồ kho tài liệu, còn scraper và agent là đôi chân đi lấy đúng trang cần.

**1.** Ở root directory của website, định dạng Markdown machine-readable với URLs và mô tả các pages quan trọng nhất.
