# Chúc Mừng Bạn Đã Xong Khóa Học: Lộ Trình Tiếp Theo Cho Developer Và Admin

Chúc mừng bạn đã đi tới cuối khóa học Kafka này. Từ một người chưa biết topic là gì, giờ bạn đã tự tay dựng cluster, viết producer/consumer, tune replication và retention. Đó là một chặng đường dài và đáng tự hào.

Nhưng đây mới là điểm khởi đầu. Kafka trong production rộng hơn khóa học này nhiều. Câu hỏi là: bạn muốn đi sâu theo hướng nào?

---

## 1. Bạn Đã Học Được Gì? Tóm Tắt Lộ Trình

- **Nền tảng:** topics, partitions, offsets, producers, consumers, brokers, replication, acks, KRaft.
- **Thực chiến CLI và code:** tạo topic, produce/consume, consumer groups, reset offsets, Java client, graceful shutdown, rebalance.
- **Dự án thật:** Wikimedia → OpenSearch pipeline, batching, delivery semantics, idempotence.
- **Mở rộng:** Kafka Connect, Kafka Streams, Schema Registry — chọn đúng API cho từng bài toán.
- **Vận hành và tuning:** sizing cluster, monitoring, security, MirrorMaker, segments, cleanup policies, compaction, unclean election, large messages.

Nếu bạn làm lại toàn bộ demo mà không cần nhìn hướng dẫn, bạn đã đủ tự tin nhận task Kafka ở công ty.

## 2. Muốn Thành Kafka Developer Giỏi? Học Tiếp 4 Mảnh Này

1. **Kafka Connect** — bơm dữ liệu ra S3, Elasticsearch, database mà không viết consumer tay.
2. **Kafka Streams** — xử lý stream real-time ngay trong Kafka (join, aggregate, windowing).
3. **ksqlDB (Confluent)** — query stream bằng SQL thay vì viết code Java.
4. **Schema Registry** — quản Avro/Protobuf schema, tương thích ngược khi event thay đổi.

## 3. Muốn Thành Kafka Admin Cứng? Học Tiếp 3 Mảnh Này

1. **Kafka Setup** — dựng multi-broker, multi-rack từ con số 0, automation bằng Terraform/Ansible.
2. **Kafka Monitoring** — JMX, Prometheus, alert URP và latency như bài section 15.
3. **Kafka Security** — SSL, SASL/SCRAM, ACL cho từng service account.

Và khi đã cứng cả hai hướng, hãy thi **Confluent Certified Developer / Administrator for Apache Kafka** để chứng minh năng lực — transcript gợi ý dùng practice exam của Conduktor để luyện.
